# 制作模式优化讨论

**开始日期**: 2026-02-01

## 用户制作拼豆的痛点

1. **找珠子** - 从一堆珠子中找到正确颜色
2. **放珠子** - 按图纸准确放置，不放错位置
3. **跟踪进度** - 做到一半被打断，回来不知道做到哪了
4. **色号缺货** - 某些颜色买不到，需要用其他颜色替代

## 当前已有功能

- 行模式/区块模式引导
- 进度追踪（标记已完成的珠子）
- 缩放查看
- 颜色色号显示
- +/- 按钮和滚轮缩放

## 讨论中的改进方向

### 1. 找珠子优化 - 智能点击交互

**根据缩放级别自动切换点击行为**：

| 缩放状态 | 点击行为 | 作用 |
|---------|---------|------|
| 缩小（看不到色号） | 点击 → 选中所在的大网格（10x10） | 选区块 |
| 放大（能看到色号） | 点击 → 高亮当前大网格内所有同色格子 | 按颜色放珠子 |

**用户操作流程**：
1. 缩小看全图 → 点击选择要做的区块
2. 放大进入区块 → 点击某个颜色的格子
3. 系统高亮该区块内所有同色格子
4. 用户找该颜色珠子，一口气放完
5. 点击下一个颜色，重复

**高亮行为区分**：
| 操作 | 高亮内容 | 说明 |
|------|---------|------|
| 选中区块（缩小状态点击） | 高亮网格线（粗/细） | 只强调区块边界，不改变格子颜色 |
| 选中颜色（放大状态点击） | 高亮同色格子 | 把区块内该色号的格子高亮显示 |

### 2. 放珠子优化 - 坐标提示

**双重提示机制**：

| 场景 | 提示方式 |
|------|---------|
| 支持语音的环境 | Web Speech API 朗读坐标 |
| 不支持语音的环境 | 悬浮坐标提示框 |

**悬浮提示框设计**：
- **位置**：优先左上方，避免遮挡右侧和下方格子
- **边界处理**：点击左上角时，提示框显示在右下方
- **显示时长**：1.5-2秒后开始淡出
- **淡出动画**：0.3秒渐隐消失
- **再次查看**：再点一次重新显示

**配合十字准星**（可选）：
- 点击格子时显示横纵十字辅助线
- 帮助用户在图纸和实际拼豆板之间对准位置

### 3. 进度保存 - 恢复选中状态

**简化设计**：不记录完成度，只记住用户最后的选中状态

**保存数据**：
```typescript
{
  patternId: string;
  selectionType: 'block' | 'color';  // 选中类型
  block: { x: number; y: number };    // 哪个区块
  colorCode?: string;                 // 哪个色号（颜色模式时）
}
```

**恢复效果**：
| 上次状态 | 下次进入效果 |
|---------|-------------|
| 选中了区块(1,2) | 区块(1,2)的网格线高亮 |
| 选中了区块(1,2)的色号#FF0000 | 区块(1,2)内所有#FF0000格子高亮 |

**保存时机**：
- `visibilitychange` - 页面切后台/切标签
- `pagehide` - 关闭页面
- 切换区块/颜色时顺便保存（兜底）

### 4. 色号替换功能

**场景**：用户买不到某个颜色的珠子，需要替代

**已确定的设计**：
| 问题 | 决定 |
|------|------|
| 色板数据 | 使用程序现有的品牌色板 |
| 替换保存 | 永久保存，下次打开仍是替换后的 |
| 导出图纸 | 使用替换后的颜色 |
| 替换范围 | 全局替换（整个作品，不是单个区块） |
| 批量替换 | 支持，该色号所有位置都换掉 |

**交互入口**：
- 放大状态点击格子 → 高亮同色 → 底部操作栏显示「替换颜色」按钮

**交互流程**：
1. 用户点击格子，高亮同色
2. 底部显示：颜色信息 + 本区块数量 + 整个作品数量
3. 点击「替换颜色」→ 弹出替换面板
4. 显示推荐颜色（按色差排序）+ 手动选择
5. 确认前提示"将替换整个作品中的 N 颗"
6. 确认后全局替换，预览实时更新

**待实现**：
- [ ] Delta E 颜色推荐算法

### 5. 图纸显示规范（匹配实际拼豆板）
- **坐标系统**：图纸显示横纵坐标，方便用户定位
- **网格线起点**：从第2格开始画（第1格是边框，四个角不计数）
- **坐标编号**：网格线起始处标为"1"（不是2），用户不用做心理换算
- **大网格线**：每10格画一条粗线
- **坐标范围**：1 到 N-2（如29x29板子，坐标是1~27）
