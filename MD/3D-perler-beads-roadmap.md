# 3D拼豆图纸生成器 - 技术路线图 V2

## 更新记录
- V2 (2024): 新增深度图方案，放弃传统3D建模方案

## 项目背景

当前拼豆工坊只支持2D图纸生成，用户对3D拼豆作品的需求日益增长。

**核心思路变更**：
- ~~原方案：2D图片 → AI生成3D mesh模型 → 体素化~~（效果差、成本高）
- **新方案：2D图片 → 深度估计 → 立体像素化**（效果好、成本低、更适合拼豆）

## 产品形态

### 模式1：浮雕模式（单张图片）
```
用户上传1张正面图 → 生成正面浮雕
- 正面有凹凸细节
- 背面平整
- 适合：冰箱贴、挂墙装饰、桌面摆件
```

### 模式2：完整3D模式（多角度图片）
```
用户上传3-4张固定角度图 → 生成完整立体
- 正面 + 背面 + 侧面
- 360°完整立体
- 适合：可旋转观看的摆件
```

## 技术方案对比

| 方案 | 传统3D建模 | 深度图方案（新） |
|------|-----------|-----------------|
| 流程 | 图片→3D mesh→体素化 | 图片→深度图→立体像素 |
| 效果 | 容易变形、扁平 | 天然适合像素风格 |
| 成本 | ~$0.05/次 | ~$0.01/次 |
| 背景处理 | 容易带入背景 | 自动过滤（黑色=远） |
| 适合拼豆 | 一般 | 非常适合 |

## 数据结构设计

### 体素数据结构
```typescript
// types/3d/voxel.ts

interface Voxel {
  x: number;      // X坐标
  y: number;      // Y坐标
  z: number;      // Z坐标（层数）
  color: string;  // 颜色hex
  beadId: string; // 对应的拼豆色号
}

interface VoxelModel {
  width: number;   // X方向尺寸
  height: number;  // Y方向尺寸
  depth: number;   // Z方向尺寸（层数）
  voxels: Voxel[]; // 所有体素
}

interface Layer {
  z: number;       // 层号（从0开始）
  beads: Bead[];   // 该层的珠子数据（复用现有Bead类型）
}
```
