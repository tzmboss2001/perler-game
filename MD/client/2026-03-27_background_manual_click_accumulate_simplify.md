# 2026-03-27 手动扣背景简化为点格累加

## 背景
用户希望手动扣背景进一步简化，不再暴露多种手动工具，而是改成：
1. 用户每点一个背景格子，系统自动识别一块可删除背景
2. 再点其他背景格子，系统继续累加新的背景块
3. 提供“回退一步”撤销最近一次选择
4. 背景查看时提供显式“移动视图”模式，不要求记忆复杂手势

## 本次修改
### 1. 手动扣背景改成多块累加
- `连片选背景` 的内部状态从单个选区改成多块选择列表 `bgManualSelections`
- 每次点击新的背景格子时，会把新的连通背景块追加到当前选区，而不是替换掉上一次选择
- 当前高亮区域统一合并所有手动选择块，再统一减去排除区

### 2. 增加“回退一步”
- 新增 `handleBgUndoManualSelection()`
- 每次点击“回退一步”会移除最近加入的一块手动背景选择
- 若全部回退完，则回到未选择状态

### 3. 交互文案收口
- 手动扣背景区域改成更直接的说明：
  - “点图扣背景”
  - “每点一次，系统都会自动识别并累加一块背景；点错了就回退一步。”
- 底部主操作改成：
  - `回退一步`
  - `确定`
  - `返回编辑`

### 4. 移动画面模式保留
- 背景模式下保留显式的 `移动视图 / 结束移动视图`
- 开启后不再执行点格选择，而是直接拖动画面查看局部

### 5. 代码收尾
- 补齐新的手动引导卡样式
- `回退一步` 图标改为逆时针回退图标
- `handleBgClearSelection()` 同步清空 `bgManualSelections`

## 涉及文件
- `perler-beads/src/pages/mobile/EditorPage.tsx`

## 验证
- 执行：`cmd /c npm run build`
- 结果：通过

## 当前效果
手动扣背景现在更接近单一路径：
1. 打开手动扣背景
2. 直接点背景格子累加要删除的区域
3. 点错了就回退一步
4. 需要查看局部时，显式打开移动视图
5. 最后点确定
