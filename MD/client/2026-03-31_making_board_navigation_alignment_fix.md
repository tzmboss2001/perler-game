# 2026-03-31 制作模式多板导航板号对齐修复

## 问题
- 制作模式多板场景下，`上一块 / 下一块 / 定位当前板` 已经接上，但板号显示、切板提示和当前板判断出现错位。
- 典型表现：点击 `下一块` 后提示 `已切到板5`，底部辅助条却仍显示 `板3`；点击 `上一块` 后提示和板号也可能对不上。

## 根因
- 当前板判断对区块选择使用的是 `selection.blockX * BLOCK_SIZE` 和 `selection.blockY * BLOCK_SIZE`，也就是区块左上角坐标。
- 当目标板的起点不是 `BLOCK_SIZE` 的整数倍时，例如现实豆板宽度为 `104`，区块量化后会把坐标压到 `100`，导致板号重新落回上一块板。
- 结果就是：
  - `currentBoardRect` 计算错误
  - 底部辅助条显示的板号错误
  - `上一块 / 下一块` 的启禁和跳转提示也会跟着错位

## 修复
- 在 `MakingPage.tsx` 中新增 `selectedBlockAnchor`：
  - 对区块选择不再用区块左上角判断板号
  - 改成使用区块中心格作为当前板判断锚点
- `currentBoardRect` 改为优先使用：
  - 颜色选择时的 `selectedCell`
  - 区块选择时的 `selectedBlockAnchor`
- `selectedCoordinateSummary` 也改为基于同一锚点计算：
  - `板N`
  - `列X · 行Y`
  - `全图 X,Y`

## 结果
- 多板场景下，底部辅助条中的板号、列行、全图坐标与 `上一块 / 下一块 / 定位当前板` 将保持一致。
- 现实豆板边界为 `104` 这类非 `BLOCK_SIZE` 整倍数时，不会再因为区块量化回落到上一块板。
