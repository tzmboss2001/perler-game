# 2026-04-08 制作模式坐标提示文本与颜色高亮减弱优化

## 问题
- 用户反馈制作模式里的坐标提示疑似存在乱码。
- 同时，区块内同色高亮统一使用偏重的粉色覆盖，会削弱原始颜色识别。

## 判断
- 当前 MCP 页面快照里，页面 DOM 中的主坐标文本已经是正常中文。
- 为降低特殊分隔符或字体兼容带来的显示风险，仍将坐标提示文案进一步收成更基础的文本表达。

## 修改
1. 坐标提示文案收口
- 将制作模式底部坐标摘要中的：
  - `列X · 行Y`
  改成：
  - `列X 行Y`
- 将 `CoordinateTooltip` 中同样的文本同步改成：
  - `列X 行Y`

2. 颜色高亮减弱
- 当前区块内非目标格子的变暗从 `rgba(0, 0, 0, 0.22)` 降到 `rgba(0, 0, 0, 0.16)`
- 区块内目标同色格子的浅色提亮从 `rgba(255, 255, 255, 0.24)` 降到 `rgba(255, 255, 255, 0.14)`
- overlay 粉色填充从 `rgba(255, 106, 162, 0.34)` 降到 `rgba(255, 106, 162, 0.18)`

## 结果
- 坐标提示更基础，减少因特殊分隔符带来的显示异常风险。
- 同色高亮仍然明显，但原始颜色透出更多，不会整片都偏粉。
