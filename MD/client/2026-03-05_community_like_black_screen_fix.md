# 2026-03-05 社区点赞黑屏兜底修复

## 问题现象
- 用户反馈：在社区详情页点击点赞后出现黑屏。

## 根因分析
- 点赞链路存在返回数据容错不足问题：前端默认依赖 `res.data.liked` / `res.data.like_count`。
- 当后端返回结构异常、为空或非预期类型时，页面状态可能进入异常分支，表现为白屏/黑屏。
- 成品详情页点赞链路同样存在同类风险。

## 本次修改

### 1) 社区详情页点赞容错
- 文件：`perler-beads/src/pages/mobile/CommunityDetailPage.tsx`
- 修改点：
  - 增加 `id` 有效性校验（无效时直接提示并返回）。
  - 点赞成功时对返回值做类型保护：
    - `liked` 非布尔值时回退为当前状态。
    - `like_count` 非数字时回退为当前计数。
  - 非 `code=0` 或请求异常时弹出错误提示，不再静默失败。

### 2) 成品详情页点赞容错
- 文件：`perler-beads/src/pages/mobile/FinishedWorkDetailPage.tsx`
- 修改点：
  - 同步增加 `res.data` 字段类型保护与回退。
  - 点赞失败显示 `alert`，避免用户误判为无响应。

## MCP 回归测试
- 场景1：未登录状态进入 `http://127.0.0.1:4173/mobile/community/11` 点击点赞。
  - 结果：稳定跳转到登录页，无黑屏崩溃。
- 场景2：社区详情页加载与互动按钮渲染正常。
  - 结果：页面可交互，未出现控制台报错。

## 构建验证
- 命令：`cmd /c npm run build`
- 结果：构建通过。

## 备注
- 当前修复重点是“点赞异常响应的前端防崩溃兜底”。
- 若后续仍有个别机型黑屏，需要继续抓取该机型 WebView 控制台日志做进一步定位。
