# 2026-04-03 制作模式色号描边圆角修复

## 问题
制作模式中色号使用 `strokeText + fillText` 绘制描边时，像 `M` 这样的尖角字母在高倍率下会出现两侧长出“小耳朵”的现象，看起来像描边炸开。

## 原因
Canvas 文本描边默认使用尖角连接（miter join），在字母尖顶处会形成突出的尖角。配合较粗描边时，这种尖角会被放大，导致 `M/W/N` 等字母边缘出现不自然的突出。

## 修复
在 `MakingPage.tsx` 的色号 overlay 绘制逻辑中：
1. 将色号描边宽度从较重的配置收细。
2. 将 `lineJoin` 改为 `round`。
3. 将 `lineCap` 改为 `round`。
4. 收紧 `miterLimit`，避免尖角继续外突。

## 效果
- `M`、`W`、`N` 等字母的描边转角更圆润。
- 不再出现两侧长出“小耳朵”的尖角突刺。
- 保留描边提供的深浅底色可读性，不需要把描边整体删除。

## 验证
- `npm run build` 通过。
