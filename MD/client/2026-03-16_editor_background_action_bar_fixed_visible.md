# 2026-03-16 背景处理模式底部操作条首屏可见修复

## 问题
- 手机端进入编辑页背景处理模式后，底部操作条里的“回退上一步 / 前进一步 / 应用去背景 / 返回编辑”没有出现在首屏可视区域。
- 实际截图中只能看到顶部主按钮和中部预览区，看不到底部核心操作。

## 原因
- 背景处理模式底部操作条虽然配置了 `sticky`，但仍处在页面正常文档流中。
- 在手机屏幕高度有限时，预览区和提示区域会把底部操作条继续挤到首屏以下。
- 同时背景模式遮罩层级低于底部导航，存在被底部导航压住的风险。

## 修复
- 将背景处理模式遮罩层 `z-index` 提升到高于底部导航。
- 将底部操作条从 `sticky` 改为真正的 `fixed` 贴底布局。
- 给背景处理模式整体增加底部留白，避免底部固定操作条遮住中间内容。

## 修改文件
- `perler-beads/src/pages/mobile/EditorPage.tsx`

## 结果
- 背景处理模式下，底部操作条会固定显示在屏幕底部。
- 手机端首屏可直接看到“回退上一步 / 前进一步 / 应用去背景 / 返回编辑”。
