# 下载图纸功能迁移到制作页面

**日期**: 2026-01-31
**类型**: 功能调整

## 需求描述

将"下载图纸"功能从编辑页面迁移到制作页面。这样用户想要下载图纸或进行制作时，都需要先进入制作页面（需要登录并保存），便于后续接入广告变现。

## 修改文件

### 前端
1. `src/pages/mobile/EditorPage.tsx` - 移除下载功能
2. `src/pages/mobile/MakingPage.tsx` - 添加下载功能

## 修改内容

### EditorPage.tsx - 移除下载功能

```typescript
// 移除的导入
- import { DownloadSimple } from '@phosphor-icons/react';
- import ExportModal from '../../components/ExportModal';

// 移除的状态
- const [showExportModal, setShowExportModal] = useState(false);

// 移除的函数
- const handleDownload = () => {
-   if (!beadData) return;
-   setShowExportModal(true);
- };

// 移除的按钮
- <button style={styles.secondaryBtn} onClick={handleDownload}>
-   <DownloadSimple size={18} />
-   下载
- </button>

// 移除的组件
- <ExportModal
-   visible={showExportModal}
-   onClose={() => setShowExportModal(false)}
-   beadData={beadData}
- />
```

### MakingPage.tsx - 添加下载功能

```typescript
// 新增导入
+ import { DownloadSimple } from '@phosphor-icons/react';
+ import ExportModal from '../../components/ExportModal';

// 新增状态
+ const [showExportModal, setShowExportModal] = useState(false);

// 在浮动控制栏添加下载按钮
+ <button
+   style={styles.miniBtn}
+   onClick={() => setShowExportModal(true)}
+   title="下载图纸"
+ >
+   <DownloadSimple size={14} />
+ </button>

// 添加导出弹窗组件
+ {beadData && (
+   <ExportModal
+     visible={showExportModal}
+     onClose={() => setShowExportModal(false)}
+     beadData={beadData}
+   />
+ )}
```

## 用户流程变化

### 修改前
1. 编辑页面 → 直接点击"下载"按钮
2. 无需登录，无需保存

### 修改后
1. 编辑页面 → 点击"开始制作"
2. 如未登录 → 弹出登录弹窗
3. 登录成功 → 保存方案到云端
4. 进入制作页面 → 点击下载按钮

## 效果

- 下载图纸功能移至制作页面的浮动控制栏
- 用户必须登录并保存方案后才能进入制作页面
- 便于后续在保存/进入制作流程中接入广告
- 编辑页面按钮减少，界面更简洁
