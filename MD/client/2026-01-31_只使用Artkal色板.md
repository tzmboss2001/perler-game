# 只使用 Artkal 色板 - 国内玩家常用品牌

**日期**: 2026-01-31
**类型**: 功能优化

## 需求描述

将颜色匹配限制为中国玩家常用的品牌 Artkal，而不是使用所有 356 色。

## 背景

原有系统支持三个品牌的珠子颜色：
- **Perler**: 102色 (美国品牌)
- **Hama**: 80色 (欧洲/丹麦品牌)
- **Artkal**: 174色 (中国品牌)
- **总计**: 356色

对于国内玩家，Artkal 是最容易购买到的品牌，其他品牌需要海淘，成本高且不方便。

## 修改文件

`src/data/beadColors.ts`

## 修改内容

### 1. 修改 allBeadColors

```typescript
// 修改前
export const allBeadColors: BeadColor[] = [
  ...perlerColors,
  ...hamaColors,
  ...artkalColors,
];

// 修改后 - 只使用 Artkal
export const allBeadColors: BeadColor[] = [
  ...artkalColors,
];
```

### 2. 更新颜色数量选项

```typescript
// 修改前
export const colorCountOptions: ColorCountOption[] = [
  { count: 48, label: '48', description: '简单' },
  { count: 72, label: '72', description: '一般' },
  { count: 96, label: '96', description: '细腻' },
  { count: 120, label: '120', description: '精细' },
  { count: 168, label: '168', description: '超精细' },
  { count: 220, label: '220', description: '极致' },
  { count: 280, label: '280', description: '顶配' },
  { count: 356, label: '356', description: '全部' },

// 修改后 - 基于 Artkal 174色
export const colorCountOptions: ColorCountOption[] = [
  { count: 48, label: '48', description: '简单' },
  { count: 72, label: '72', description: '一般' },
  { count: 96, label: '96', description: '细腻' },
  { count: 120, label: '120', description: '精细' },
  { count: 174, label: '174', description: '全部' },
];
```

## 效果

1. 颜色匹配只使用 Artkal 的 174 种颜色
2. 用户选择颜色数量时，最大值为 174（全部）
3. 生成的图案只需要购买 Artkal 品牌珠子即可制作
4. 减少用户购买材料的复杂度和成本

## 保留的功能

- `perlerColors`、`hamaColors`、`artkalColors` 数组仍然保留在代码中
- `getColorsByBrand()` 函数仍然可用，未来可以支持品牌切换功能
- 如需恢复多品牌支持，只需修改 `allBeadColors` 的定义即可
