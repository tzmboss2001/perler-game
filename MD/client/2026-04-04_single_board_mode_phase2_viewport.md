# 2026-04-04 单板模式第二阶段：当前板视口验证

## 本次完成
- 单板模式的大浏览区已切换为“只渲染当前板”，不再继续显示整张作品。
- 修复了第二阶段实现中的两个真实问题：
  1. `commitTranslate` 在声明前被 `useEffect` 调用，导致制作页运行时错误。
  2. 单板切换后，`activeBoardNumber` 会被传统模式下的 `currentBoardRect` 反向覆盖，导致点了板6却显示板4。
- 修正了 `activateBoard()` 的区块锚点计算，保证切换到新板后，区块中心落在该板内部而不是跨板边界外侧。

## MCP 验证
- 当前页面：`/mobile/making`
- 验证步骤：
  1. 保持在 `单板模式`
  2. 点击 `板6`
  3. 截图确认大浏览区只显示板6对应内容
  4. 点击 `板2`
  5. 截图确认大浏览区切换为板2对应内容
- 验证结果：
  - 底部固定辅助条会随切板更新：
    - 板6 时显示 `板6 · 列12 · 行8 · 全图116,216`
    - 板2 时显示 `板2 · 列12 · 行6 · 全图116,6`
  - 大浏览区内容随板切换明显变化，说明当前板视口逻辑已经生效。

## 当前还差哪些项
1. 总览缩略图还没做
- 还没有一张小型总体图来标识“当前板在整张作品中的位置”。

2. 单板预览区空间利用还不够好
- 当前单板区域已经只显示当前板，但首屏里实际可视区域偏矮，后续要继续优化布局，让单板更像真正的主工作区。

3. 板级进度体系还不完整
- 现在已有“标记本板完成”和本地持久化。
- 还没有总完成率可视化、自动切下一块、按板恢复制作入口等更完整的工作流。
