# 2026-03-14 个人页小屏响应式收口

## 问题
- 个人页在窄屏手机下，用户卡片、方案卡片、社区发布卡片和菜单区容易出现横向拥挤。
- 标题和元信息在小屏时可读性下降，操作按钮也容易顶到内容区域。

## 处理
- 为 `ProfilePage.tsx` 增加 `viewportWidth` 监听。
- `<= 390px` 时：
  - 用户卡片允许换行，登录/退出按钮可独占一行。
  - 方案卡片和发布卡片的元信息允许换行。
  - 操作按钮区改为更稳定的右对齐布局。
- `<= 360px` 时：
  - 标题改为最多两行显示。
  - 相册头部按钮改为整行。
  - 菜单项内边距和字号进一步压缩。
- 统一收口了个人页中的项目卡片、社区发布卡片、相册卡片和菜单项小屏表现。

## 影响范围
- 客户端
- 文件：`perler-beads/src/pages/mobile/ProfilePage.tsx`

## 验证
- 运行 `npm run build`，确认前端构建通过。

## 说明
- 本轮仅处理小屏布局，不改个人页业务逻辑。
