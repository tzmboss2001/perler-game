# 2026-03-10 大图高清优化模式

## 变更背景
- 创建页面之前对超过 10MB 的图片直接拒绝上传。
- 这种做法虽然能保护前端性能，但会直接挡住高清原图用户，体验太硬。

## 本次改动
1. 新增 `imageOptimizationService.ts`
- 对大图做统一预处理。
- 规则：最长边限制到 2560，像素总量限制到安全范围。
- 在多档 JPEG 质量下自动选择，尽量压到 10MB 内。

2. 改造 `CreatePage.tsx`
- 10MB 内图片：保持原来的快速导入。
- 超过 10MB：不再直接拒绝，进入“高清优化模式”。
- 用户观看激励广告后，系统自动优化图片，再进入裁剪流程。
- 页面补充优化中的提示和优化结果摘要。

3. 文案调整
- 上传提示改为：10MB 内快速导入，超大图可进入高清优化模式。
- 选图建议新增高清图优化说明。

## 用户可见变化
- 之前：超过 10MB 直接弹错误提示，无法继续。
- 现在：超过 10MB 会提示进入高清优化模式，看完广告后自动处理并继续。

## 技术说明
- 这次不是单纯按文件体积压缩。
- 同时控制了解码后的像素尺寸，避免手机端 `canvas/getImageData` 内存和 CPU 暴涨。
- 目标是保留对拼豆生成有价值的清晰度，而不是追求原图无损。

## 验证结果
- `cmd /c npm run build` 通过。
- 前端已具备大图高清优化处理能力。
