# 2026-04-07 单板模式高倍率颜色高亮可视性增强

## 问题
- 单板模式在高倍率下虽然已能进入颜色模式，但区块内同色格子的高亮过弱。
- 用户视觉上容易误判为仍然停留在区块模式。

## 本次修改
- 在制作模式覆盖层中，为当前区块内同色格子增加更明显的高亮填充。
- 为所有同色格子增加粉色描边。
- 为当前点击的那个格子增加更强的白色描边，突出当前焦点。
- 保留区块边界高亮，不改变原有区块聚焦逻辑。

## 修改文件
- `perler-beads/src/pages/mobile/MakingPage.tsx`

## 验证
- `cmd /c npm run build`
