# 预览图自适应居中显示

**日期**: 2026-01-30
**类型**: 功能优化

## 需求描述

无论用户上传什么尺寸的图片，生成的拼豆图案在预览区域都应该：
1. 自动计算适配缩放比例，确保图片完整显示
2. 大图自动缩小，小图适当放大
3. 居中显示
4. 用户可以通过滑杆自由调整缩放

## 修改文件

`src/components/InteractiveCanvas.tsx`

## 修改内容

### 1. 添加自适应缩放计算函数

```tsx
// 计算适配预览区的缩放比例
const calculateFitScale = useCallback(() => {
  if (!containerRef.current || !beadData) return 1;

  // 容器可用尺寸（减去 padding）
  const containerWidth = containerRef.current.clientWidth - 32;
  const containerHeight = containerRef.current.clientHeight - 32;

  // 图片原始尺寸
  const imageWidth = beadData.width * cellSize;
  const imageHeight = beadData.height * cellSize;

  // 计算水平和垂直方向的缩放比例，取较小值
  let fitScale = Math.min(containerWidth / imageWidth, containerHeight / imageHeight);

  // 限制在合理范围内
  return Math.max(MIN_SCALE, Math.min(MAX_SCALE, fitScale));
}, [beadData, cellSize]);
```

### 2. beadData 变化时自动适配

```tsx
useEffect(() => {
  if (beadData && containerRef.current) {
    requestAnimationFrame(() => {
      const fitScale = calculateFitScale();
      setScale(fitScale);
    });
  }
}, [beadData?.width, beadData?.height, calculateFitScale]);
```

### 3. 添加"适配"按钮

在缩放控制栏添加"适配"按钮，用户可以随时点击恢复到适配全图状态：

```tsx
<button
  style={styles.zoomButton}
  onClick={() => setScale(calculateFitScale())}
  title="适配预览区"
>
  适配
</button>
```

### 4. 居中显示

```tsx
margin: 'auto', // 小图时居中显示
```

## 效果

- 初始加载时自动计算并设置适配缩放比例
- 大图自动缩小到能完整显示
- 小图适当放大到合适尺寸
- 图片始终居中显示
- 新增"适配"按钮，用户可随时恢复适配状态
- 用户仍可通过滑杆自由调整缩放比例
