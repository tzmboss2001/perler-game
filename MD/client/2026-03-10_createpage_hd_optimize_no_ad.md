# 2026-03-10 大图自动优化免广告

## 变更背景
- 上一版把超过 10MB 的图片接入了高清优化模式，但进入优化前需要先看广告。
- 这个门槛不适合创建主链路，会增加首步阻力。

## 本次改动
1. 取消大图优化前的激励广告
- 超过 10MB 的图片现在直接进入自动优化。
- 不再弹奖励广告弹窗。

2. 保留自动优化能力
- 仍然会先按安全规格压缩和缩放。
- 然后再进入裁剪和后续编辑流程。

3. 调整用户文案
- 上传页提示改为：超大图会自动优化后继续。
- 优化状态提示改为自动处理，不再出现广告相关描述。

4. 顺手修复
- 清理 `imageOptimizationService.ts` 中的错误提示乱码。

## 用户可见变化
- 之前：大图上传后需要先看广告。
- 现在：大图上传后直接自动优化，再进入裁剪。

## 验证结果
- `cmd /c npm run build` 通过。
- 适合直接用于真机上传大图测试。
