# 2026-03-27 去背景页面布局与交互简化

## 问题
- 背景处理模式顶部的“一键去背景”和“打开手动扣背景”会占用预览区上方空间，压缩可视区域。
- 手动扣背景相关提示文案重复，用户需要读文案才能理解操作。
- 页面左上角已经有返回按钮，底部再放“返回编辑”属于重复入口。
- 用户希望直接点预览图就进入手动扣背景，不再额外打开二级按钮。

## 调整
1. 删除顶部入口区：
   - 去掉“去背景工具”说明卡
   - 去掉顶部“一键去背景”按钮
   - 去掉“打开手动扣背景”按钮
2. 手动扣背景默认可用：
   - 进入背景处理模式后，用户可直接点击预览图背景格子开始累加选择
   - 不再需要先点“打开手动扣背景”
3. 精简文案：
   - 删除“已加入一块背景区域……”
   - 删除“可继续点击别处累加背景……”
   - 保留必要的自动去背景结果提示、移动视图提示和误删恢复提示
4. 底部主操作重排：
   - 保留“回退一步”
   - 保留“确定”
   - 将“返回编辑”替换成“一键去背景”
   - 返回只保留左上角按钮

## 结果
- 预览图上方被释放出更多空间。
- 背景处理模式默认就是“直接点图扣背景”。
- 页面主操作更清晰：点图选择、回退一步、确定、一键去背景。
