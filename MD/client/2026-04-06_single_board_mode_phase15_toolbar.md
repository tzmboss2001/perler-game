# 2026-04-06 单板模式第十五阶段：单板工具区收口

## 本次目标
- 继续压缩顶部与工具区
- 让缩放区和控制区更贴合单板制作工作流
- 继续收尾全部完成后的后续动作体验

## 本次完成
1. 单板模式缩放区切换为单板语义
- 单板模式下原来的 `适宽` 按钮已改成 `适板`。
- 描述也同步调整为：`适应当前板`。
- 这样用户在单板模式里不会再把这个按钮理解成整图宽度适配。

2. 单板工具按钮改成工作台入口
- 单板模式下原来的图标按钮改成了更明确的文字入口：
  - `图纸`
  - `辅助`
- 对应行为仍然是：
  - 打开导出图纸
  - 打开设置/辅助面板
- 但语义上更符合单板制作，而不是通用浏览工具栏。

3. 单板模式空状态提示继续收紧
- 未选中状态下的状态提示，从：
  - `点击选择区块 / 点击选择颜色`
- 收成：
  - `点格选区块 / 点格选颜色`
- 更短，更符合单板模式的工作语境。

## MCP 验证
1. 首屏工具区验证通过
- 当前单板模式首屏已显示：
  - `适板`
  - `图纸`
  - `辅助`
- 说明单板工作台入口已生效。

2. 全部完成状态下仍保持一致
- 在当前已全部完成的场景下：
  - 顶部入口仍是 `导出图纸`
  - 工具区同步保留 `图纸 / 辅助`
  - 底部任务条仍为收尾态：`全部完成 / 10/10 / 剩余0 / 导出图纸`
- 说明单板模式在“制作中”和“全部完成”两种状态下，工具区语义都已收口。
