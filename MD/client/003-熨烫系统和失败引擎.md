# [2026-02-06] 任务2.1~3.3 - 熨烫系统 + 失败引擎 + 结果页面

## 完成内容

### 任务2.1 IroningSystem 核心 + 风险计算器
- `src/core/RiskCalculator.ts` - 风险值计算器
  - 温度风险（偏离最佳温度6的程度）
  - 时间风险（偏离最佳5秒的程度）
  - 轨迹覆盖率（3×3扩散算法）
  - 轨迹均匀度（4×4网格变异系数）
  - 综合风险 = 温度×0.4 + 时间×0.3 + 轨迹×0.3
- `src/core/IroningSystem.ts` - 熨烫模拟系统
  - 温度/时间/轨迹参数管理
  - 开始/停止/重置
  - 调用 FailureEngine 生成结果

### 任务3.1 FailureEngine 失败引擎
- `src/core/FailureEngine.ts` - 翻车计算引擎
  - 5种失败类型判定：
    - 半生不熟（温度<4 或 时间<2s）
    - 局部融化（轨迹均匀度<0.5）
    - 整体塌陷（温度>8 且 时间>8s）
    - 颜色烧焦（温度>8）
    - 粘连拉扯（默认失败）
  - 拼豆状态变更（raw/melted/burned/collapsed）
  - 烧焦颜色偏移算法（向黄褐色偏移）
  - 翻车报告文案系统（每种类型4+条随机文案）
  - 改进建议系统

### 任务2.2 熨烫UI交互面板
- `src/components/IroningPanel/` - 熨烫控制面板

  - 时间计时器（实时显示，绿→黄→红进度条）
  - 轨迹绘制区域（缩略图+拼豆位置+轨迹热力线）
