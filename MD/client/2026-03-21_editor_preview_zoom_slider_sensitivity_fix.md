# 2026-03-21 编辑页预览缩放滑杆灵敏度修复

## 问题
- 编辑图案页的预览缩放滑杆在相邻缩放比例之间，视觉上经常看不出变化。
- 用户会感觉已经选了不同的缩放百分比，但预览图大小几乎一样。

## 根因
- `InteractiveCanvas` 在计算实际渲染单元格尺寸时使用了 `Math.round(cellSize * scale)`。
- 这会把大量相邻的小数缩放比例压到同一个整数像素值上，导致多个百分比对应同一渲染尺寸。

## 修改
- 去掉缩放渲染尺寸上的整数取整。
- 改为使用真实小数尺寸进行渲染，仅保留最小下限保护。

## 影响文件
- `perler-beads/src/components/InteractiveCanvas.tsx`

## 预期效果
- 预览缩放在相邻百分比之间会更连续。
- 91%、92%、93% 这类细小变化不会再轻易被吞掉。

## 验证
- 执行 `cmd /c npm run build`，构建通过。
