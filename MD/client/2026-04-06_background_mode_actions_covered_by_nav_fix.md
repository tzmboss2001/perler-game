# 背景处理模式底部按钮被底部导航遮挡修复

## 问题
- 背景处理模式中 `回退一步 / 确定 / 一键去背景` 已经渲染出来，但在当前视口中被底部导航和页面层级遮挡，用户视觉上看起来像“没有按钮”。
- 实测按钮区 top 大约在 645px，页面可视高约 703px，和底部导航区发生冲突。

## 修复
1. 提高背景处理覆盖层 `z-index`，确保其真正盖住底部导航与其他固定层。
2. 将背景处理底部操作区 `bgModeActions` 改成 `position: sticky; bottom: 0;`，保证操作区始终贴住当前背景处理页面底部可视区。

## 验证
- `cmd /c npm run build`
- MCP 验证背景处理模式下：
  1. 底部三个按钮重新出现在可视区
  2. 不再被底部导航遮挡
