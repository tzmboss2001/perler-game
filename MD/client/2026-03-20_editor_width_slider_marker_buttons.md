# 2026-03-20 编辑页宽度控件文案与滑杆标记优化

## 问题
- 编辑图案页里“作品宽度”文案偏长，用户实际理解的是宽度。
- 常用拼豆板宽 54 / 78 / 104 虽然已有快捷按钮，但与滑杆分离，使用路径不够直接。

## 处理
- 将编辑页控件文案从“作品宽度”改为“宽度”。
- 保留当前数值显示为“xx 颗”。
- 在宽度滑杆区域内直接加入 54 / 78 / 104 三个标准拼豆板宽度标记按钮。
- 标记按钮按上下交错排列，点击后直接切换到对应宽度并重生成。
- 移除原来单独一排的 54 / 78 / 104 快捷按钮，避免重复。
- 保留一行简短提示，说明常用板宽可直接点滑杆标记。

## 影响文件
- `perler-beads/src/pages/mobile/EditorPage.tsx`

## 验证
- 执行 `cmd /c npm run build`
- 构建通过。

## 结果
- 编辑页宽度控件更直白。
- 常用板宽入口更靠近滑杆本体，手机上更容易直接命中。
