# 006 - 熨烫效果连续渐变改造

## 日期
2026-02-11

## 改动概述
将熨烫结果渲染从"离散状态"模式改为"连续渐变"模式。之前烫1秒和烫2秒只要落在同一个失败类型里，渲染结果完全相同。现在温度越高、时间越长，豆子从圆形逐渐变方、中孔逐渐消失、颜色逐渐变焦，实现真实的连续渐变效果。

## 核心思路
计算连续物理参数（0~1），驱动统一渲染函数做连续插值。failureType 保留用于文字报告，渲染全部由物理参数驱动。

## 修改的文件

### 1. `src/types/game.ts`
- 新增 `IroningPhysics` 接口（6个连续参数 + heatMap）
- 扩展 `IroningResult` 添加 `physics: IroningPhysics` 字段

### 2. `src/core/PhysicsCalculator.ts`（新建）
- 纯函数 `calculatePhysics()`，从熨烫参数计算6个连续物理参数
- 计算公式：
  - **fusion**（融合度）：sigmoid 函数，基于温度和时间
  - **burnLevel**（烧焦程度）：温度超过7度后线性增长
  - **collapseAmount**（坍塌量）：高温+长时间的幂函数
  - **stickyStretch**（粘连拉伸）：高融合+低烧焦+低坍塌条件下
  - **heatMap**（局部热量）：基于轨迹覆盖密度
- 后处理约束确保物理合理性

### 3. `src/core/IroningSystem.ts`
- 在 `finish()` 中调用 `calculatePhysics()` 计算 physics
- 将 physics 加入返回的 `IroningResult`

### 4. `src/components/ResultCanvas/ContinuousRenderer.ts`（新建）
- `drawContinuous()` 主渲染函数
  - 形状插值：圆形 → 圆角矩形 → 方块
  - 中孔：半径随融合度缩小直到消失
  - 颜色：实时计算烧焦偏色
  - 位移：坍塌向心收缩、粘连拉扯
  - 高光：低融合度时显示珠面高光
- `drawOverlays()` 装饰层
  - 焦斑、烟雾（burnLevel 驱动）
  - 皱褶线、翘曲阴影（collapseAmount 驱动）
  - 拉丝高光（stickyStretch 驱动）

### 5. `src/components/ResultCanvas/ResultCanvas.tsx`
- Props 新增 `physics?: IroningPhysics`
- 渲染逻辑：优先使用 `drawContinuous()`，fallback 到旧的离散渲染

### 6. `src/pages/ResultPage.tsx`
- 传递 `physics={ironingResult?.physics}` 给 ResultCanvas

### 7. `src/utils/shareCard.ts`
- 接收 `physics?: IroningPhysics` 参数
- 使用 `drawContinuous()` 渲染分享卡片中的拼豆图（替代原来的简单圆形）
- 通过 `RenderConfig` 适配分享卡片的不同 cellSize

### 8. `src/pages/ResultPage.tsx`（追加修改）
- `getShareOptions` 中传递 `physics` 给分享卡片

### Bug修复：sticky 效果不一致
- **问题**：FailureEngine 判定为 sticky（粘连拉扯），但 PhysicsCalculator 计算的 fusion 太低（<0.6），导致 stickyStretch=0，画面显示未融合的圆形豆子，与"粘连"描述矛盾
- **原因**：stickyStretch 触发门槛 `fusion > 0.6` 太高，手动操作时 uniformity 低导致 fusion 被压低
- **修复**：
  - 降低 stickyStretch 触发门槛：`fusion > 0.6` → `fusion > 0.35`
  - 新增后处理约束：`stickyStretch > 0.1` → `fusion >= 0.65`（粘连必然意味着已融合）

### 优化：sticky 粘连效果（参考真实照片大幅重写）
- **问题**：之前 sticky 效果会让每颗豆子被各向异性拉伸变形（`ctx.scale(stretchX, stretchY)`），看起来像钉板也被融化变形了。现实中钉板是硬塑料，正常温度不可能变形
- **参考**：真实拼豆烫失败的照片 — 豆子粘在烫纸上被拉起，拉成很长的彩色丝条
- **改进（v1 → v2）**：
  - 移除单个豆子的拉伸变形（`stretchX/stretchY` → `liftScale` 缩小效果，被拉伸的豆子变小消失）
  - 大幅增加位移距离：`CELL * 1.5` → `CELL * 5`（真实效果中丝条非常长）
  - 被拉起的豆子透明度随拉伸强度递增（高强度时几乎消失，因为已经变成丝条了）
  - 新增**钉板层**：被拉走的豆子原位置清晰露出钉板底色和钉子
  - 新增**长丝条拉丝**：用三次贝塞尔曲线画从原位置到远端的彩色丝条（3~6条/豆），保留原始颜色
  - 丝条**汇聚到揭纸方向的远端**，模拟真实揭纸的物理效果
  - 丝条根部粗、远端细，叠加白色高光线增加立体感
  - 保留**撕裂边界拉丝**（lifted 和 non-lifted 之间）
  - 投影只对低强度拉起的豆子显示（高强度的已经变成丝条了）
