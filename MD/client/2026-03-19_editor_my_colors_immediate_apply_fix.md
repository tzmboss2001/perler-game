# 2026-03-19 编辑页启用我的颜色即时生效修复

## 问题
编辑图案页的色系面板中，点击 `启用我的颜色` 或在 `管理我的颜色` 弹窗里保存后，预览图不会立即变化，用户需要再额外点击应用按钮才能看到结果。

## 根因
- `useMyColors` 和 `activeCustomColorIds` 之前只更新了界面状态。
- 没有立刻触发 `processImage()` 重生成。
- 因此用户切换到“我的颜色”后，预览仍然停留在旧结果。

## 修复
- 文件：`perler-beads/src/pages/mobile/EditorPage.tsx`
- 点击 `启用/关闭我的颜色` 时，现在会立即触发重生成。
- 在 `管理我的颜色` 弹窗点击保存后，也会立即按最新选中的颜色集合重生成。
- 同时保持 `lastAppliedParamsRef` 参数同步，避免取消回滚时参数状态不完整。

## 结果
- 点击 `启用我的颜色` 后，预览图会立刻按我的颜色集合重新生成。
- 点击 `已启用` 关闭后，也会立刻恢复为普通色系结果。
- 在 `管理` 弹窗保存后，预览会立即反映新的我的颜色集合。

## 验证
- `cmd /c npm run build` 通过。
