# 2026-03-15 编辑页抠图工具重构

## 背景
用户确认不需要 `涂 / 灌 / 擦 / 取` 这类手动画图工具，编辑页应突出“方便去背景”这一条主能力，而不是像像素画软件那样暴露一组精修画笔。

## 本次调整
1. 将编辑页左侧主悬浮入口从“画笔/手动编辑”改为“抠图 / 去背景”。
2. 移除原来主界面里的 `涂 / 灌 / 擦 / 取` 主入口展示，不再作为默认编辑工具暴露。
3. 保留 `色系`、`统计` 两个悬浮入口，和新的抠图入口并列。
4. 进入背景处理模式后，新增“去背景工具”说明卡，明确告诉用户：
   - 先试一键去背景
   - 复杂背景再用智能抠图或手动微调
   - 当前只保留拼豆强相关功能
5. 修复新抠图入口的点击链路：
   - 显式使用 `type="button"`
   - 阻止默认行为和冒泡
   - 调整悬浮按钮位置，避开左上角返回按钮点击区，避免误触发返回到上传页
6. 调整 `sessionStorage.editorData` 读取逻辑，避免编辑页在局部重挂载时过早丢失兜底数据。

## 修改文件
- `perler-beads/src/pages/mobile/EditorPage.tsx`

## 验证
- 前端构建：`cmd /c npm run build` 通过
- MCP 验证通过：
  - 编辑页主界面存在 `进入去背景工具`
  - 旧的主入口 `涂 / 灌 / 擦 / 取` 不再出现在主界面
  - 点击后成功进入 `背景处理模式`
  - 新面板文案可见：
    - `去背景工具`
    - `先试一键去背景，复杂背景再用智能抠图或手动微调。`
    - `只保留拼豆强相关功能`
    - `一键去背景`
    - `智能抠图`

## 结论
编辑页工具入口现在已经从“像素画精修”重心，切换为“拼豆去背景”重心，更符合当前产品定位。
