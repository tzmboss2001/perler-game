# 导出弹窗按钮显示修复

**日期**: 2026-01-30
**类型**: Bug修复

## 问题描述

用户点击"下载"按钮打开导出弹窗后，看不到底部的"导出图片"按钮。按钮被弹窗截断，无法进行导出操作。

## 问题原因

弹窗设置了 `maxHeight: '85vh'` 和 `overflow: 'hidden'`，当弹窗内容（分辨率选项、导出选项、预览信息等）超出最大高度时，底部的导出按钮会被截断隐藏。

## 修改文件

`src/components/ExportModal.tsx`

## 修改内容

### 1. 添加内容区域和固定底部样式

```typescript
// 新增样式
content: {
  flex: 1,
  overflowY: 'auto',
  overflowX: 'hidden',
},

footer: {
  flexShrink: 0,
  padding: '16px 20px',
  paddingTop: '0',
  background: colors.bg.secondary,
},
```

### 2. 重构JSX结构

将弹窗内容分为三部分：
- **header**: 标题和关闭按钮（固定）
- **content**: 可滚动的内容区域（分辨率选项、导出选项、预览信息）
- **footer**: 固定底部的导出按钮

```tsx
<div style={styles.modal}>
  {/* 头部 - 固定 */}
  <div style={styles.header}>...</div>

  {/* 可滚动内容区域 */}
  <div style={styles.content}>
    {/* 分辨率选项 */}
    {/* 导出选项 */}
    {/* 预览信息 */}
  </div>

  {/* 固定底部导出按钮 */}
  <div style={styles.footer}>
    <button>导出图片</button>
  </div>
</div>
```

### 3. 更新按钮样式

```typescript
// 修改前
exportBtn: {
  margin: '0 20px 20px',
  // ...
},

// 修改后
exportBtn: {
  width: '100%',  // 按钮宽度由footer控制
  // ...
},
```

## 效果

- 导出弹窗内容区域可滚动
- "导出图片"按钮始终固定显示在弹窗底部
- 无论弹窗内容多长，用户都能看到并点击导出按钮
