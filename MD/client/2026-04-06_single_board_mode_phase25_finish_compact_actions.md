# 单板模式第二十五阶段：完成态动作与顶部继续收口

## 本次目标
- 继续压缩单板模式全部完成态的首屏结构。
- 进一步减少顶部与底部重复动作。
- 让完成态更像真正的收尾页，而不是仍停留在制作态。

## 实现内容
1. 单板模式在全部完成时隐藏顶部模式切换条。
2. 顶部完成入口文案从“可以直接导出、回看整图、返回编辑或分享”收成“可以直接导出图纸或查看整图”。
3. 顶部完成入口动作收口为：
   - 查看整图
   - 导出图纸
4. 顶部移除：
   - 分享作品
   - 回到编辑
   这两类动作继续保留在底部收尾任务条中。
5. 底部完成态任务条最后一个按钮从“查看整图”改为禁用的“已完成”，避免顶部和底部都重复给出整图入口。
6. 底部继续保留：
   - 导出图纸
   - 回到编辑
   - 分享作品
   - 已完成

## 影响
- 单板模式全部完成态首屏更短、更聚焦。
- 顶部和底部的收尾动作分工更明确：
  - 顶部负责主收尾入口
  - 底部负责补充动作与完成状态
- 模式切换条在全部完成态不再干扰首屏。

## 验证
- `cmd /c npm run build`
- MCP 检查 `/mobile/making` 单板模式全部完成态：
  - 顶部不再显示模式切换条
  - 顶部只显示 `查看整图 / 导出图纸`
  - 底部显示 `导出图纸 / 回到编辑 / 分享作品 / 已完成`
