# 2026-03-15 编辑页悬浮入口样式统一

## 背景
编辑页左侧的 `抠图 / 色系 / 统计` 三个悬浮入口此前存在两套视觉语言：
- 抠图：双行大按钮
- 色系/统计：小尺寸图标按钮

这会让页面层级混乱，普通用户会觉得像是临时拼接的工具条。

## 本次调整
1. 统一三枚悬浮入口的尺寸和结构。
2. 以 `抠图` 按钮为基准，让 `色系 / 统计` 去适配主入口样式。
3. `色系 / 统计` 改成和 `抠图` 一样的双行文字胶囊：
   - `色系 / 配色`
   - `统计 / 用量`
4. 统一圆角、阴影、按钮尺寸和激活态阴影强度。
5. 保留不同按钮的渐变配色，用于功能区分，但不再混用“大按钮 + 小图标按钮”两种语言。
6. 窄屏下的缩小逻辑也同步跟进，避免只有主按钮缩放、次级按钮不一致。

## 修改文件
- `perler-beads/src/pages/mobile/EditorPage.tsx`

## 验证
- 前端构建：`cmd /c npm run build` 通过
- 预期结果：
  - `抠图 / 色系 / 统计` 三个悬浮入口尺寸一致
  - 三者均为双行文字结构
  - 主次关系更清晰，但整体风格统一

## 结论
编辑页左侧悬浮工具现在已经统一成同一套 UI 语言，更符合产品级界面的完整性。
