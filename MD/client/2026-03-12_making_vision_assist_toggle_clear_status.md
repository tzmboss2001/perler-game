# 制作页视觉辅助：关闭开关时立即清理自动切板状态

## 日期
- 2026-03-12

## 目标
- 解决用户关闭 `自动轮询` 或 `自动切板` 后，界面上还可能残留“确认中 / 冷却中”状态的问题。

## 本次修改
- 文件：[BoardVisionAssistModal.tsx](/D:/work/web/perler-beads-creator/perler-beads/src/components/BoardVisionAssistModal.tsx)

### 1. 新增开关联动清理
- 增加 effect：
  - 当以下任一条件成立时，立即清理自动切板状态
    - 弹层不可见
    - `自动轮询` 关闭
    - `自动切板` 关闭
    - 当前不是多板场景

### 2. 同时清理候选板状态
- 关闭相关开关时，不只清文案：
  - 也会把 `autoSwitchCandidateRef` 一起清掉
- 这样重新开启后，不会沿用上一次的候选板确认进度

## 验证

### 本地构建
- 命令：`cmd /c npm run build`
- 结果：通过

### 当前验证边界
- MCP 当前无摄像头权限，不能真实驱动“确认中 / 冷却中”状态后再切开关。
- 但本轮逻辑非常直接，且没有影响：
  - 视觉辅助弹层打开
  - 多板入口显示
  - 手动切板提示

## 结果
- 用户关闭相关开关后，自动切板状态不会再等下一轮轮询才消失。
- 这一步主要提升了状态和开关的一致性。
