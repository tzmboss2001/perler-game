# 编辑页色系设置与珠子统计改为悬浮入口

日期：2026-03-09
范围：客户端

## 目标

优化编辑图案页面的空间布局，把原本占据下方内容区的“色系设置”“珠子统计”收纳到预览区悬浮按钮中，给主流程和滑杆留出更多空间。

## 处理

- 保留原有画笔悬浮按钮
- 在其下新增两个悬浮入口：
  - `色系`
  - `统计`
- 点击后在预览区旁展开对应面板
- 下方内容区移除原来的大块色系卡片和统计卡片
- 保留原有功能：
  - 色系档位切换
  - 我的颜色管理
  - 珠子统计
  - 换色、排除、还原、合并

## 结果

- 编辑页层级更清晰
- 预览相关工具集中在预览区附近
- 下方内容区更短，主流程按钮更容易看到

- `perler-beads/src/pages/mobile/EditorPage.tsx`
