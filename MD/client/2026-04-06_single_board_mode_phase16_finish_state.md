# 2026-04-06 单板模式第十六阶段：收尾态与顶部瘦身

## 本次目标
- 继续压缩顶部结构
- 让全部完成后的动作更明确
- 让单板模式控制区更像收尾工作台

## 本次完成
1. 全部完成状态新增双动作收尾入口
- 顶部完成入口不再只剩一个 `导出图纸`。
- 现在改成：
  - `查看整图`
  - `导出图纸`
- 这样用户在完成全部板后，可以直接切回传统模式看整张成品，也可以直接进入导出。

2. 全部完成后停止渲染过程态控件
- 在单板模式全部完成状态下，不再继续显示：
  - 自动切板策略
  - 未完成板列表
  - 当前板工作流卡片
  - 总览缩略图
  - 板列表 / 紧凑板导航
- 这样顶部结构从“制作中”切换成真正的“收尾态”。

3. 底部任务条在全部完成时改成收尾动作
- 底部三枚次级按钮在全部完成时不再继续保留板间导航语义。
- 改成：
  - `查看整图`
  - `导出图纸`
  - `已完成`
- 让底部条也从“做板”切换成“收尾”。
