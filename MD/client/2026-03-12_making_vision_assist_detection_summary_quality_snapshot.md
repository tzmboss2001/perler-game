# 制作页视觉辅助：历史识别摘要显示环境快照

## 本次目标
- 让用户重新打开视觉辅助时，不只看到上次识别进度，还能看到当时的识别环境状态。
- 帮助用户判断旧结果是不是在偏暗、偏色、反光等环境下得到的。

## 改动内容
1. 在 `VisionAssistDetectionSummary` 中新增：
   - `qualityLevel`
   - `qualityIssues`
2. 在生成历史识别摘要时，把识别结果里的环境等级和问题列表一起写入摘要。
3. 在 `上次识别摘要` 中新增展示：
   - `上次环境：环境良好 / 可识别但需注意 / 环境较差`
   - 最多 3 条环境问题标签，例如：
     - `光线略暗`
     - `环境有轻微偏色`
4. 为历史环境状态补充 `qualityChipGood` 样式，保证和现有环境标签视觉一致。

## MCP 验证
- 手动写入一份带以下内容的历史摘要：
  - `qualityLevel = warning`
  - `qualityIssues = [光线略暗, 环境有轻微偏色]`
- 重新打开视觉辅助后，验证结果：
  - 出现 `上次环境：可识别但需注意`
  - 出现 `光线略暗`
  - 出现 `环境有轻微偏色`
