# 2026-03-31 分页打印版图纸可读性增强

## 背景
高清导出和分页打印版是当前最适合承载广告的高价值动作，但分页导出原先的页头、坐标尺和边距过于粗糙：左侧坐标贴边容易被裁掉，页头信息挤成一行，不够像真正可打印的图纸页面。

## 本次修改
1. 优化分页导出的页面结构，增加左侧坐标边距和底部坐标边距。
2. 提升分页页头高度，拆成两行信息：
   - 第一行显示打印版图纸与页码
   - 第二行显示板区、板规格、板内列范围与行范围
3. 将分页导出中的网格线、5x5/10x10 分区线全部按新的图案偏移重新绘制，确保与坐标尺对齐。
4. 将分页导出的横纵坐标尺绘制到真实边距区域，不再出现负坐标贴边绘制。
5. 为每一页图案区域增加外围边框，让打印版成品感更强。

## 涉及文件
- `perler-beads/src/services/colorMatchService.ts`

## 结果
分页打印版现在更像真正的可打印图纸：页头信息更清晰，坐标尺不再贴边被裁，图案区域边界更明确，整体更适合作为“打印版/分页版图纸”这一类广告解锁结果。
