# 开始制作需要登录验证

**日期**: 2026-01-31
**类型**: 功能优化

## 需求描述

用户点击"开始制作"时：
1. 如果未登录，弹出登录弹窗提示用户登录
2. 用户登录成功后，自动弹出保存方案弹窗继续流程
3. 已登录用户直接显示保存方案弹窗

**之前的问题**：
- 游客可以用 device_id 保存作品（不安全，换设备丢失）
- 保存失败时提示"网络异常，但可以继续制作"，让用户困惑

### 前端 - EditorPage.tsx

```typescript
// 导入
import LoginModal from '../../components/LoginModal';
import { useUserStore } from '../../store/userStore';

// 获取登录状态
const { isLoggedIn, initUser } = useUserStore();

// 添加登录弹窗状态
const [showLoginModal, setShowLoginModal] = useState(false);

// 修改"开始制作"按钮点击事件
const handleStartMakingClick = (e?: React.MouseEvent) => {
  if (!beadData) return;
  if (e?.shiftKey) {
    // 测试模式跳过保存
    navigate('/mobile/making', { state: { beadData, colorCount } });
    return;
  }
  // 检查是否已登录
  if (!isLoggedIn) {
    setShowLoginModal(true);
    return;
  }
  setShowSaveModal(true);
};

// 登录成功后的回调
const handleLoginSuccess = () => {
  setShowLoginModal(false);
  setShowSaveModal(true); // 自动打开保存弹窗
};
```

### 后端 - router/project.go

```go
// 公开路由（无需登录）
func InitProjectRouter(Router *gin.RouterGroup) {
  projectRouter.GET("list", projectApi.GetList)
  projectRouter.GET(":id", projectApi.GetById)
  projectRouter.PUT(":id/progress", projectApi.UpdateProgress)
}

// 私有路由（需要登录）
func InitProjectPrivateRouter(Router *gin.RouterGroup) {
  projectRouter.POST("create", projectApi.Create)  // 创建需要登录
  projectRouter.PUT(":id", projectApi.Update)      // 更新需要登录
  projectRouter.DELETE(":id", projectApi.Delete)   // 删除需要登录
}
```

## 效果

1. 游客点击"开始制作" → 弹出登录弹窗
2. 用户完成登录 → 自动弹出保存方案弹窗
3. 已登录用户点击"开始制作" → 直接弹出保存方案弹窗
4. 后端 API 强制要求登录，防止绕过前端直接调用

## 用户体验

- 登录弹窗不离开编辑页面，数据不丢失
- 登录成功后无缝继续保存流程
- 作品保存到云端，换设备也能找回
