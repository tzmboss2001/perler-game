# 颜色风格控件文案与快捷档位优化

日期：2026-03-10
文件：`perler-beads/src/pages/mobile/EditorPage.tsx`

## 问题
- “鲜艳度”是技术感较强的词，用户不容易理解它对最终拼豆图的影响。
- 只有滑杆时，用户不知道应该停在哪个位置才合适。

## 处理
1. 将控件标题从 `鲜艳度` 改为 `颜色风格`。
2. 滑杆两端文案改为：
   - `更接近原图`
   - `更鲜亮`
3. 新增三个快捷档位：
   - `原图` = 0
   - `推荐` = 8
   - `鲜亮` = 16
4. 新增 `handleRegenerateWithSaturation`，点击快捷档位时直接按目标值重新生成，避免异步状态导致沿用旧参数。
5. 保留原来的滑杆松手后再重生成逻辑。

## 效果
- 用户不需要理解“鲜艳度”这个词，也能知道自己是在调“更还原”还是“更讨喜”。
- 常见选择可以直接点，不需要来回拖滑杆试探。
