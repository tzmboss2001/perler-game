# 2026-03-29 导出图纸坐标尺同步现实豆板坐标系

## 问题
- 制作模式点击坐标已经改成按现实豆板显示：板号 + 板内列/行。
- 但导出图纸的外围横纵坐标尺至少在分页导出链路里仍然使用全局连续编号。
- 单页导出历史上也没有真正把外围坐标尺画出来，`显示坐标刻度` 会错误传到色号参数上。

## 本次修改
1. 在 `colorMatchService.ts` 中新增导出坐标换算辅助：
   - 复用现实豆板基准尺寸。
   - 横向、纵向坐标都按每块板内重新从 `1` 开始。
2. 单页导出：
   - 为图案左侧和底部增加坐标尺留白。
   - 开启 `显示坐标刻度` 时绘制板内横纵坐标。
3. 带珠子清单的单页导出：
   - 同步增加左侧和底部坐标尺。
   - 清单区域继续保持在图案右侧。
4. 分页导出：
   - 页头改成现实豆板口径的板区与板内列/行范围。
   - 页内横纵坐标尺改成板内重新从 `1` 开始，不再跨板连续编号。
5. `ExportModal.tsx`：
   - 修正单页导出调用参数。
   - `显示坐标刻度` 现在会正确传入导出渲染函数，不再误传给色号参数。

## 影响文件
- `perler-beads/src/services/colorMatchService.ts`
- `perler-beads/src/components/ExportModal.tsx`

## 验证
- `cmd /c npm run build` 通过。

## 结果
- 制作模式坐标与导出图纸外围坐标尺现在统一成现实豆板口径：
  - 横向、纵向都会在每块板里重新从 `1` 开始。
  - 不再出现跨板继续编号成 `105、106` 这类全局连续坐标。
