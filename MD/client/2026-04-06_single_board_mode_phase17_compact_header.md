# 2026-04-06 单板模式第十七阶段：顶部与状态提示瘦身

## 本次目标
- 继续压缩单板模式顶部结构
- 继续收紧单板模式工具区
- 减少首屏无操作时的状态提示占位

## 本次完成
1. 模式切换条继续减薄
- 单板模式下模式切换条缩小了上下内边距和按钮高度。
- 首屏顶部比上一阶段更薄，给当前板工作区让出了更多垂直空间。

2. 单板模式默认隐藏状态提示
- 之前单板模式即使未选中，也会常驻显示 `点格选区块 / 点格选颜色` 提示。
- 现在改成：
  - 未选中时默认不显示顶部状态提示
  - 只有真正选中区块/颜色，或打开设置时才显示
- 这样首屏不会再被悬浮提示条占位。

3. 单板模式底部空状态文案继续收短
- 单板模式空状态文案改成：
  - 缩小时：`点格选区块`
  - 放大时：`点格看坐标`
- 更符合单板制作语境。

4. 单板模式工具按钮继续收紧
- `图纸 / 辅助` 工具按钮在紧凑场景下进一步缩窄。
- 减少工具区对首屏主工作区的挤压。
