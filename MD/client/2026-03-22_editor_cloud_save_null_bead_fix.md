# 编辑页云端保存透明格异常修复

日期：2026-03-22

## 问题
用户在编辑页去背景后点击“保存并开始制作”，会出现“云端保存异常，已自动转存到本地方案”的提示。

## 根因
- 去背景后，`beadData.beads` 中会包含透明格 `null`
- 云端保存分支在构造 `projectApi.create()` 请求体时，直接读取了 `b.id / b.hex`
- 本地保存分支有判空，云端保存分支没有
- 因此透明格会把云端保存分支直接打进 `catch`

## 处理
1. 在 `EditorPage.tsx` 中新增 `serializeBeadDataForSave()`
2. 云端保存 `projectApi.create()` 改为复用统一序列化结果
3. 本地保存 `saveToLocal()` 也改为复用同一套序列化逻辑
4. 透明格统一序列化为占位 bead 对象，避免前后链路不一致

## 结果
- 去背景后的方案也可以正常走云端保存
- 不会再因为透明格 `null` 触发“云端保存异常”
- 云端与本地保存的数据结构保持一致
