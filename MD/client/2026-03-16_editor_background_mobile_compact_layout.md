# 编辑页背景处理模式移动端紧凑布局优化

- 日期：2026-03-16
- 影响范围：客户端编辑页背景处理模式
- 文件：`perler-beads/src/pages/mobile/EditorPage.tsx`

## 问题
背景处理模式里按钮过长、占高过大，压缩了手机上本就有限的预览区。底部还保留了“恢复上次去背景”这种长文案动作，和通用编辑里的撤销/重做能力重复。

## 调整
1. 顶部主操作按钮改成更短的双行紧凑按钮：
   - `一键 / 去背景`
   - `AI / 智能抠图`
2. 说明卡和提示区压缩高度，减少文案占位。
3. 底部操作区改成更紧凑的移动端工具条：
   - `回退`
   - `前进`
   - `清空选择`
   - `应用去背景`
   - `返回编辑`
4. 去掉了背景模式里的“恢复上次去背景”长文案按钮展示，统一通过回退/前进处理编辑过程。

## 结果
- 背景处理模式把更多垂直空间还给预览区。
- 交互结构更接近移动端文档编辑：回退/前进统一处理历史步骤。
- 用户不需要理解单独的“恢复上次去背景”逻辑。
