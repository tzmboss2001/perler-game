# 单板模式第二十一阶段：收尾入口去重

## 本次目标
- 继续压缩单板模式在“全部板已完成”时的重复动作入口。
- 保留顶部和底部的收尾动作，同时减少工具区中的重复按钮。
- 收掉全部完成状态下无意义的状态提示文案。

## 实现内容
1. 全部完成时隐藏工具区中的 `收尾` 与 `图纸`
- 单板模式在 `singleBoardAllDone` 状态下，右侧工具区现在只保留：
  - `辅助`
- 不再继续显示：
  - `收尾`
  - `图纸`
- 顶部和底部仍然保留收尾动作，不影响导出和查看整图。

2. 全部完成时隐藏顶部状态提示
- `shouldShowStatusHint` 现在在单板模式且 `singleBoardAllDone` 时默认关闭。
- 不再继续显示区块选中提示，减少收尾态噪音。

3. 全部完成时隐藏“再次点击可取消选中”提示
- 底部过程态的小提示在全部完成后不再显示。

4. 底部收尾态保留三项结构
- `导出图纸`
- `查看整图`
- `已完成`
- 继续保留当前板元信息和完成状态文本。
