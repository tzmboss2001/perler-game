# 017 - 修复熨烫后豆子间隙问题

## 日期
2026-02-12

## 问题描述
用户反馈：熨烫了很久，相邻豆子之间仍然存在间隙。按道理说，充分熨烫后相邻豆子应该完全融合无间隙。

## 根因分析

**文件**: `src/components/ResultCanvas/ContinuousRenderer.ts`

旧代码在 fusion 0.7~0.95 范围使用的 rectSize 公式：
```ts
rectSize = BEAD_R * 2 + (CELL - BEAD_R * 2) * localFusion
```

以 CELL=18, BEAD_R=7.2 为例：
- fusion=0.9 时: rectSize = 14.4 + 3.6*0.9 = 17.64 < CELL(18)
- 相邻豆子之间始终有 ~1.36px 间隙

完全无间隙方块的阈值是 `localFusion > 0.95`，但由于物理公式中 localFusion = fusion * (0.3 + localHeat * 0.7)，局部热量需要极高才能达到 0.95，实际很难触发。

## 修复方案

### 修改 ContinuousRenderer.ts

1. **降低完全融合阈值**: `localFusion > 0.95` → `localFusion > 0.85`
2. **修正 0.7~0.85 范围 rectSize**: `rectSize = CELL + t * 1`（CELL → CELL+1，确保填满格子）
3. **修正 0.3~0.7 范围公式**: `rectSize = BEAD_R * 2 + (CELL + 1 - BEAD_R * 2) * t`（在 fusion=0.7 时接近 CELL）
4. **加速圆角消失**: `cornerRadius = BEAD_R * (1 - localFusion) * 2`

### 修改前后对比

| fusion 值 | 旧代码 rectSize | 新代码 rectSize | 间隙 |
|-----------|----------------|----------------|------|
| 0.7 | 16.92 | CELL(18) | 旧:有 新:无 |
| 0.8 | 17.28 | CELL+0.67 | 旧:有 新:无 |
| 0.85 | 17.46 | CELL+1(全方块) | 旧:有 新:无 |
| 0.9 | 17.64 | CELL+1(全方块) | 旧:有 新:无 |
| 0.95 | 17.82 | CELL+1(全方块) | 旧:有 新:无 |
