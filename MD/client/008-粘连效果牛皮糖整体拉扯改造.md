# 008 - 粘连效果"牛皮糖"整体拉扯改造

## 日期
2026-02-12

## 改动概述
将粘连效果从"一堆分散小块各自飞散"改造为"一整块融合的片材被整体拉扯"，模拟真实的牛皮糖/融化塑料揭开效果。

## 改动文件

### 1. `src/components/ResultCanvas/ContinuousRenderer.ts`（主要）

#### A. 预计算阶段
- **perpNoise 降低**：从 `CELL * 0.6` 降为 `CELL * 0.12`，垂直方向只有微弱波动
- **liftScale 移除**：固定为 1，融合的片材不再缩小

#### B. 第0层：钉板露出
- 显示阈值从 `stickyIntensity < 0.1` 提高到 `< 0.3`

#### C. 第1层：拉丝效果（核心改造）
- **移除** per-bead strand 循环（每颗豆子生成3~6条丝条）
- **新增** 撕裂边界拉丝：只在相邻豆子位移差 > CELL*0.3 的边界处生成丝条
- 丝条根部更粗：从 `CELL * 0.15` 提高到 `CELL * 0.3`
- 使用两端豆子颜色的平均值
- 添加了 `averageColor` 辅助函数

#### D. 第1.5层：投影
- 从单个豆子投影改为整体连续投影
- 使用重叠方块形成连续阴影
- 阴影沿拉扯方向偏移

#### E. 第2层：豆子绘制（核心改造）
- **粘连模式**：强制所有豆子用 CELL+3px 的重叠方块绘制，消除间隙
- **不缩放**：移除 liftScale 的 ctx.scale 调用
- **透明度**：stickyIntensity < 0.9 完全不透明，> 0.9 才轻微降低
- **非粘连模式**：保持原有的 fusion 渐变逻辑不变

### 2. `src/components/ResultCanvas/ResultCanvas.tsx`（次要）

#### drawSticky 离散渲染函数
- **移除** per-bead 的 rotate + scale 变换
- **降低 perpNoise**：从 `CELL * 0.4` 降为 `CELL * 0.12`
- **第1层改为撕裂边界拉丝**：与 ContinuousRenderer 逻辑一致
- **第2层重叠方块**：每边多1.5px，无 rotate/scale
- **透明度**：只有 intensity > 0.9 才轻微降低

## 核心物理原理
1. 拼豆在高温下融合成一整块连续的塑料片（无缝，无边界）
2. 这块塑料粘在烫纸上
3. 揭开烫纸时，整块塑料片被一起掀起，像牛皮糖一样
4. 靠近固定点的部分粗而完整，越往远处拉越细，最终形成丝条

## 迭代改进（测试后修复）

### 问题1：per-bead 噪声导致间隙
- **原因**：`noise = seededRandom * 0.3` 使相邻豆子 stickyIntensity 差异大，位移不连续
- **修复**：noise 从 0.3 降到 0.05（两个文件同步修改）

### 问题2：固定 overlap 无法覆盖大位移差
- **原因**：高强度区域位移差远大于 1.5px 的 overlap
- **修复**：动态 overlap = `1.5 + stickyIntensity * CELL * 0.3`

### 问题3：相邻豆子位移梯度不连续（核心修复）
- **原因**：每颗豆子独立计算 intensity，没有考虑片材连续性约束
- **修复**：添加 **3次平滑 pass**，每次迭代将 intensity 与四邻域加权平均
  - 自身权重 x2，邻居权重 x1
  - 3次迭代后位移场变得非常平滑
  - ContinuousRenderer.ts 和 ResultCanvas.tsx 均已添加
