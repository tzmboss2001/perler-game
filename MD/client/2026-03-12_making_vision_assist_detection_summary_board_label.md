# 制作页视觉辅助：历史识别摘要显示板号

## 本次目标
- 在多板作品里，恢复历史识别摘要时直接告诉用户这份结果属于哪一块板。
- 避免用户看到历史摘要却不知道它对应板1还是板2。

## 改动内容
1. 在 `VisionAssistDetectionSummary` 中新增 `boardLabel` 字段。
2. 在生成历史识别摘要时，把当前板的 `label` 一起写入摘要。
3. 在 `上次识别摘要` 卡片中新增显示：
   - `识别板位：板X`
4. 保持原有的：
   - 进度
   - 时间
   - 当前优先颜色
   - 下一步建议
   - 错放建议
   不受影响。

## MCP 验证
- 手动写入一份带 `boardLabel = 板2` 的历史摘要后重新打开视觉辅助
- 验证结果：
  - 出现 `上次识别摘要`
  - 出现 `识别板位：板2`
  - 其他历史摘要信息仍正常显示
