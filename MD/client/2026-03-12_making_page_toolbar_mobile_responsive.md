# 制作页顶部工具栏移动端响应式收口

## 本次目标
- 解决制作页顶部缩放栏和功能按钮在手机窄屏下互相挤压、按钮被挤出可视区的问题。
- 让小屏设备上仍能完整看到 `缩放 / 适宽 / 下载 / 设置` 这些高频操作。

## 本次修改
- 文件：`perler-beads/src/pages/mobile/MakingPage.tsx`
- 新增 `viewportWidth` 状态，并在窗口尺寸变化时同步更新。
- 顶部浮动工具栏根据屏幕宽度切换布局：
  - 常规宽度：保持单行布局
  - `<= 420px`：切换为上下两行，缩放区在上，功能按钮在下
  - `<= 360px`：进一步收紧滑杆、倍率标签和适宽按钮的占宽
- 状态提示条会在工具栏换行后自动下移，避免与顶部工具栏叠在一起。

## 结果
- 手机窄屏下，顶部工具栏不再强行单行塞满。
- 下载和设置按钮不会再因为宽度不足被裁掉。
- 缩放条、百分比、适宽按钮仍然保留在首屏可操作范围内。

## 验证
- 执行：`cmd /c npm run build`
- 结果：构建通过
- MCP 验证：
  - 以窄屏视口重新加载制作页
  - 语义快照中仍可看到 `适宽 / 下载图纸 / 设置`
  - 截图确认顶部工具栏已分成两行，按钮完整可见
