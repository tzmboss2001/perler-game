# 智能登录功能（自动注册）

**日期**: 2026-01-31
**类型**: 新功能

## 需求描述

用户在登录页面输入邮箱和密码时，如果邮箱之前没有注册过，系统自动帮用户完成注册并登录。这样可以：
1. 简化用户操作流程，无需区分登录/注册
2. 降低用户流失率
3. 类似主流App的"一键登录"体验

### 后端 - 新增 API

```
POST /api/v1/auth/smart-login
```

请求：
```json
{
  "email": "user@example.com",
  "password": "123456"
}
```

响应：
```json
{
  "code": 0,
  "msg": "success",
  "data": {
    "token": "xxx",
    "user_info": {...},
    "is_new_user": true  // 标识是否为新注册用户
```

## 用户流程

### 老用户
1. 输入邮箱和密码 → 点击"登录/注册"
2. 验证密码成功 → 直接登录

### 新用户
1. 输入邮箱和密码 → 点击"登录/注册"
2. 系统自动创建账号（用户名=邮箱前缀）
3. 显示"欢迎加入！账号已自动创建"
4. 1秒后自动进入已登录状态

## 效果

- 用户无需思考是登录还是注册
- 界面更简洁，只有邮箱和密码两个输入框
- 一键完成登录或注册+登录
- 新用户有明确的欢迎提示
