# 创建页UI全面优化 — 两阶段布局合理分配

**日期**: 2026-02-27
**类型**: UI优化
**影响文件**: 1个

## 问题

1. 创建页颜色数量选择（3×2卡片网格）占用太多空间
2. 上传图片前，页面下半部分空空如也
3. 上传图片后（预览阶段），下半部分也空

## 修改

### CreatePage.tsx

#### 上传阶段（选图前）
- **布局**: 内容整体垂直居中（`uploadPhase` flex wrapper + `justifyContent: center`）
- **选图建议卡片**: 新增4条实用建议（背景简单、裁剪面部、卡通最佳、高对比度）
- **容器**: `minHeight: calc(100vh - 65px)` 确保填满视口

#### 预览阶段（选图后）
- **预览图**: 从 `aspectRatio: 1`(固定正方形) → `flex: 1` + `minHeight: 160px` + `maxHeight: 50vh`，自适应填充可用空间
- **颜色选择**: 3×2卡片网格 → 一行6个紧凑标签（pill），选中项描述显示在标题行
- **操作按钮/色板**: 间距压缩
- **小贴士**: 单行居中提示

#### 全局
- 内容区 `display: flex, flexDirection: column` 支持弹性布局
- 移除 `Lightbulb` 图标导入

### 屏幕适配

| 设备 | 上传阶段 | 预览阶段 |
|------|---------|---------|
| iPhone SE (667px) | 内容刚好填满 | 预览图~320px，无需滚动 |
| iPhone 14 (844px) | 内容居中，上下均匀留白 | 预览图~420px(50vh)，布局舒适 |

### 验证
- `npm run build` 编译通过
- Chrome MCP 截图验证 iPhone SE + iPhone 14 两种尺寸
