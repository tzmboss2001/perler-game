# 2026-03-27 背景处理模式接入编辑页同款外部缩放控件

## 背景
背景处理模式之前仍依赖 `InteractiveCanvas` 内置的小型缩放条，和编辑图案页主预览区不是同一套交互，用户在背景处理模式里不容易理解如何放大缩小，也不容易把它当成和编辑页一致的预览操作。

## 本次修改
1. 背景处理模式中的 `InteractiveCanvas` 改为 `showControls={false}`，隐藏组件内部缩放条。
2. 在背景处理模式预览区下方新增和编辑页同款的外部缩放控件：
   - `预览缩放`
   - 百分比显示
   - `- / 滑杆 / + / 适配 / 1:1`
3. 背景处理模式同步接入 `onScaleChange={setPreviewZoom}`，复用编辑页已有缩放状态展示。
4. 新增 `bgModeZoomPanel` 样式，使背景处理模式的预览缩放交互和编辑页保持同一视觉和操作语义。

## 目的
让背景处理模式的预览缩放方式与编辑页保持一致，用户不需要再适应一套不同的缩放 UI，就能直接放大缩小图片并配合移动视图做精细选格。
