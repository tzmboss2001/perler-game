# 2026-03-06 制作页缩放步进优化（从50%改为可连续调节）

## 问题
- 缩放按钮一次变化 50%（±0.5）过于粗糙，用户难以精确调整。

## 改动
- 文件: `perler-beads/src/pages/mobile/MakingPage.tsx`
- 新增常量:
  - `ZOOM_STEP = 0.1`（按钮每次微调 10%）
- 新增缩放滑杆:
  - `input[type=range]`
  - 范围 `0.5 ~ 6`
  - 步进 `0.05`
- 滑杆与按钮统一走 `applyScaleAtPoint()`，保持缩放中心和边界逻辑一致。

## 效果
- 用户可自由细调倍率，不再被 50% 步进限制。
- 缩放体验更平滑，真机操作更可控。

## 验证
- `npm run build` 通过。
