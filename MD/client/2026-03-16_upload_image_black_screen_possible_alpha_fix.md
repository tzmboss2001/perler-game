# 2026-03-16 上传图片黑屏高概率链路修复

## 问题
用户反馈点击上传图片后出现黑屏。当前本地未稳定复现整页 React 崩溃，但排查到图片优化链路会把超大图统一转成 JPEG。

对于带透明通道的 PNG，如果直接导出 JPEG，透明区域会被浏览器压成黑底，用户视觉上会误认为“黑屏”。

## 修复
- 文件：`perler-beads/src/services/imageOptimizationService.ts`
- 在大图优化阶段，画布导出 JPEG 前先铺白底，再绘制原图。
- 这样透明区域会转成白底，不会变成整片黑底。

## 影响
- 仅影响大于 10MB、需要走自动优化的大图上传链路。
- 普通 JPG/PNG 上传逻辑不变。

## 验证
- `cmd /c npm run build` 通过。
