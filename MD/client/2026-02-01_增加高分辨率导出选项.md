# 增加高分辨率导出选项

**日期**: 2026-02-01
**类型**: 功能增强

## 需求描述

用户在预览界面可以放大查看图案细节，放大后看到的分辨率很高。但原来的导出选项最高只有"高清"(40px/格)，当用户放大预览时，导出的图片清晰度可能不如预览。

## 修改文件

- `src/components/ExportModal.tsx`

## 修改内容

### 新增导出选项

| 选项 | cellSize | 29×29图案尺寸 | 用途 |
|------|----------|---------------|------|
| 小图 | 10px | 290×290px | 快速分享 |
| 标准 | 20px | 580×580px | 日常使用 |
| **高清** | 40px | 1160×1160px | 适合打印 (推荐) |
| **超高清** | 80px | 2320×2320px | 高质量打印 |
| **极清** | 100px | 2900×2900px | 专业海报 |

### 代码变更

```typescript
// 新增两个高分辨率选项
{
  id: 'ultra',
  label: '超高清',
  description: `${patternWidth * 80}×${patternHeight * 80}px · 高质量打印`,
  cellSize: 80,
  icon: FileImage,
  color: colors.bead.pink,
},
{
  id: 'max',
  label: '极清',
  description: `${patternWidth * 100}×${patternHeight * 100}px · 专业海报`,
  cellSize: 100,
  icon: FileImage,
  color: colors.bead.orange,
},

// 默认选项改为"高清"
const [selectedOption, setSelectedOption] = useState<string>('hd');
```

## 效果

- 用户可以选择更高分辨率的导出
- "高清"成为推荐选项（原来是"标准"）
- 导出的图纸清晰度可以超过预览界面
- 支持专业打印需求（海报、大幅面打印）
