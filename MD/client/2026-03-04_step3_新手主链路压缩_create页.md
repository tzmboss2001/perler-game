# 2026-03-04 第3项优化：新手主链路压缩（Create 页）

## 问题
- 创建页需要用户先理解较多参数（颜色数量、自定义色板）再进入编辑器，新手第一步决策负担偏高。
- 页面存在多处可见乱码文案，影响信任感与可用性。

## 本次改动
1. 重构 `CreatePage`
- 文件：`perler-beads/src/pages/mobile/CreatePage.tsx`
- 清理本页所有可见乱码文案，统一为正常中文。
- 新增主入口按钮：`快速开始（推荐）`。
- 新增“高级设置”折叠区：
  - 默认收起，不打断新手主流程。
  - 展开后可调整颜色数量、是否仅用“我的颜色”。
- 保留原有上传、拍照、裁剪、图片复杂度分析能力。

2. 流程调整
- 快速路径：上传/裁剪 -> 一键快速开始 -> 进入编辑页。
- 高级路径：上传/裁剪 -> 打开高级设置 -> 按高级设置生成 -> 进入编辑页。

## 修复前后（通俗版）
- 修复前：你一上来就要看懂一堆设置，像先填表再办事。
- 修复后：先给你一个“大按钮直接开始”，高级项放到后面再看，像先开车上路，细调再说。
