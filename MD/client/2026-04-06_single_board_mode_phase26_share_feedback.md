# 单板模式第二十六阶段：完成态分享反馈与工具区继续压缩

## 本次目标
- 继续压缩单板模式全部完成态的缩放区和工具区占位。
- 让“分享作品”不只依赖 toast，而是在页面内给出明确反馈。

## 实现内容
1. 新增 `shareFeedback` 状态，记录完成态分享的结果：
   - `shared`：已打开系统分享
   - `copied`：已复制分享文案
   - `unsupported`：当前环境不支持直接分享
2. 在全部完成入口卡片内增加页面内反馈文案，分享完成后会直接显示结果。
3. 单板模式全部完成态下，继续收紧缩放区：
   - 更小的 padding
   - 更小的 gap
   - 更小的缩放百分比宽度和字号
4. 单板模式全部完成态下，继续收紧工具区：
   - `辅助` 按钮改用更紧凑尺寸
   - `适板` 按钮同步减小尺寸

## 影响
- 分享动作不再只依赖 toast，用户可以在页面顶部直接看到结果反馈。
- 全部完成态的缩放区和工具区占位继续下降，首屏更像收尾页。

## 验证
- `cmd /c npm run build`
- MCP 在单板模式全部完成态点击“分享作品”后：
  - 页面顶部出现“已打开系统分享”或“已复制分享文案”之类的反馈文案
  - 首屏仍保持顶部精简收尾入口与底部收尾动作结构
