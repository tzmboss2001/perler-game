# 游客登录后恢复保存并开始制作链路（补强）
- 在登录页回跳时透传 resumeStartMaking 状态，避免仅依赖会话草稿导致自动续做不稳定。
- 编辑页恢复逻辑现采用“双保险”：
  1. 登录前保存 editorResumeDraft，会话中保留当前 beadData 和待继续动作。
  2. 登录成功回到编辑页时，路由 state 也会携带 resumeStartMaking 标记。
- 编辑页回到登录前状态后，会自动弹出“保存方案”弹层，用户无需再次点击“保存并开始制作”。
- MCP 复测覆盖了两种场景：
  1. 游客登录后直接自动弹出保存方案。
  2. 登录前先把宽度改到 208，登录回来后宽度仍保持 208，不会退回初始状态。
