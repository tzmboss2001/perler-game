# 制作页视觉辅助弹层移动端响应式收口

## 本次目标
- 解决视觉辅助弹层在手机窄屏下双栏强撑导致的信息截断、挤压和按钮难点的问题。
- 让视觉辅助在移动端优先保证信息完整显示，其次再考虑桌面双栏效率。

## 本次修改
- 文件：`perler-beads/src/components/BoardVisionAssistModal.tsx`
- 新增 `viewportWidth` 状态，在弹层打开时监听窗口尺寸变化。
- 根据屏幕宽度增加两档布局：
  - `<= 920px`：双栏切为单栏
  - `<= 560px`：进一步压缩内边距、标题字号，并让操作按钮支持半宽/整宽排列
- 调整了以下区域的小屏样式：
  - 弹层外边距与顶部对齐方式
  - 头部标题和副标题换行
  - 主体区从固定双栏改为手机单栏
  - 操作按钮支持换行，不再被固定最小宽度挤爆
  - 上手进度标题区允许换行
  - 元信息卡片在窄屏下改为单列
  - 当前引导、历史摘要、颜色列表在窄屏下支持更自然的换行和单列布局

## 结果
- 在手机宽度下，视觉辅助不再强制右栏最小 320px 挤压整体内容。
- 关键说明、历史摘要、颜色列表和按钮区都能完整显示，不再依赖横向截断。

## 验证
- 执行：`cmd /c npm run build`
- 结果：构建通过
- MCP 验证：
  - 以 `390 x 844` 视口打开本地制作页视觉辅助
  - 已确认弹层内容能完整出现在窄屏快照中
  - 标题、步骤卡、元信息卡、历史摘要和清除按钮均可见
