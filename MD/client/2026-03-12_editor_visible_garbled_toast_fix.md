# 2026-03-12 编辑页可见乱码提示修复

## 问题
- 编辑图案页保存方案时，在没有可保存图案数据的情况下，会弹出乱码 toast。
- 该问题属于用户可见文案错误，会直接影响理解。

## 处理
- 修复 `EditorPage.tsx` 中保存前校验失败的错误提示文案。
- 将乱码提示改为：`没有可保存的图案数据`。

## 范围
- 客户端
- 文件：`perler-beads/src/pages/mobile/EditorPage.tsx`

## 验证
- 运行 `npm run build`，确认前端构建通过。
- 复查 `EditorPage.tsx` 中 toast / alert / confirm 相关用户可见文案，本轮未发现第二处确定会显示到界面的乱码。

## 说明
- 当前文件中仍存在大量乱码注释，但这些不属于用户可见内容。
- 为避免扩大修改面和引入回归，本轮未清理注释层乱码。
