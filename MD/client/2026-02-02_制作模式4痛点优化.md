# 制作模式4痛点优化

**日期**: 2026-02-02
**类型**: 功能重构

## 需求描述

解决用户在制作拼豆作品时的4个主要痛点：
1. 找珠子 - 从一堆珠子中找到正确颜色
2. 放珠子 - 按图纸准确放置，不放错位置
3. 跟踪进度 - 做到一半被打断，回来不知道做到哪了
4. 色号缺货 - 某些颜色买不到，需要替代

- `src/components/CoordinateTooltip.tsx` - 坐标提示框

## 功能实现

### 1. 智能点击交互（找珠子）

**根据缩放级别自动切换点击行为**：
- 缩小状态（< 250%）点击 → 选中区块（10x10大网格）
- 放大状态（≥ 250%）点击 → 高亮区块内所有同色格子

**代码核心**：
```typescript
const ZOOM_THRESHOLD = 2.5; // 缩放阈值

if (scale < ZOOM_THRESHOLD) {
  // 选中区块
  setSelection({ type: 'block', blockX, blockY });
} else {
  // 选中颜色
  setSelection({ type: 'color', blockX, blockY, colorHex, colorId });
}
```

### 2. 坐标提示（放珠子）

**双重提示机制**：
- 语音提示：使用 Web Speech API 朗读坐标
- 视觉提示：悬浮坐标提示框，优先左上方显示，1.5秒后淡出

**代码核心**：
```typescript
// 语音提示
export function speakCoordinate(row: number, col: number): boolean {
  if ('speechSynthesis' in window) {
    const utterance = new SpeechSynthesisUtterance(`第${row}行，第${col}列`);
    utterance.lang = 'zh-CN';
    speechSynthesis.speak(utterance);
    return true;
  }
  return false;
}
```

### 3. 状态保存（跟踪进度）

**保存时机**：
- visibilitychange - 页面切后台/切标签
- pagehide - 关闭页面
- 切换选中状态时自动保存

**保存内容**：
```typescript
interface SelectionState {
  type: 'block' | 'color' | null;
  blockX: number;
  blockY: number;
  colorHex?: string;
  colorId?: string;
}
```

### 4. 颜色替换（色号缺货）

**功能特点**：
- Delta E 算法计算颜色差异，推荐相近色
- 显示"区块内数量"和"全部数量"
- 全局替换（整个作品）
- 永久保存（替换后数据更新）

**Delta E 计算**：
```typescript
export function deltaE(hex1: string, hex2: string): number {
  const lab1 = hexToLab(hex1);
  const lab2 = hexToLab(hex2);
  return Math.sqrt(
    (lab1.L - lab2.L) ** 2 +
    (lab1.a - lab2.a) ** 2 +
    (lab1.b - lab2.b) ** 2
  );
}
```
