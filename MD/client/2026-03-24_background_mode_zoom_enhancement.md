# 2026-03-24 背景处理模式缩放增强

- 日期：2026-03-24
- 范围：客户端

## 改动目标
让背景处理模式在手机端更容易点选格子，支持更大的放大倍数，避免用户用手指操作时点不准。

## 本次修改
- 文件：`perler-beads/src/components/InteractiveCanvas.tsx`
- 对背景处理模式单独放宽缩放范围：
  - 最小缩放从 `fitScale * 0.8` 放宽到 `fitScale * 0.65`
  - 最大缩放从普通模式的 `fitScale * 2` / `至少 1x`，提高到 `fitScale * 6` / `至少 3x`
- 对背景处理模式单独增大缩放步进：
  - `+/-` 缩放步进从 `0.1` 提高到 `0.15`

## 预期效果
- 背景处理模式下，用户可以把预览图放得更大。
- 在手机上点背景边缘格子、点格擦除、补回误删时更容易操作。
- 普通编辑页的预览缩放规则保持不变，不受这次增强影响。

## 验证
- `npm run build` 通过。
