# 单板模式第二十七阶段：完成态工具区继续压缩与分享反馈强化

## 本次目标
- 继续压缩单板模式全部完成态的缩放区与工具区占位。
- 强化“分享作品”的页面内反馈，不只依赖 toast。

## 实现内容
1. 新增 `shareFeedback` 页面状态，记录分享结果：
   - `shared`：已打开系统分享
   - `copied`：已复制分享文案
   - `unsupported`：当前环境不支持直接分享
2. 在全部完成态顶部完成入口卡片内显示分享反馈文案。
3. 全部完成态下进一步压缩缩放区：
   - 更小的 padding
   - 更小的 gap
   - 更小的百分比字号与宽度
4. 全部完成态下进一步压缩工具区：
   - `适板` 按钮尺寸继续缩小
   - `辅助` 按钮继续使用紧凑尺寸

## 影响
- 全部完成态首屏更紧凑，缩放区和工具区对主工作区的挤压更小。
- 分享动作在代码层已具备页面内反馈通路，后续在真实浏览器环境中会直接反馈“已打开系统分享”“已复制分享文案”或“不支持直接分享”。

## 验证
- `cmd /c npm run build`
- MCP 检查 `/mobile/making` 单板模式全部完成态：
  - 顶部保持精简收尾入口
  - 工具区只保留紧凑的 `适板 / 辅助`
  - 底部保持 `导出图纸 / 回到编辑 / 分享作品 / 已完成`
