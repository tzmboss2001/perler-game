# 背景处理提示文案乱码修复

## 时间
- 2026-03-11

## 问题
- 编辑图案页进入背景处理模式后，点击 `一键去背景`，提示文案里的原因说明仍然是乱码。
- MCP 实测时可见文案类似：
  - `重新圈出 1 格背景候选区。...乱码...`

## 原因
- `backgroundRemovalService.ts` 里的 `reason` 和 `finalReason` 字符串在之前的编码处理过程中被损坏。

## 修复
- 修改文件：
  - `perler-beads/src/services/backgroundRemovalService.ts`
- 恢复以下中文提示：
  - `边缘背景不够稳定，建议使用智能抠图获得更干净的结果。`
  - `边缘主色很稳定，已按整片同色背景优先圈选。`
  - `边缘存在多组接近背景色，已把相近区域一起纳入候选。`
  - `已按边缘连通区域圈出主要背景候选。`
  - `已启用主体保护，中心主体及周边缓冲区不会被一并删除。`

## 验证
- 本地执行 `npm run build` 通过。
- MCP 重新走创建图案 -> 裁剪 -> 编辑图案 -> 背景处理模式。
- 点击 `一键去背景` 后，页面正常显示：
  - `重新圈出 1 格背景候选区。边缘背景不够稳定，建议使用智能抠图获得更干净的结果。 已启用主体保护，中心主体及周边缓冲区不会被一并删除。`

## 发布
- 本次仅本地修复，未发布公网。
