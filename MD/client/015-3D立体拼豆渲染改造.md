# 3D立体拼豆渲染改造

## 日期
2026-02-12

## 改动概述
将拼豆渲染从纯平面2D填充升级为3D立体渲染效果，通过多层Canvas渐变模拟真实拼豆的短圆柱+中心孔（环面/甜甜圈）外观。

## 核心改动

### 新建文件
- **`src/core/BeadRenderer3D.ts`** - 3D拼豆渲染器
  - `drawBead3D()` - 7层渐变实现完整3D渲染
  - `getBeadImage()` - OffscreenCanvas 缓存机制
  - `drawBeadCached()` - 使用缓存图高性能绘制
  - `clearBeadCache()` - 清除缓存
  - LOD 支持：>=16px完整7层, 8~15px简化3层, <8px纯色

### 修改文件
1. **`GameCanvas.tsx`** - 编辑画面豆子绘制
   - 替换原有4层（实心圆+中孔+孔阴影+高光点）为 `drawBeadCached()`
   - 保留放置动画（弹入效果）和模板引导逻辑

2. **`ContinuousRenderer.ts`** - 结果画面连续渲染
   - `localFusion < 0.3`：3D渲染 + 中孔随融合度消失
   - `0.3 ≤ localFusion < 0.7`：3D扁平化 + 圆角矩形过渡
   - `0.7 ≤ localFusion < 0.95`：圆角矩形 → 方块
   - `localFusion ≥ 0.95`：完全融合方块
   - 粘连模式不变（已融合片材）

3. **`ResultCanvas.tsx`** - 回退渲染（无 physics 时）
   - `drawUndercooked()`：全部使用 3D 渲染
   - `drawPartialMelt()`：正常豆子用 3D，融化豆子保持原有变形逻辑
   - `drawSuccess/drawSticky/drawBurned/drawCollapse`：不变

## 3D渲染7层结构
| 层 | 名称 | 效果 |
|----|------|------|
| 1 | 底部投影 | 豆子浮在钉板上的阴影 |
| 2 | 外圈暗环 | 圆柱侧面暗色 |
| 3 | 主体色渐变 | 顶面弧度（光源左上） |
| 4 | 中孔底色 | 深暗色圆孔 |
| 5 | 中孔内壁 | 环形渐变深度感 |
| 6 | 环面高光 | 塑料光泽（左上偏移） |
| 7 | 边缘光 | 右下侧环境光反弹 |

## 性能优化
- OffscreenCanvas 缓存：每种颜色只渲染一次
- 惰性缓存：首次绘制时创建
- cell 尺寸变化时自动清除重建
- 编辑画面（CELL=24）使用 `drawBeadCached()` 走缓存路径
