# 2026-03-07 创建流程文案与返回逻辑优化

## 用户反馈
1. 第一个“创建图案”页面实际是上传图片，命名不准确。
2. 第二步“快速开始（推荐）”没说明推荐参数是什么。
3. 高级设置本质是色系/颜色数量选择，文案不清楚。
4. 第二步点左上角返回应回到裁剪步骤，而不是回到上传页面或上一路由。

## 修改内容
文件：`perler-beads/src/pages/mobile/CreatePage.tsx`

1. 标题改为分步骤动态显示
- 上传阶段：`上传图片`
- 裁剪阶段：`裁剪图片`
- 参数阶段：`创建图案`

2. 增加推荐参数说明
- 在“系统建议网格宽度”下新增说明行：
  - `快速开始参数：网格宽度 X，颜色数量 Y 色（描述）`
- 明确“快速开始（推荐）”到底使用什么配置。

3. 高级设置文案更准确
- `打开高级设置/收起高级设置` -> `打开色系设置/收起色系设置`
- `颜色数量` -> `色系设置（颜色数量）`

4. 返回逻辑按步骤回退
- 在参数阶段点返回：回到裁剪阶段（保留原图）
- 在裁剪阶段点返回：回到上传阶段
- 仅在上传阶段才执行 `navigate(-1)`

## 验证
- 执行 `npm run build`：通过。

## 预期效果
- 用户能清楚区分创建流程各步骤。
- 推荐按钮参数透明，减少误解。
- 返回行为符合流程预期，不会“跳错步骤”。
