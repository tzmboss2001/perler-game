# 2026-03-04 第7项优化：颜色显示改为“名称主、色号次”（不进小方格）

## 需求
- 不在小方格里塞中文名，避免拥挤。
- 在统计列表里做“中文名优先 + 色号次要”的展示。

## 实现
- 文件：`perler-beads/src/pages/mobile/EditorPage.tsx`

1. 新增显示信息函数
- `getColorDisplayInfo(color)`
- 规则：
  - 优先 `nameCN`（且不等于色号）
  - 其次 `name`（且不等于色号）
  - 都没有时回退为 `色号 {id}`

2. 统计列表展示策略
- 主字段：`colorInfo.name`
- 次字段：仅当有“友好名称”时显示 `编号 {id}`
- 行 title 增加完整提示：`名称 · 色号 · 数量`

3. 小方格保持不变
- 颜色块继续纯色，不增加文字。

## MCP 验证
- 路由：`/mobile/editor`
- 展开“珠子统计”后，列表显示已变为主名称样式。
- 对于没有中文名/英文名的 MARD 颜色，会显示 `色号 ZG8` 这类可读文案（不再出现两列重复代码）。
