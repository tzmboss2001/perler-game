# 单板模式第二十八阶段：完成态回流验证与分享准备反馈

## 本次目标
- 为“分享作品”补充更可感知的页面内准备态反馈。
- 对单板模式完成态做一轮真实主路径回归验证。

## 实现内容
1. `shareFeedback` 状态新增 `preparing`：
   - 用户点击“分享作品”后，先在页面内显示 `正在准备分享...`
   - 若系统分享成功，切换为 `已打开系统分享`
   - 若复制成功，切换为 `已复制分享文案`
   - 若环境不支持，切换为 `当前环境不支持直接分享，可先导出图纸`
2. 如果用户关闭系统分享（AbortError），页面内反馈会重置，不留下错误状态。

## 验证计划
- `cmd /c npm run build`
- MCP 在单板模式全部完成态验证：
  1. 点击 `分享作品`，页面内出现 `正在准备分享...` 或后续结果反馈
  2. 点击 `查看整图` 能切回传统模式
  3. 点击 `导出图纸` 能拉起导出弹窗

## 影响
- 完成态的分享动作不再像“点了没感觉”，而是有明确页面内反馈。
- 第二十八阶段重点在于主路径回归，不再新增重功能。
