# 2026-03-27 手动扣背景相近区域扩张增强

## 背景
在真实图片测试中，手动扣背景虽然已经支持“连续点击累加”，但点击蓝天等复杂背景时，往往只能识别出 1 到 4 格，仍然过碎，离产品预期较远。

## 本次修改
### 1. 手动扣背景从“同色连通”升级为“相近色连通”
- 修改 `EditorPage.tsx` 中的 `collectConnectedManualBgIndices`
- 原逻辑只会扩张和种子点颜色 ID 完全相同的格子
- 新逻辑改成：
  - 以点击种子点颜色为起点
  - 同时参考种子颜色与当前已接受区域的平均颜色
  - 对四邻接格子做相近色扩张

### 2. 新增相近判断维度
- 种子颜色距离阈值
- 当前区域平均颜色距离阈值
- 亮度差阈值

### 3. 目标
- 让用户点击蓝天、树叶、阴影这类经过像素化后被拆成多种相近颜色的背景区域时
- 系统能一次带出更大一片连续背景，而不是只识别极少数同色格

## 涉及文件
- `perler-beads/src/pages/mobile/EditorPage.tsx`

## 验证
- 执行：`cmd /c npm run build`
- 结果：通过

## 当前效果
手动扣背景现在更接近“点一处背景，系统自动带出一大片相近背景”的方向，后续仍需继续结合真实图片回归验证效果是否达到产品要求。
