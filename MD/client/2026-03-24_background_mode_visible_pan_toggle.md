# 2026-03-24 背景处理模式显式移动视图入口

## 变更目的
- 解决电脑端背景处理模式需要按住空格再拖动才能移动预览图的问题。
- 让用户通过可见按钮直接发现并切换到移动视图模式，而不是依赖键盘手势记忆。

## 本次修改
- 在 `EditorPage.tsx` 的背景处理模式中新增 `移动视图` 按钮。
- 打开 `移动视图` 后，`InteractiveCanvas.tsx` 会进入显式平移模式：
  - 电脑端：左键直接拖动画布。
  - 手机端：单指直接拖动画布。
- 保留原来的双指缩放/双指平移能力。
- 切回 `连片选背景 / 点格擦除 / 补回误删` 时，会自动退出移动视图模式。
- 进入/退出背景处理模式、确认去背景、清空选择等场景会重置移动视图状态。

## 涉及文件
- `perler-beads/src/pages/mobile/EditorPage.tsx`
- `perler-beads/src/components/InteractiveCanvas.tsx`

## 验证
- `npm run build`
- 后续再用 MCP 确认：
  - 背景处理模式里能看到 `移动视图` 按钮。
  - 点开后，电脑端左键拖动会直接平移预览图。
