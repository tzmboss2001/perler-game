# 2026-03-19 编辑页预览最小缩放与全图适配修复

## 问题
用户反馈编辑页预览最多只能缩小到 89%，仍然无法在预览区一眼看完全图。

## 根因
`InteractiveCanvas` 之前的默认适配规则采用：
- 横图优先按宽度适配
- 竖图优先按高度适配

这会导致另一边溢出预览区，虽然数值上已经缩小，但实际仍然看不完整图案。

## 修复
- 文件：`perler-beads/src/components/InteractiveCanvas.tsx`
- 将默认适配规则改为统一使用 `Math.min(scaleX, scaleY)`。
- 新规则保证宽和高都不超过预览区，可在默认适配和最小缩放附近一眼看完全图。

## 结果
- `适配` 按钮会真正回到完整显示全图的状态。
- 最小缩放不再卡在一个仍看不完整图案的值。

## 验证
- `cmd /c npm run build` 通过。
