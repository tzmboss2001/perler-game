# 2026-04-07 单板模式区块与颜色高亮交互优化

## 背景
用户希望单板模式的点击逻辑按缩放层级切换：
- 缩放不高时，点击格子等于选择该格子所在区块，整块高亮。
- 缩放较高时，保持区块边界高亮；点击某个格子后，高亮该区块内与该格子同色的全部格子，帮助聚焦当前准备拼的颜色。
- 如果高倍率下点击其他区块的格子，应同时切换区块和颜色，而不是出现整块板都被压暗或高亮混乱。

## 处理
- 保留低倍率下的区块选择逻辑。
- 高倍率下：
  - 点击当前区块内格子：切换区块内同色高亮。
  - 点击其他区块格子：同时切换区块和颜色高亮。
  - 再次点击当前区块内同一颜色：回退到“仅区块高亮”状态，不清空区块。
- 渲染层改为：
  - `selection.type === color` 时，仅区块外弱化。
  - 区块内非目标颜色保持原色。
  - 区块内同色格子叠加亮化高亮。
  - 区块边界在 `block` 和 `color` 两种状态下都保持高亮。

## 结果
- 单板模式的高倍率点击逻辑更贴近真实制作流程：
  - 先聚焦区块
  - 再聚焦区块内同色格子
- 点击其他区块时会直接切换到新目标区块和新颜色，不再出现“整块板都高亮/压暗”的混乱感。

## 验证
- `cmd /c npm run build` 通过。
