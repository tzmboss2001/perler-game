# 2026-03-21 编辑页宽度区右侧对齐与归属优化

## 问题
- 编辑图案页中，`宽度 / 80` 视觉上更靠近上方预览缩放区。
- 右侧 `27%` 与 `80` 没有形成统一右边界。
- 宽度行右侧 `+` 按钮与上方 `1:1` 按钮的右边距观感不一致。

## 修改
- 宽度控制区改为与预览缩放更接近的 `flex` 排布。
- 宽度滑杆标记区域增加 `flex: 1`，确保右侧 `+` 按钮真正贴着当前行的最右侧。
- 宽度标题区增加轻微上内边距，拉开与上方缩放区的视觉关系。
- 宽度数值输入改为 `type="text" + inputMode="numeric"`，去掉 number 输入的浏览器内置占位差异。
- 保持右侧 `64px` 固定宽度与右对齐显示，和上方百分比统一到同一条右边界。

## 影响文件
- `perler-beads/src/pages/mobile/EditorPage.tsx`

## 结果
- `宽度 / 80` 会更明确归属于下方宽度滑杆。
- `27%` 与 `80` 的右边界会更一致。
- 宽度行的右侧 `+` 按钮会更靠近整行右边界。

## 验证
- 执行 `cmd /c npm run build`，构建通过。
