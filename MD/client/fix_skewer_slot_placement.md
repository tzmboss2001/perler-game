# 修复糖葫芦串插孔放置问题（两轮修复）

## 日期: 2026-02-10 ~ 2026-02-11

## 问题一：插孔在镂空区域

### 问题描述
糖葫芦串连接系统的插孔（slot）被放置在层的镂空部分（没有珠子的地方），而不是珠子壳体上。用户反馈："已经是空的了，还能留出插孔？插孔难道不是应该在拼豆中的吗"

### 根本原因
算法使用**实心数据**（未镂空）计算重叠区域，然后在**已镂空**的层上挖孔：

```
Phase 1: 每层镂空 → slices[i].pixels = 只有壳的数据
Phase 1.5: fullLayersData = 实心数据（未镂空）
Phase 2b: findCommonOverlap(fullLayersData)  ← BUG！
         → 距离变换优先选模型中心（离边缘最远）
         → 但模型中心在镂空后已经是空的！
         → punchSkewerSlot(slice.pixels) → 在空气上挖孔
```

### 修复方案

1. `findCommonOverlap()` → `findCoverageMap()`：返回覆盖计数而非布尔值
2. `selectSkewerPositions()` 支持覆盖率评分（≥50%即可，不要求100%）
3. `punchSkewerSlot()` 增加 `if (layerPixels[r][c] !== null)` 空位检查

## 问题二：插孔在最外层边缘

### 问题描述
修复问题一后，用户发现小层（如顶层Layer-15/Layer-30）的插孔被放在珠子的**最外缘**——没有足够的周围材料包裹，结构不安全。

用户反馈："你看看最上面那一层，如果你想要做卡槽口，你怎么能把卡槽口设置在豆子的最外层"

### 根本原因

第一版修复使用全方向距离检查（`getLayerEdgeDistance`），计算到**所有 null 像素**（包括镂空内部）的距离。对于3珠壳体：

```
[外部null] [外壳珠] [中间珠] [内壳珠] [内部null(镂空)]

外壳珠: 到外部=1, 到内部=3, min=1 → 被拒绝
中间珠: 到外部=2, 到内部=2, min=2 → 勉强通过
内壳珠: 到外部=3, 到内部=1, min=1 → 被拒绝！
```

结果：壳体内侧位置也被拒绝 → 大量中间层（4-10等200+珠大层）完全没有插槽。

### 修复方案

**核心改进**：区分"外部边界"和"镂空内部"

新增 `computeExteriorDistanceMap()` 函数：
1. **BFS洪水填充**：从网格四条边出发，标记所有外部 null（只穿过 null 像素，不穿过珠子）
2. **曼哈顿距离变换**：只以**外部 null**为距离源，忽略镂空内部的 null
3. **网格外 = 外部**：边界珠子自动得到距离1

效果对比：
```
[外部null] [外壳珠] [中间珠] [内壳珠] [内部null(镂空)]

外壳珠: 到外部=1 → 被拒绝（正确！最外层）
中间珠: 到外部=2 → 通过 ✓
内壳珠: 到外部=3 → 通过 ✓（内侧安全，有外壳包围）
```

**修改的 `punchSkewerSlot()`**：
- 新增 `exteriorDist` 参数（预计算的外部距离图）
- 检查 `extDist < halfSlot + 1` 时跳过（太靠近外部边缘）
- Phase 2b 预计算每层距离图：`slices.map(s => computeExteriorDistanceMap(s.pixels))`

## 修改文件

**`perler-beads/src/services/3d/contourSliceService.ts`**

| 函数 | 修改 |
|------|------|
| `findCoverageMap()` | 替代 `findCommonOverlap()`，返回覆盖计数 |
| `computeExteriorDistanceMap()` | **新增**，BFS标记外部null + 曼哈顿距离变换 |
| `selectSkewerPositions()` | 基于覆盖率评分 |
| `punchSkewerSlot()` | 新增 `exteriorDist` 参数，用外部距离做安全检查 |
| Phase 2b 调用处 | 预计算每层外部距离图，传递给 punchSkewerSlot |

## 最终验证结果

Duck.glb, 分辨率16, 壳厚度3珠, 糖葫芦串模式：

| 指标 | 问题一（修复前） | 问题一修复后 | 问题二修复后 |
|------|-----------------|-------------|-------------|
| 插条数 | 1 | 3 | 3 |
| 有槽的层数 | N/A（在空气挖孔） | 12/30 | **20/30** |
| 身体层(1-13) | 在镂空区域 | 只有1,2,3,11,12,13有槽 | **全部有槽** ✓ |
| 颈部层(14-18) | 在镂空区域 | 无槽 | 无槽（太窄）✓ |
| 头部层(19-25) | 在镂空区域 | 部分有槽 | **全部有槽** ✓ |
| 头顶层(26-30) | 在镂空区域 | 无槽 | 无槽（太小）✓ |
| 插孔位置 | 镂空区域 | 壳体上但可能在外缘 | **壳体内侧** ✓ |
| 总珠子 | - | 5137 | 5089 |

### 物理合理性
- 大层（身体/头部）：插孔在壳体中间或内侧，外壁有珠子包围 → 结构牢固
- 窄层（颈部）：插条自然穿过，不挖槽 → 不破坏结构
- 小层（头顶）：同上，插条穿过不挖槽 → 保持完整
