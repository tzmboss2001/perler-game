# 2026-03-21 编辑页控制区窄屏防溢出修复

## 变更内容
- 修复编辑图案页在手机窄屏下控制区横向溢出的问题。
- 将窄屏判断放宽到 `<= 420px`，更早启用移动端紧凑布局。
- 修复宽度滑杆区域错误的 `minWidth: 100%`，改为 `minWidth: 0`，避免整行被撑出屏幕。
- 在窄屏下压缩：
  - `- / +` 按钮尺寸
  - `适配 / 1:1` 按钮内边距
  - 宽度数值宽度
  - `54 / 78 / 104 / 208` 标记按钮和引导线
- 让预览缩放滑杆在窄屏下单独占一行，避免与右侧按钮互相挤压。

- `perler-beads/src/pages/mobile/EditorPage.tsx`
