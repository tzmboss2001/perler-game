# 2026-04-06 单板模式第十一阶段：默认恢复主路径

## 本次目标
- 将“进入单板模式后默认继续上次制作”真正变成主路径。
- 在不移除现有板切换和完成策略的前提下，进一步压缩折叠态顶部的非核心信息占位。

## 代码改动
### 1. 切换到单板模式时优先恢复未完成板
文件：`perler-beads/src/pages/mobile/MakingPage.tsx`

改动：
- 点击 `单板模式` 时，不再优先继续当前整图浏览所在板。
- 现在切换逻辑改为：
  1. 若存在 `resumeBoardNumber`，优先恢复该未完成板
  2. 否则回落到当前板
  3. 再不行才回落到第一块板

作用：
- 单板模式真正变成“继续制作”的主路径，而不是“另一种浏览模式”。

### 2. 单板模式加载后自动校准到未完成板
文件：`perler-beads/src/pages/mobile/MakingPage.tsx`

新增：
- `singleBoardResumeAppliedRef`

改动：
- 单板模式 hydration 完成后，会自动判断：
  - 当前活动板是否已完成
  - 当前活动板是否与 `resumeBoardNumber` 不一致
- 若不一致，则自动调用 `activateBoard(resumeBoardNumber, true)`

作用：
- 即使本地恢复到了旧的活动板，进入单板模式后仍会优先落到真正应该继续制作的未完成板。

### 3. 折叠态顶部继续减薄
文件：`perler-beads/src/pages/mobile/MakingPage.tsx`

改动：
- 收起总览时，隐藏 `未完成：板N ...` 这一层
- 折叠态顶部现在保留：
  - 独立恢复入口条
  - 紧凑摘要
  - 自动切板策略按钮
  - 紧凑板导航

作用：
- 首屏顶部继续瘦身，把更多空间让给当前板工作区。

## MCP 验证
### 验证 1：折叠态顶部已收紧
当前单板模式首屏确认显示：
- `继续上次制作`
- `板1 · 已完成 4/10`
- `继续`
- `单板 · 已完成 4/10 · 40%`
- `展开总览`
- `完成本板后停留当前板`
- `上一块板 / 板1 / 板2 / 下一块板`

同时确认：
- 折叠态下不再显示 `未完成：板N ...` 行

结论：
- 折叠态顶部非核心信息已进一步减少。

### 验证 2：从传统模式切回单板模式会默认恢复到未完成板
操作：
1. 在单板模式下先从 `板1` 切到 `板2`
2. 切到 `传统模式`
3. 再切回 `单板模式`

结果：
- 切回单板模式后，页面没有停在 `板2`
- 而是自动回到未完成板：`板1`
- 同时 `上一块板` 变灰，说明确实回到了第一块板
- 底部任务条同步显示：`板1任务 · 4/10`

结论：
- “进入单板模式默认继续上次制作”主路径已生效
