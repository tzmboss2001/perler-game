# 制作页视觉辅助引导 MVP 落地记录

日期：2026-03-11
范围：客户端本地实现，未发布公网

## 本次改动
### 1. 新增视觉识别服务
文件：`perler-beads/src/services/visionAssistService.ts`
- 新增拼豆板切分逻辑 `splitBeadDataIntoBoards`
- 新增四角插值采样逻辑
- 新增逐格识别逻辑 `analyzeVisionProgress`
- 支持识别：已完成、待放、错放、空位、额外填充
- 补了色值兜底：目标色没有 `rgb` 时，从 `hex` 解析颜色，避免测试数据报错

### 2. 新增视觉辅助弹层
文件：`perler-beads/src/components/BoardVisionAssistModal.tsx`
- 内置摄像头画面
- 支持四角校准
- 支持空板参考色取样
- 支持自动轮询识别和手动立即识别
- 支持多板切换
- 支持显示当前优先颜色、完成度、待放数、错放数
- 视频上叠加蓝色数字、绿色圈、红叉做引导
- 进度百分比改成避免误导的显示方式，不再把 `99.8%` 显示成 `100%`

### 3. 制作页接入入口
文件：`perler-beads/src/pages/mobile/MakingPage.tsx`
- 在设置面板里增加 `视觉辅助 -> 打开`
- 自动把当前区块换算到对应拼豆板，作为视觉辅助初始板
- 当前已选颜色会传给视觉辅助，优先作为引导颜色

## MCP 验证
### 验证方式
- 打开本地制作页：`http://127.0.0.1:3005/mobile/making?test=1`
- 用脚本注入模拟摄像头画面，不依赖真实硬件摄像头权限
- 模拟画面内容直接按测试图纸绘制

### 验证结果 1：完整匹配
- 视觉辅助弹层可正常打开
- 四角校准与空板取样可完成
- 自动识别结果：`900 已完成 / 0 待放 / 0 错放`
- 当前优先颜色和颜色剩余列表正常显示

### 验证结果 2：故意制造缺失与错放
- 模拟 1 格漏放 + 1 格错放
- 自动识别结果：`898 已完成 / 1 待放 / 1 错放`
- 能正常识别剩余颜色数量
- 说明不是只会报全对，缺失和错色也能分出来
