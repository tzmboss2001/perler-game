# 背景去除算法继续优化记录（二）

- 日期：2026-03-23
- 范围：客户端

## 本次目标
- 继续强化一键去背景对 1 像素细边和贴边断续残留的自动清理能力。
- 不增加任何新的用户操作，只优化算法本身。

## 本次修改
1. 细线桥接吸收规则
- 文件：`perler-beads/src/services/backgroundRemovalService.ts`
- 在背景候选区自动扩张时，除了原有“邻接背景候选足够多”之外，新增了“直线桥接”判断：
  - 如果一个格子左右两侧都已经是背景候选，或上下两侧都已经是背景候选，且颜色足够接近背景主色，也会被自动吸收进背景区域。
- 这条规则主要解决：
  - 一键去背景后只剩一条 1 像素细线没有被吃掉。
  - 贴边的细碎边缘因为邻接数不足，上一轮没有被自动识别。

2. 保持误删风险可控
- 直线桥接规则仍然只对“足够接近背景主色”的格子生效。
- 仍然受主体保护缓冲区约束。
- 不会放开成按整张图同色全删。

## 当前效果方向
- 一键去背景不再只靠大块连通区。
- 对细碎边、细线残留、贴边断续边的处理会更完整。
- 同时继续避免把图案内部被轮廓包住的同色区域误判成背景。

## 验证
- `npm run build` 通过。
