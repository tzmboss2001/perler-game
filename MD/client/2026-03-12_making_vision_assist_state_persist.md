# 制作页视觉辅助：状态保存与恢复

## 日期
2026-03-12

## 目标
让视觉辅助弹层在关闭后重新打开时，保留上一次的关键设置与校准进度，避免用户每次都从头开始。

## 本次实现
为视觉辅助增加本地持久化，保存以下状态：
- 当前板索引
- 当前优先颜色
- 四角点位
- 空孔点位
- 空板参考色
- 取样预览色
- 识别容差
- 自动轮询开关
- 自动切板开关

## 方案
1. 根据当前作品生成轻量存档 key
- 由 `boardSize`、作品宽高、bead 数量和前 24 个颜色 id 组合而成
- 避免不同作品间互相污染

2. 弹层打开时优先恢复本地存档
- 如果存在存档：恢复状态，并显示 `已恢复上次视觉辅助设置`
- 如果不存在存档：走初始默认值并重置校准

3. 弹层可见且完成首次恢复后，持续写入 localStorage
- 不存摄像头帧数据
- 不存瞬时识别结果
- 只保留对下次继续操作有价值的轻量状态

## 涉及文件
- `perler-beads/src/components/BoardVisionAssistModal.tsx`

## 验证
### 本地构建
- 执行：`npm run build`
- 结果：通过

### MCP 验证
1. 打开制作页视觉辅助
2. 切到 `板2`
3. 关闭 `自动轮询`
4. 关闭弹层
5. 再次打开视觉辅助

验证结果：
- 出现提示：`已恢复上次视觉辅助设置`
- 当前板恢复为 `板2`
- `当前板尺寸` 恢复为 `1 × 20`
- `自动轮询` 恢复为 `已关闭`
- localStorage 中已写入 `visionAssist:*` 记录
