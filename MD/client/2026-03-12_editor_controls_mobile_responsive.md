# 编辑图案页小屏控件响应式收口

## 本次目标
- 解决编辑图案页在手机窄屏下，预览缩放和作品宽度控件被硬挤、输入框和按钮拥挤的问题。
- 保证小屏设备上仍能完整操作缩放、作品宽度和快捷档位。

## 本次修改
- 文件：`perler-beads/src/pages/mobile/EditorPage.tsx`
- 新增 `viewportWidth` 状态，并监听窗口尺寸变化。
- 根据屏幕宽度为编辑页控件增加两档响应式：
  - `<= 390px`：滑杆改为整行优先，数字输入自动靠右
  - `<= 360px`：进一步压缩按钮尺寸和胶囊按钮内边距
- 调整了以下区域的小屏样式：
  - 预览缩放行
  - 作品宽度行
  - 作品宽度数字输入框
  - 作品宽度快捷档位行
  - 颜色风格快捷档位行

## 结果
- 小屏下，滑杆会优先单独占一行，不再和 `- / + / 输入框` 硬挤在同一行。
- 作品宽度输入框不会再把整体控件挤坏。
- 颜色风格和作品宽度的快捷档位在窄屏下也更容易排开。
