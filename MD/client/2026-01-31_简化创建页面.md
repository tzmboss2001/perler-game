# 简化创建页面 - 移除网格宽度选择

**日期**: 2026-01-31
**类型**: 用户体验优化

## 需求描述

减少用户在创建图案时的选择操作：
- 网格宽度由系统根据图片复杂度自动决定
- 用户如需调整，可在编辑页面修改

## 修改文件

`src/pages/mobile/CreatePage.tsx`

## 修改内容

### 1. 移除网格宽度选择 UI

删除了"图案尺寸"选择区域，包括：
- 网格宽度选项按钮（32, 42, 52, 64, 80, 104）
- 智能推荐标签
- 相关样式代码

### 2. 保留自动分析功能

系统仍然会在裁剪完成后自动分析图片复杂度：
```typescript
const handleCropComplete = async (croppedImg: string) => {
  setCroppedImage(croppedImg);

  // 自动分析图片复杂度，决定网格宽度
  setIsAnalyzing(true);
  try {
    const result = await analyzeImage(croppedImg);
    setGridWidth(result.recommendedWidth); // 自动使用推荐值
  } catch (error) {
    setGridWidth(52); // 失败时使用默认值
  } finally {
    setIsAnalyzing(false);
  }
};
```

### 3. 简化导入

```typescript
// 移除不再使用的导入
- import { GridFour, MagicWand } from '@phosphor-icons/react';
- import { STANDARD_BOARD_SIZES } from '../../services/imageAnalysisService';
```

## 修改前后对比

**修改前**（创建页面）：
1. 上传图片
2. 裁剪图片
3. 选择图案尺寸 ← 已移除
4. 选择颜色数量
5. 开始生成

**修改后**（创建页面）：
1. 上传图片
2. 裁剪图片
3. 选择颜色数量
4. 开始生成

## 效果

- 创建流程更简洁，减少用户决策负担
- 网格宽度由系统智能决定（基于图片复杂度）
- 用户如需调整，可在编辑页面通过滑杆修改
- 图片分析算法不变（边缘密度 + 颜色复杂度）
