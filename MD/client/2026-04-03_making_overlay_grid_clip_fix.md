# 制作模式预览区横条问题修复记录

- 日期：2026-04-03
- 文件：`perler-beads/src/pages/mobile/MakingPage.tsx`

## 问题
制作模式下，预览区外出现整屏横向黑线，看起来像网格线铺满了整个容器，而不是只出现在图案区域内。

## 原因
overlay canvas 在绘制基础格线、豆板内部对称线、豆板边界线时，使用了整个预览容器的宽高作为绘制范围，没有限制到图案本身的可视矩形。

## 修复
1. 计算图案在预览容器中的实际可视矩形：`canvasLeft / canvasTop / visualCanvasWidth / visualCanvasHeight`。
2. 对 overlay 绘制区域增加 `clip`，只允许在图案矩形内绘制。
3. 将所有竖线、横线、豆板边界线的绘制范围从整页容器改为图案矩形范围。

## 结果
制作模式下的网格线、豆板线和中心十字现在只会出现在图案区域内，不会再在图案外的预览背景上铺出横条。
