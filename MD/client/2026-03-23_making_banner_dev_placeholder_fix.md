# 2026-03-23 制作页广告位开发环境占位修复

## 问题
- 制作页代码里虽然有 `BannerAd placement="making_bottom"`，但当前 `VITE_AD_MODE` 默认是 `off`。
- 在本地开发环境中会直接返回 `null`，导致用户完全看不到广告位，也无法确认广告区布局是否合理。

## 处理
- 修改 `perler-beads/src/components/ads/BannerAd.tsx`
- 当 `import.meta.env.DEV && adMode === 'off'` 时，不再返回空，而是渲染一条可见的广告位占位卡片。
- 占位文案明确说明：当前是开发环境占位，抖音端会替换为真实广告。
- 保留生产逻辑：非开发环境且 `adMode === 'off'` 时仍然不渲染广告。

## 结果
- 本地开发和联调时，制作页可以直接看到广告区。
- 不需要等真实广告接通，也能先验证页面布局、留白和滚动体验。
- 生产环境不会因为这次改动在 `off` 模式下误显示假广告。
