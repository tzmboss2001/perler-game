# 2026-03-07 制作页双指缩放抖动修复

## 现象
- 在制作页面双指放大/缩小时，画面出现明显抖动，影响操作稳定性。

## 原因
- 原实现采用“逐帧增量”缩放（每次用当前距离与上一帧距离比值）。
- 双指手势本身存在微小抖动，增量叠加会放大误差，导致画面锚点漂移。
- 缩放与位移每帧同时更新，误差累积后表现为明显抖动。

## 修复方案
- 改为“手势起点基准”算法：
  - 在双指开始时记录 `startDistance/startScale/startTranslate/startFocal`。
  - 移动过程中统一按起点计算目标缩放和位移，不再依赖上一帧增量。
- 双指开始时显式关闭单指拖动状态，避免拖拽状态干扰缩放。

## 修改文件
- `perler-beads/src/pages/mobile/MakingPage.tsx`

## 验证
- `npm run build` 构建通过。

## 预期效果
- 双指缩放时画面中心更稳定，抖动明显降低。
- 缩放过程中跟手性更一致，不再出现“忽左忽右”的锚点漂移感。
