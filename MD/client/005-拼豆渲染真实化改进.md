## 问题描述
1. **豆子看起来是实心的** - 中孔只有2.5px（在半径10px的豆子上），比例太小
2. **豆子之间间距太大** - CELL_SIZE=24, BEAD_RADIUS=10，相邻豆子间有4px空隙
3. **熨烫后没有融合效果** - 成功状态只是稍微放大了圆，没有展现豆子粘连、变扁的真实效果
4. **拉丝效果不真实** - 只是豆子之间画细线，没有融化塑料被拉扯变形的感觉
5. **拉丝状态豆子不应该分离** - 温度高到产生拉丝，豆子肯定已完全融合成一整片
6. **烧焦颜色偏移方向错误** - `applyBurnColor` 让颜色变亮变黄（R增G减B减），实际应该变暗变焦
7. **烧焦/塌陷还是一颗颗豆子** - 温度那么高，豆子早该完全融合，不应该看到独立的圆形

## 核心物理逻辑
温度越高，豆子越扁、面积越大、融合越彻底：
```
半生不熟：◎ ◎ ◎   圆形+中孔+间隙（没融化）
成功融合：■■■■■   完美方块无缝（刚好融化）
烧焦/塌陷：■■■■■  同样完全融合，但颜色变焦/整体收缩
```

## 修改内容

### GameCanvas 编辑模式
- `BEAD_RADIUS`: 10 → 11（间距从4px减为2px，豆子更紧密）
- `HOLE_RADIUS`: 新增，3.5（占直径比32%，更真实）
- `PEG_RADIUS`: 2 → 3（钉子稍大，穿过中孔可见）
- 豆子绘制从3层改为4层：
  1. 外圈主体（拼豆颜色圆）
  2. 中孔（接近钉板背景色，模拟穿透效果）
  3. 中孔边缘阴影（径向渐变，模拟圆柱内壁深度）
  4. 环面高光（左上偏移，模拟光照）

### FailureEngine 烧焦颜色算法
- **修前**：R增加(+40)、G减少(-30)、B减少(-50) → 颜色变亮变黄（错误）
- **修后**：整体变暗(darken=0.4) + 向深棕色(80,40,10)混合(50%) → 颜色变深变焦（正确）
- 示例：红色 `#b0353c` → 烧焦后 `#511f14`（深棕黑色）

### ResultCanvas 结果页

#### drawSuccess（成功融合）- 最终版
- 完全平整、无缝隙、无中孔、无圆角
- 每颗豆子变成完美正方形 `fillRect`，与邻居无缝拼接（+0.5px重叠消除抗锯齿缝隙）
- 整体看起来像一片完美的像素画

#### drawSticky（粘连拉扯）- 完全重写
- **核心思路**：完全融合的整片塑料被从某个角揭开时拉扯变形
- **统一拉扯方向**：随机确定一个揭开角度，所有豆子沿同一方向被拉
- **渐变变形**：越靠近拉扯方向末端变形越大（平方曲线）
- **三层渲染**：
  1. 宽带状塑料连接（融化塑料被拉开的带子，不是细线）
  2. 融合方块形豆子（已完全融合，不是分离的圆），沿拉扯方向拉伸
  3. 拉伸区域高光条纹（模拟塑料被拉薄时的光泽）

#### drawBurned（烧焦）- 完全重写
- **核心思路**：比成功更热，一定完全融合 + 颜色变焦 + 焦痕
- **5层渲染**：
  1. 完全融合的方块底色（颜色已在 FailureEngine 变暗）
  2. 不均匀烧焦暗块（有些地方烧得更厉害）
  3. 焦痕斑点（较大、深色）
  4. 边缘焦黑（边缘更容易烧焦）
  5. 烟雾效果（灰色渐变圆）

#### drawCollapse（整体塌陷）- 完全重写
- **核心思路**：完全融合的整片塑料被过度加热后软化坍塌、皱缩
- **不再是一颗颗椭圆**，而是融合方块向中心收缩
- **4层渲染**：
  1. 融合方块底色（向中心收缩，模拟塑料片缩水）
  2. 不均匀暗色（厚薄不均）
  3. 皱褶纹路（塑料皱缩形成的褶皱线）
  4. 边缘翘曲阴影（收缩后边缘不平整）

#### drawUndercooked（半生不熟）
- 中孔用新的HOLE_R=2.5，颜色改为接近钉板背景色
- 保持没融合的环形外观

#### drawPartialMelt（局部融化）
- 融化区域：椭圆变形，无中孔（已融合）
- 正常区域：环形绘制，有中孔，与编辑模式一致

## 物理逻辑链一致性修复（第三轮）

### FailureEngine.ts 修复
1. **Collapse 增加颜色变焦** - 温度比 burned 更极端，颜色也应变暗（intensity × 0.7）
2. **Sticky 标记全部豆子为 melted** - 粘连=已完全融合，不应该只标记40%

### ResultCanvas.tsx 修复
3. **Undercooked 移除微偏移** - 没融合的豆子应严格保持原位（完全分离）
4. **Undercooked 改为间隙线** - 用圆形描边强调"分离"感
