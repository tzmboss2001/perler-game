# 2026-03-21 编辑页宽度标题与滑杆关联性优化

## 问题
- 编辑图案页中 `宽度 / 208` 视觉上更靠近上方的预览缩放区。
- 原因是宽度滑杆的标记按钮区上下留白过大，导致标题与真正的宽度滑杆之间距离太远。

## 修改
- 收紧宽度滑杆标记区的上下留白：
  - `paddingTop` 和 `paddingBottom` 从 `26px` 调整为 `18px`
- 缩小标记按钮与锚点区域尺寸：
  - 按钮高度从 `22px` 调整为 `20px`
  - 锚点宽度从 `40px` 调整为 `34px`
  - 字号缩小到 `10px`
- 缩短标记按钮到滑杆的垂直引导线：
  - 线高从 `14px` 调整为 `10px`
  - 顶部/底部定位从 `22px` 调整为 `18px`

## 影响文件
- `perler-beads/src/pages/mobile/EditorPage.tsx`

## 结果
- `宽度 / 208` 会更明显地和下方宽度滑杆关联。
- 不会再看起来像挂在上方预览缩放区上。

## 验证
- 执行 `cmd /c npm run build`，构建通过。
