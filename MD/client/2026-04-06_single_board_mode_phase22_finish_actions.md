# 单板模式第二十二阶段：收尾动作产品化

## 本次目标
- 继续产品化单板模式在“全部完成”后的后续动作。
- 为收尾态补充“回到编辑”入口。
- 继续压缩全部完成态的工具区和状态提示。

## 实现内容
1. 顶部完成入口增加 `回到编辑`
- 单板模式在 `singleBoardAllDone` 状态下，顶部完成入口现在提供：
  - `回到编辑`
  - `查看整图`
  - `导出图纸`
- 完成提示文案同步更新为：
  - `可以直接收尾、回看整图或返回编辑`

2. 全部完成时工具区继续收口
- 单板模式在全部完成时，工具区继续只保留：
  - `适板`
  - `辅助`
- 不再显示：
  - `收尾`
  - `图纸`

3. 全部完成时顶部状态提示仍然关闭
- 单板模式 `singleBoardAllDone` 下，顶部状态提示不会再常驻显示。

4. 底部收尾态改成三动作结构
- 底部任务条在全部完成时现在是：
  - `导出图纸`
  - `回到编辑`
  - `已完成`
- 同时保留完成状态元信息：
  - `全部完成`
  - `10/10`
  - `剩余 0`
