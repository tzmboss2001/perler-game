# 制作页视觉辅助：摄像头失败后可立即重试

## 日期
2026-03-12

## 目标
解决视觉辅助在摄像头权限失败后，只能关闭弹层再重新打开的问题。

## 本次实现
1. 把摄像头启动逻辑抽成可复用的 `startCamera()`
2. 新增 `handleRetryCamera()`，支持在当前弹层内直接重试
3. 在摄像头错误遮罩中加入按钮：
- `重试摄像头`
- 重试过程中显示：`正在重试...`
4. 增加启动请求 id 防止旧请求回写，避免重复重试时状态串乱

## 涉及文件
- `perler-beads/src/components/BoardVisionAssistModal.tsx`

## 验证
### 本地构建
- 执行：`npm run build`
- 结果：通过

### MCP 验证
- 当前环境无摄像头权限
- 打开视觉辅助后，可见：
  - `无法打开摄像头，请检查浏览器权限后重试`
  - `重试摄像头`
- 点击 `重试摄像头` 后：
  - 不需要关闭弹层
  - 仍停留在当前弹层内
  - 错误态可原地继续重试
