# 制作页视觉辅助：历史识别摘要与当前板不一致提醒

## 本次目标
- 在多板作品中，如果恢复的历史识别摘要来自另一块板，明确提醒用户当前板和历史结果不一致。
- 避免用户把别的板的历史结果误当成当前板进度。

## 改动内容
1. 在 `BoardVisionAssistModal.tsx` 中新增 `detectionSummaryBoardMismatch` 判断。
2. 当满足以下条件时显示提醒：
   - 存在历史识别摘要
   - 历史摘要带有板号
   - 当前选中板与历史摘要板号不同
3. 提示文案：
   - `当前已切到 板X，这份历史结果来自 板Y，建议重新识别当前板。`
4. 调整切板逻辑：
   - 手动/自动切板时不再直接清空历史摘要
   - 这样用户切板后还能看到旧摘要，并收到不一致提醒
5. 重置校准、初始化恢复等场景仍会按原逻辑清理不该保留的数据。

## MCP 验证
- 手动写入一份：
  - 当前板索引 = 板1
  - 历史摘要板号 = 板2
- 重新打开视觉辅助后，验证结果：
  - 出现 `上次识别摘要`
  - 出现 `识别板位：板2`
  - 出现 `当前已切到 板1，这份历史结果来自 板2，建议重新识别当前板。`
