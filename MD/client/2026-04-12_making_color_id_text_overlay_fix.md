# 2026-04-12 制作模式色号独立高清文字层修复

## 问题
- 制作模式放大到 500% 左右时，色号字符明显发糊、像素感重。
- 即使调轻描边，根因仍在于色号文字和底图一起处于 stage 缩放体系里，被整体放大。

## 根因
- 原先色号直接画在 overlay canvas 上。
- overlay canvas 与底图 canvas 同处 `canvasStage`，会一起被 `scale()` 放大。
- 这会让文字天然带上像素放大感，在高倍率下看起来不清楚。

## 修复
- `MakingPage.tsx`
  - 从 overlay canvas 中移除色号绘制。
  - 新增 `textOverlayCanvasRef` 独立高清文字层。
  - 文字层挂在 wrapper 上，不跟随 stage 一起缩放。
  - 按 wrapper 屏幕像素和当前可视区域，直接重新绘制色号。
  - 保持点击穿透，不影响原有交互。
  - 文字层保留轻描边，但比原先更轻，并按屏幕字号重新计算。

## 结果
- 图案和高亮层继续安全缩放。
- 色号文字改为按当前屏幕像素独立绘制，不再跟着底图一起被放大成像素块。
- 高倍率下色号可读性会明显优于之前的 stage 内文字渲染。
