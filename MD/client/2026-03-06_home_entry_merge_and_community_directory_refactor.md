# 2026-03-06 首页入口合并与社区目录重构

## 问题
1. 首页“拍照创作/相册选择”与底部“创作”均跳转同一页面，入口重复。
2. 首页“成品社区”作为快捷按钮与创作操作并列，信息架构不合理。

## 处理
- 将快捷操作区合并为两个核心入口：
  - 开始创作（统一跳转 `/mobile/create`）
  - 我的方案（跳转 `/mobile/profile`）
- 移除首页快捷区“成品社区”按钮。
- 在“社区作品”模块新增目录切换：
  - 图纸社区
  - 成品社区
- 图纸社区保留原有标签筛选、排序、瀑布流展示与分页加载逻辑。
- 成品社区接入 `finishedWorkApi.listPublic(1, 20)`，展示成品卡片，并提供“查看全部”跳转 `/mobile/finished`。

## 修改文件
- `perler-beads/src/pages/mobile/HomePage.tsx`

## 验证
- 执行：`cmd /c npm run build`
- 结果：构建通过（vite build success）。

## 影响
- 首页导航层级更清晰：创作入口与社区内容分离。
- 社区模块结构更符合业务语义，用户可以在同一位置切换查看“图纸”与“成品”。
