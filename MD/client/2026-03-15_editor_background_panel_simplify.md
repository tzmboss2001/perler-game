# 2026-03-15 编辑页背景处理面板简化

## 背景
上一轮已经把编辑页主入口改成抠图，但背景处理面板内部仍然把强度、主体保护、候选区查看、对比、手动擦除等选项全部平铺展示。对普通用户来说，层级还是偏重，不够像“一键去背景工具”。

## 本次调整
1. 将背景处理面板改为“主操作在前，高级微调折叠在后”。
2. 主操作区只保留：
   - `一键去背景`
   - `智能抠图`
3. 新增高级微调折叠入口：
   - `打开高级微调`
   - `收起高级微调`
4. 将以下能力统一收进高级微调区：
   - 识别强度
   - 主体保护
   - 只看背景候选区
   - 查看去背景前
   - 手动选背景
   - 手动擦除
   - 手动补回
   - 清空选择
5. 调整文案，让页面更符合拼豆工具定位：
   - 说明文案改成“优先用一键去背景，复杂图片再用智能抠图；只有不满意时再打开高级微调。”
   - `查看当前选择` 改成 `手动选背景`
   - `手动擦背景` 改成 `手动擦除`
   - `手动补背景` 改成 `手动补回`
6. 进入手动模式时，会自动展开高级微调，避免用户找不到对应工具。

## 修改文件
- `perler-beads/src/pages/mobile/EditorPage.tsx`

## 验证
- 前端构建：`cmd /c npm run build` 通过
- MCP 验证通过：
  - 进入 `背景处理模式` 后，默认只看到：
    - `一键去背景`
    - `智能抠图`
    - `打开高级微调`
  - 点击后可展开：
    - `识别强度`
    - `主体保护：已开启`
    - `只看背景候选区`
    - `查看去背景前`
    - `手动选背景`
    - `手动擦除`
    - `手动补回`

## 结论
背景处理面板已经从“全量工具堆叠”改成“默认傻瓜操作 + 需要时再精修”的结构，更符合拼豆图生成器的用户预期。
