# 背景处理主体保护规则

## 时间
- 2026-03-11

## 本次改动
- 在 `backgroundRemovalService.ts` 中为一键去背景加入“主体保护”规则。
- 算法会先在画面中心区域寻找非背景主体核，再向外扩一圈保护缓冲。
- 一键去背景时，会把保护缓冲内的背景候选格从删除列表中剔除，减少主体边缘被误删。
- 在 `EditorPage.tsx` 的背景处理模式中新增 `主体保护：已开启/已关闭` 开关，默认开启。

## 目的
- 降低复杂图片里人物脸边、头发边、主体轮廓被一键去背景误删的概率。
- 保留用户关闭主体保护的能力，便于处理背景占比很高、主体很小的特殊图。

## 验证计划
- 本地执行 `npm run build` 确认前端构建通过。
- 使用 MCP 进入编辑图案页，打开背景处理模式，确认：
  - 出现“主体保护”开关；
  - 开关可切换；
  - 一键去背景流程无新增报错。
