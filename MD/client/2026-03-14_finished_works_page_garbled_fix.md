# 2026-03-14 成品社区页乱码修复

## 问题
- 成品社区页新增搜索与排序后，页面标题、占位文案和按钮文本出现实际界面乱码。
- MCP 截图已确认这是页面显示问题，不是快照解码误差。

- 文件在写入过程中出现了错误编码，导致中文字符串被破坏。

## 修复
- 文件：`perler-beads/src/pages/mobile/FinishedWorksPage.tsx`
- 采用 UTF-8 重新写回完整文件内容
- 恢复以下用户可见中文：
  - `成品社区`
  - `搜索成品名 / 描述 / 作者`
  - `清除`
  - `最新`
  - `最热`
  - `没有找到匹配的公开成品`
  - `暂无公开成品`
  - `加载中...`
  - `已经到底了`

## 结果
- 成品社区页恢复正常中文显示
- 搜索与排序功能保留
