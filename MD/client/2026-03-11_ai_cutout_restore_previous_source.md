# 智能抠图前原图恢复

## 时间
- 2026-03-11

## 本次改动
- 编辑图案页增加 `lastAiCutoutImageData` 快照。
- 智能抠图成功后，会保存抠图前原图。
- 在编辑主控区新增 `恢复抠图前原图` 按钮。
- 点击后会直接回退到抠图前原图，并重新生成图案。

## 目的
- 智能抠图存在误判风险，用户需要一键撤回能力。
- 回退入口放在主控区，比藏在背景模式里更容易找到。

## 验证计划
- 本地执行 `npm run build`
- MCP 进入编辑页 -> 背景模式 -> 智能抠图
- 确认：
  - 回到编辑页后出现恢复按钮
  - 点击恢复按钮后回退成功
