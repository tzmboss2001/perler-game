# 制作页视觉辅助自动四角识别与角点微调

日期：2026-03-11
范围：客户端本地实现，未发布公网

## 本次改动
### 1. 自动识别四角
文件：`perler-beads/src/services/visionAssistService.ts`
- 新增 `detectBoardCorners`
- 基于视频帧做轻量规则识别，不依赖 OpenCV 或额外安装
- 先通过边缘能量和边框颜色差找出拼豆板核心区域
- 再按当前板的 `boardSize / usedWidth / usedHeight` 推回整块物理板尺寸
- 解决了边缘残板只识别到有效图案区、不识别整板范围的问题

### 2. 视觉辅助弹层接入自动识别
文件：`perler-beads/src/components/BoardVisionAssistModal.tsx`
- 新增按钮：`自动识别四角`
- 自动识别成功后，直接进入“点击空孔取样”步骤
- 识别失败时，仍可回退到原有手动点角流程

### 3. 新增角点微调
文件：`perler-beads/src/components/BoardVisionAssistModal.tsx`
- 四角已经确定但尚未取样时
- 用户点击某个角点附近，会直接替换那个角点位置
- 用于修正自动识别的误差，不需要整套重来

## 构建结果
- `npm run build` 通过

## MCP 验证
### 已验证
1. 制作页设置中可打开视觉辅助
2. `自动识别四角` 按钮可正常工作
3. 自动识别后，步骤提示会切换到“点击空孔取样”
4. 自动识别得到的角点不再只框住有效图案区，而会扩展到整块物理板的近似范围

### 当前结论
- 视觉辅助校准已从“纯手动”升级为“半自动”
- 当前推荐流程：
  1. 先点 `自动识别四角`
  2. 如果有轻微偏差，点角点附近微调
  3. 再点空孔完成取样

## 当前边界
- 自动识别仍是近似框，不是最终无误差的全自动校准
- 真机复杂场景下仍需要继续做更强的自动校准与抗干扰增强
