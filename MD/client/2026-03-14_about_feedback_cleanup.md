# 2026-03-14 关于页与反馈页乱码修复及小屏收口

## 问题
- 关于页和反馈页存在大量用户可见乱码，已经影响页面正常使用。
- 两页在窄屏手机下也存在标题、说明文案、按钮区拥挤的问题。

## 处理
- 重写 `AboutPage.tsx` 的用户可见文案，恢复为正常中文。
- 重写 `FeedbackPage.tsx` 的用户可见文案，恢复为正常中文。
- 同时为两页增加基于 `viewportWidth` 的小屏响应式布局：
  - `<= 390px` 时，信息行、反馈类型卡片、说明区更稳定换行。
  - `<= 360px` 时，内边距压缩，按钮更适合单手点击。

## 影响范围
- 客户端
- 文件：
  - `perler-beads/src/pages/mobile/AboutPage.tsx`
  - `perler-beads/src/pages/mobile/FeedbackPage.tsx`

## 验证
- 运行 `npm run build`，前端构建通过。
- 后续结合 MCP 主流程回归继续确认页面能正常打开。

## 说明
- 本轮采用整页重写方式处理次级页面乱码，避免零碎修补遗漏。
- 未修改业务接口，仅处理文案和界面表现。
