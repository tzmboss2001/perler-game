# 2026-03-19 编辑页悬浮面板点击空白关闭修复

## 问题
编辑图案页点击 `色系` 按钮后，悬浮面板只能再次点按钮或点关闭叉号收起。用户点击空白区域时，面板不会自动关闭，操作不顺手。

## 修复
- 文件：`perler-beads/src/pages/mobile/EditorPage.tsx`
- 当 `色系设置` 或 `豆子统计` 面板打开时，新增一层全屏透明遮罩。
- 点击遮罩时，会统一关闭 `showPaletteSettings` 和 `showStats`。
- 遮罩层级放在页面内容上方、按钮和面板下方，因此：
  - 点空白会关闭面板
  - 点按钮和面板本体不会误关

## 结果
- 点 `色系` 打开面板后，点击空白区域即可关闭。
- `统计` 面板同样支持点击空白关闭。

## 验证
- `cmd /c npm run build` 通过。
