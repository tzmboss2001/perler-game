# 智能抠图本地模拟模式

## 时间
- 2026-03-11

## 本次改动
- `aiCutoutService.ts` 新增 `mock` 模式。
- 本地开发环境增加 `perler-beads/.env.local`：
  - `VITE_AI_CUTOUT_ENABLED=mock`
- 在 `mock` 模式下，智能抠图会直接对原图做边缘背景透明化，返回新的 PNG 数据。

## 目的
- 不依赖后端，也能把“智能抠图 -> 返回新图 -> 编辑页重生成”整条链路跑通。
- 后续切换正式接口时，只需要把环境变量从 `mock` 改成 `true/live`。

## 行为
- `off`：未接入，只显示状态弹窗
- `mock`：本地模拟抠图，直接返回处理结果
- `live`：请求服务端真实接口

## 验证计划
- 本地执行 `npm run build`
- MCP 进入编辑图案页背景处理模式，点击“智能抠图”
- 确认：
  - 按钮进入处理态
  - 退出背景模式
  - 编辑页重新生成图案
