# 2026-03-05 社区发布难度改为系统判定

## 需求
- 发布作品时不由用户手动选择难度，改为系统自动判定。

## 实现
- 重写 `perler-beads/src/components/PublishModal.tsx`：
  - 移除用户手动切换难度按钮。
  - 新增只读展示“系统判定难度”。
  - 发布时直接提交系统传入的难度值。
- 修改 `perler-beads/src/pages/mobile/ProfilePage.tsx`：
  - 新增 `inferDifficulty` 规则（基于珠子总数、颜色数、边长综合评分）。
  - 在“分享到社区”前自动计算难度并传给 `PublishModal`。

## 判定规则（v1）
- 综合以下指标打分：
  - 珠子总数：`>=6000` 加2分；`>=2500` 加1分
  - 颜色数：`>=60` 加2分；`>=30` 加1分
  - 最大边长：`>=96` 加1分
- 结果：
  - `0-1` 分：`easy`
  - `2-3` 分：`medium`
  - `>=4` 分：`hard`

## 验证
- `npm run build` 通过。
