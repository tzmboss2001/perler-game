# 添加鼠标滚轮缩放功能

**日期**: 2026-02-01
**类型**: 功能增强

## 需求描述

制作页面在桌面端应该支持鼠标滚轮缩放，这是桌面应用的标准交互方式（如 Google Maps、Figma）。

## 修改文件

- `src/pages/mobile/MakingPage.tsx`

## 修改内容

### 之前
- 只支持双指缩放（移动端）
- 只支持 +/- 按钮
- 滚轮缩放需要按住 Ctrl 键

### 之后
- 鼠标滚轮直接缩放（类似 Google Maps）
- 不需要按 Ctrl 键
- 平滑缩放步进（0.2 每次）

### 代码变更

```typescript
// 使用原生事件监听器以正确阻止默认滚动
useEffect(() => {
  const wrapper = wrapperRef.current;
  if (!wrapper) return;

  const handleWheelNative = (e: WheelEvent) => {
    e.preventDefault(); // 阻止页面滚动
    // 平滑缩放：根据滚轮方向调整
    const delta = e.deltaY > 0 ? -0.2 : 0.2;
    setScale(prev => Math.min(6, Math.max(0.5, prev + delta)));
  };

  // 使用 { passive: false } 以允许 preventDefault()
  wrapper.addEventListener('wheel', handleWheelNative, { passive: false });
  return () => wrapper.removeEventListener('wheel', handleWheelNative);
}, []);
```

## 技术说明

React 的 `onWheel` 事件默认是 passive 的，无法阻止默认行为（页面滚动）。
因此使用原生 `addEventListener` 并设置 `{ passive: false }` 来正确阻止默认滚动。

## 当前支持的缩放方式

| 方式 | 平台 | 说明 |
|------|------|------|
| 双指缩放 | 移动端 | pinch zoom |
| +/- 按钮 | 全平台 | 点击按钮 |
| 鼠标滚轮 | 桌面端 | 直接滚动 |
| 鼠标拖拽 | 桌面端 | 平移画布 |
