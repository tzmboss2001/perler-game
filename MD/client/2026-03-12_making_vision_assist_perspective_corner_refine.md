# 2026-03-12 自动识别四角支持轻微透视斜拍

## 目标
让制作页视觉辅助的“自动识别四角”不再只适合正对拼豆板的矩形画面，也能更好适应轻微斜拍和透视变形。

## 本次修改
1. 扩展 `visionAssistService.ts`
- 在原有“粗找 + 边界精修”的基础上，继续增加“局部角点搜索”
- 新增：
  - `CORNER_DIRECTION_MAP`
  - `scoreCornerCandidate()`
  - `refineCornerPoint()`
- 思路：
  1. 先按粗找与边界精修得到近似矩形边界
  2. 再以四个近似角点为中心，分别做局部搜索
  3. 对每个候选角点，用“内外侧灰度对比 + 与背景差异 + 角点内部一致性”打分
  4. 再加“偏离初始边界太远则降权”的漂移惩罚，避免角点被局部强边缘拉走
  5. 最终输出四个独立角点，而不再强行固定成轴对齐矩形

## 验证
1. 本地构建
- `npm run build` 通过

2. MCP 合成透视场景验证
- 在浏览器中动态导入 `visionAssistService.ts`
- 构造两组带孔位纹理的四边形拼豆板画面：
  - `wideSkew`：宽屏轻微斜拍
  - `tallSkew`：竖屏轻微斜拍
- 使用 `interpolateQuadPoint()` 生成 30x30 孔位中心，模拟真实板面纹理

### 宽屏轻微斜拍
真实角点：
- 左上 `(250, 130)`
- 右上 `(1010, 110)`
- 右下 `(975, 645)`
- 左下 `(280, 630)`

识别误差：
- 左上 `dx = 5, dy = -4`
- 右上 `dx = -5, dy = 1`
- 右下 `dx = 1, dy = -1`
- 左下 `dx = -1, dy = 2`

### 竖屏轻微斜拍
真实角点：
- 左上 `(130, 300)`
- 右上 `(575, 265)`
- 右下 `(610, 990)`
- 左下 `(105, 1020)`

识别误差：
- 左上 `dx = -5, dy = -1`
- 右上 `dx = 5, dy = 5`
- 右下 `dx = -1, dy = 0`
- 左下 `dx = 1, dy = -5`

## 当前状态
自动识别四角现在已经从“矩形边框近似”提升到“支持轻微透视斜拍的独立角点识别”，在宽屏和竖屏合成场景下都能落在较小误差范围内。本次仅在本地完成，尚未发布公网。
