# 2026-03-23 editor save modal cloud fallback ux fix

## 问题
- 用户点击“保存并开始制作”后，如果云端保存失败，界面会先弹出“云端保存异常，已自动转存到本地方案”的 toast。
- 但此时“保存方案”弹层还留在界面上，造成体验上像是既失败了又没继续走下一步。

## 修复
- `EditorPage.tsx`
- 云端保存失败或异常时，不再先弹 warning toast。
- 统一直接走 `saveToLocal(..., { fromCloudFallback: true })`。
- 本地保存分支开始时先关闭保存弹层，再执行本地保存与跳转。
- 本地保存成功后统一给出明确结果：
  - `已自动保存到本地方案，正在进入制作模式。`
- 如果本地保存也失败，改成更准确的错误提示：
  - `保存失败，将直接进入制作模式。`

## 结果
- 不会再出现“顶部已经提示云端异常，但保存弹层还停在页面上”的割裂体验。
- 用户只会看到最终结果：要么正常保存进入制作模式，要么自动转本地后进入制作模式。
