# 2026-03-24 背景处理模式手势交互增强

- 日期：2026-03-24
- 范围：客户端

## 改动目标
补齐背景处理模式在电脑端和手机端的画布查看交互：
- 电脑端支持在不影响左键点格的前提下平移预览图
- 手机端双指缩放时同时支持双指平移

## 本次修改
- 文件：`perler-beads/src/components/InteractiveCanvas.tsx`

### 电脑端
- 新增 `空格 + 左键拖动` 平移画布
- 新增 `中键拖动` 平移画布
- 普通左键点击仍保留为：
  - 连片选背景
  - 点格擦除
  - 补回误删
- 背景处理模式下禁用默认右键菜单干扰

### 手机端
- 双指开始时记录：
  - 初始距离
  - 初始缩放
  - 初始双指中点
  - 初始偏移量
- 双指移动时同时更新：
  - 缩放比例
  - 画布偏移量
- 结果是双指既能放大缩小，也能拖动画布

### 视觉反馈
- 背景处理模式下按住空格时，鼠标光标改为 `grab`
- 正在平移时显示 `grabbing`

## 预期效果
- 电脑端：
  - 普通左键继续选格
  - 空格加拖动或中键拖动可查看别的位置
- 手机端：
  - 单指继续点格
  - 双指负责缩放和平移

## 验证
- `npm run build` 通过。
