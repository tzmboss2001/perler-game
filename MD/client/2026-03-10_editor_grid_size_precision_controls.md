# 网格宽度控件精确选择优化

日期：2026-03-10
文件：`perler-beads/src/pages/mobile/EditorPage.tsx`

## 问题
1. 网格宽度滑杆默认可滑到任意整数，不符合常见拼豆板宽度以偶数为主的使用习惯。
2. 仅靠滑杆粗调，用户在手机上很难精确选中目标宽度。

## 处理
1. 新增网格宽度归一化逻辑：统一按 `2` 为步进，范围仍保留 `10-200`。
2. 滑杆改为 `step=2`，拖动时自动吸附到偶数值。
3. 增加 `- / +` 微调按钮，每次精确调整 `2`。
4. 增加数字输入框，用户可直接输入目标宽度，失焦或回车后应用。
5. 增加常用板规格快捷按钮：`54 / 78 / 104`，一键切换常见豆板宽度。
6. 保留原有“松手后再重新生成”的策略，避免拖动中反复重算。

## 效果
1. 默认选择逻辑更贴近拼豆板规格。
2. 粗调、微调、直输、快捷尺寸四种方式同时提供，手机上更容易精确选宽度。
3. 常用板尺寸不需要再靠手拖滑杆慢慢对准。
