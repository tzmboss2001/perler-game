# 2026-03-29 编辑页色系面板系统色系与个人色系互斥优化

## 问题
- 色系面板里系统色系和个人色系的层级不够清楚。
- 点击“启用”个人色系时，如果还没配置个人色系，会直接弹出管理对话框，打断操作。
- 管理个人色系后会自动切到个人色系，不符合“点中哪个才代表当前选中哪个”的交互预期。

## 本次修改
1. 将色系面板明确分为两块：
   - 系统色系
   - 个人色系
2. 系统色系按钮始终显示，但只有当前处于系统色系模式时才会出现选中态。
3. 点击任意系统色数按钮时：
   - 自动退出个人色系模式
   - 切回对应系统色系
4. 个人色系保留：
   - 管理
   - 启用
5. 点击“启用”时：
   - 若没有配置个人色系，不再弹出管理对话框
   - 改为 toast 提示用户先点击“管理”选择个人色系
6. 管理个人色系保存后：
   - 仅更新个人色系内容
   - 不再自动切换到个人色系
   - 只有当前已经处于个人色系模式时，才会即时重生成预览
