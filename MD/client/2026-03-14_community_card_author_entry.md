# 2026-03-14 社区卡片作者入口补全

## 目标
- 在首页社区卡片、社区列表卡片、成品社区列表卡片上直接提供作者主页入口。
- 用户无需先进入详情页，即可从卡片作者名跳转到作者主页。

## 修改
- HomePage.tsx
  - 图纸社区卡片底部新增作者按钮。
  - 成品社区卡片作者名改为独立按钮。
- CommunityPage.tsx
  - 社区列表 PostCard 底部新增作者按钮。
- FinishedWorksPage.tsx
  - 成品社区列表作者名改为独立按钮。
- 所有作者按钮均拦截 `stopPropagation()`，避免触发卡片本身的详情页跳转。

## 验证
- `npm run build` 通过。
- MCP 验证从卡片作者入口可直接进入作者主页。
