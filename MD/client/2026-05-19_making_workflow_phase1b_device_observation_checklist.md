# Making Workflow Phase1-B Device Observation Checklist

日期：2026-05-19

阶段：Phase1-B 第一批真机观察期

## 当前状态

Phase1-B 第一批已经完成并收口：

- 任务提示
- 状态变化短提示
- 冻结提示
- overlay 遮挡修复
- freeze model 收口
- MCP / browser 验证
- desktop / traditional mode 回归

当前不继续开发新 UI，不继续增加 overlay，不修改手势、layout、缩放、拖动边界和复位逻辑。

## 观察目标

本阶段目标不是扩功能，而是验证真实手机长时间制作体验是否稳定。

如没有明显问题，Phase1-B 第一批进入长期稳定观察，不再继续微调。

如发现明显遮挡、拥挤、误触或疲劳问题，单独开 issue，按“复现 -> 测试 -> 最小修复”处理。

## 真机观察重点

### 1. 高倍率选格时的阅读压力

记录：

- 280% 以上选格时，是否还能清楚读到当前格和色号。
- 顶部摘要是否压迫图纸可读性。
- 底部工具弱隐藏后是否仍有视觉干扰。

判定：

- 当前格 / 色号优先级必须高于任务提示和状态提示。
- 不应出现需要反复点击或拖动画面才能读清当前格的情况。

### 2. 当前格 / 当前色可读性

记录：

- 当前格边框是否容易定位。
- 色号文字是否足够清晰。
- 当前色摘要是否能帮助用户继续找同色格。
- 强光、暗光环境下是否仍可读。

判定：

- 用户能在 1-2 秒内确认当前格位置与色号。
- 当前色提示不应长期挡住制作区域核心位置。

### 3. Overlay 拥挤感

记录：

- 顶部状态、底部工具、缩放控件是否同时造成压迫。
- 小屏手机是否明显拥挤。
- 刘海屏、安全区、浏览器工具栏是否影响沉浸式区域。

判定：

- 工具只是辅助，不能成为视觉主角。
- 图纸区域仍应是第一优先级。

### 4. 长时间制作疲劳感

记录：

- 连续制作 10 分钟、30 分钟时是否累眼。
- 弱隐藏控件是否仍分散注意力。
- 短提示是否打断制作节奏。
- 长时间缩放 / 拖动是否稳定。

判定：

- 不应因为提示和控件造成持续视觉噪音。
- 不应因为提示消失/出现导致用户失去位置感。

### 5. iPhone / Android 差异

记录：

- iPhone Safari 是否存在底色丢失、色号异常、触摸延迟。
- Android Chrome 是否存在缩放、拖动、切板误触。
- 同一倍率下色号和底色表现是否一致。

判定：

- 两端都必须保持图纸颜色、色号和当前格可读。
- 若只在某一端出现，应单独标记设备、浏览器和系统版本。

### 6. 手机浏览器差异

记录：

- iPhone Safari
- iPhone Chrome
- Android Chrome
- Android 系统浏览器
- 微信 / 抖音 WebView 如有测试条件

判定：

- 核心制作流程不能依赖某个浏览器特性。
- WebView 如出现差异，单独归类，不混入普通浏览器结论。

### 7. 缩放 / 拖动 / 切板稳定性

记录：

- 100%-200% 微移是否自然。
- 300% 以上自由拖动是否稳定。
- 缩放过程中图纸、色号、当前格是否同步。
- 多板切换是否没有误触。
- 工具抽屉打开时底层画布是否仍冻结。

判定：

- 不能为了提示可读性破坏 Phase1 的手势基线。
- 不能出现缩放结束才修正位置或色号状态的明显跳变。

### 8. 新的遮挡或误触场景

记录：

- 是否有新的 overlay 遮挡当前格。
- 是否有工具按钮误触。
- 是否有帮助、总览、工具抽屉关闭后状态不恢复。
- 是否有横竖屏切换导致布局异常。

判定：

- 任何新增遮挡都必须先确认复现步骤。
- 不直接扩大 UI 修复范围。

## 决策规则

进入长期稳定观察的条件：

- 连续真机使用未发现明显遮挡。
- 当前格 / 当前色可读。
- 短提示不打扰制作。
- 缩放 / 拖动 / 切板稳定。
- iPhone / Android 没有明显核心体验差异。

需要单独开 issue 的条件：

- 当前格 / 色号被遮挡。
- 短提示频率打扰制作。
- 工具浮层造成误触。
- 某端浏览器出现稳定复现的渲染异常。
- 手势稳定性出现回归。

不进入本轮处理的内容：

- 新增复杂帮助系统。
- 新增更多 overlay。
- 横屏沉浸式扩展。
- 多板沉浸式扩展。
- 生成质量优化。
- 模板 / 内容生态。

## 结论

Phase1-B 第一批当前进入真机观察期。

下一步只记录真实使用反馈，不主动继续扩 UI。
