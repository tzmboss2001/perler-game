# 2026-03-12 自动识别四角边界精修与画面比例验证

## 目标
提升制作页视觉辅助中“自动识别四角”的边界精度，减少宽屏和竖屏真机下自动框偏大、偏移的问题。

## 本次修改
1. 扩展 `visionAssistService.ts`
- 为 `detectBoardCorners()` 增加“粗找后边界精修”逻辑
- 新增：
  - `getAxisSamples()`
  - `scoreVerticalEdge()`
  - `scoreHorizontalEdge()`
  - `refineRectEdge()`
- 逻辑调整为：
  1. 先按原有能量场找到拼豆板粗略区域
  2. 再围绕左、右、上、下四条边分别做局部搜索
  3. 用“内外侧灰度对比 + 与背景参考色差异”给每条候选边打分
  4. 选出得分最高的边作为最终边界

2. 现有效果
- 自动识别不再只靠第一轮粗略框
- 对宽屏和竖屏取景下的边界落点更稳
- 为后续真机自动识别四角继续调参打下基础

## 验证
1. 本地构建
- `npm run build` 通过

2. MCP 合成画面验证
- 在浏览器中动态导入 `visionAssistService.ts`
- 构造两种画面比例：
  - `1280 x 720` 宽屏
  - `720 x 1280` 竖屏
- 分别生成带板边和孔位纹理的合成拼豆板画面
- `detectBoardCorners()` 返回结果：

### 宽屏
- 真实边界：`left 260 / top 120 / right 980 / bottom 640`
- 识别误差：
  - `left = -7`
  - `top = -7`
  - `right = -1`
  - `bottom = 1`

### 竖屏
- 真实边界：`left 120 / top 280 / right 600 / bottom 980`
- 识别误差：
  - `left = -7`
  - `top = -7`
  - `right = -11`
  - `bottom = 1`

## 当前状态
自动识别四角现在在宽屏和竖屏合成场景下都能稳定落在较小误差范围内。本次仅在本地完成，尚未发布公网。
