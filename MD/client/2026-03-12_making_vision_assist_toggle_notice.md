# 制作页视觉辅助：自动轮询与自动切板开关即时说明

## 日期
- 2026-03-12

## 目标
- 用户切换 `自动轮询` 和 `自动切板` 开关时，立即得到清晰反馈。
- 避免只看到按钮状态变化，却不知道当前模式具体意味着什么。

## 本次修改
- 文件：[BoardVisionAssistModal.tsx](/D:/work/web/perler-beads-creator/perler-beads/src/components/BoardVisionAssistModal.tsx)

### 1. 自动轮询开关
- 新增 `handleToggleAutoDetect()`
- 切换后会立即显示：
  - 开启：`已开启自动轮询，画面稳定后会持续更新识别`
  - 关闭：`已关闭自动轮询，当前识别结果会保留`

### 2. 自动切板开关
- 新增 `handleToggleAutoSwitchBoard()`
- 切换后会立即显示：
  - 开启：`已开启自动切板，系统会在多块拼豆板间自动匹配`
  - 关闭：`已关闭自动切板，将固定识别当前所选板`

### 3. 说明展示方式
- 这类即时说明复用视觉辅助现有的顶部提示条
- 不另外增加新弹窗，不打断用户操作

## 验证

### 本地构建
- 命令：`cmd /c npm run build`
- 结果：通过

### MCP 验证
- 页面：`http://127.0.0.1:3005/mobile/making?test=1`
- 打开：设置 -> 视觉辅助

#### 验证点 1：关闭自动轮询
- 点击 `自动轮询`
- 即时出现：
  - `已关闭自动轮询，当前识别结果会保留`

#### 验证点 2：关闭自动切板
- 点击 `自动切板`
- 即时出现：
  - `已关闭自动切板，将固定识别当前所选板`

## 结果
- 视觉辅助的两个核心开关现在都具备了明确的“模式说明反馈”。
- 这一步主要提升用户对当前识别模式的理解成本。
