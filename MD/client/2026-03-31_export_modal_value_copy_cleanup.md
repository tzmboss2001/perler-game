# 2026-03-31 高清导出与打印版导出文案收口

## 背景
当前导出弹窗存在明显乱码，且没有把“高清导出”和“分页打印版”这两个最适合承载广告的高价值动作讲清楚。用户即使看到导出入口，也不容易理解自己解锁的到底是什么价值。

## 本次修改
1. 重写导出弹窗所有乱码文案，统一改成可读中文。
2. 将导出分辨率选项改成更符合用户理解的描述：小图、标准、高清、超高清、极清。
3. 明确高清导出与打印版的价值说明：适合打印、精细对照、分页打印。
4. 将导出选项区文案改成更产品化的表达：显示网格线、显示坐标刻度、显示分区线、附带珠子清单、按拼豆板分页导出。
5. 将分页区改成“分页打印设置”，明确拼豆板规格和预计页数。
6. 导出按钮文案根据分页模式切换为“导出打印版图纸”或“导出图片”，避免模糊。

## 涉及文件
- `perler-beads/src/components/ExportModal.tsx`

## 结果
导出弹窗现在不再有乱码，且更清楚地区分了普通导出、高清导出和分页打印版图纸，为后续把“高清导出/打印版”作为广告解锁点提供了更清晰的价值表达。
