# 2026-03-14 设置页乱码修复与次级页面小屏收口

## 问题
- 设置页存在大量用户可见乱码，已经影响正常使用。
- 设置页和帮助页在窄屏手机下，按钮区和说明文案存在拥挤与换行不佳的问题。

## 处理
- 重写 `SettingsPage.tsx` 的用户可见文案，彻底修复设置页乱码。
- 同时为 `SettingsPage.tsx` 增加基于 `viewportWidth` 的小屏响应式布局：
  - `<= 390px` 时，卡片按钮可独占一行。
  - 账号信息卡改为纵向排列。
  - 法律信息和反馈入口统一收口。
- 为 `HelpPage.tsx` 增加小屏响应式布局：
  - 教程卡片、FAQ 标题、联系按钮在窄屏下自动压缩。
  - `<= 360px` 时，联系按钮改为整行，卡片内边距进一步缩小。

## 影响范围
- 客户端
- 文件：
  - `perler-beads/src/pages/mobile/SettingsPage.tsx`
  - `perler-beads/src/pages/mobile/HelpPage.tsx`

## 验证
- 运行 `npm run build`，前端构建通过。

## 说明
- 本轮设置页采用整页重写方式处理乱码，避免逐段修补遗漏。
- 未改动设置逻辑与帮助内容逻辑，只处理可见文案与布局表现。
