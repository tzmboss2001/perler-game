# 2026-03-12 视觉辅助增加遮挡与移动冻结识别

## 目标
解决真机使用视觉辅助时，用户的手经过镜头、拼豆板轻微晃动时，识别结果来回乱跳的问题。

## 本次修改
1. 扩展 `visionAssistService.ts`
- 新增 `createVisionFrameSignature()`
- 新增 `compareVisionFrameSignature()`
- 用低分辨率灰度签名比较相邻帧变化，给出画面变化值

2. 更新 `BoardVisionAssistModal.tsx`
- 自动轮询识别前先比较前后帧变化
- 当变化值超过阈值时，不更新新识别结果，保留旧结果
- 需要连续稳定若干帧后，才恢复继续识别
- 新增 UI 状态：
  - `画面稳定性`
  - `待识别`
  - `检测到遮挡或移动`
  - `等待画面稳定`
  - `画面稳定`
- 新增提示文案，告诉用户检测到手经过镜头或板子移动时会临时冻结结果
- 手动点击 `立即识别` 时，如果画面仍在移动，会给出提示而不是硬算

## 验证
1. 本地构建
- `npm run build` 通过

2. MCP 算法验证
- 浏览器内动态导入 `visionAssistService.ts`
- 构造两帧完全相同画面与一帧明显变化画面
- 结果：
  - `sameDiff = 0`
  - `changedDiff = 31.01`
- 说明同帧稳定、遮挡/移动帧差异明显，足够驱动冻结逻辑

3. MCP 页面验证
- 打开制作页视觉辅助弹层
- 页面已显示：
  - `画面稳定性`
  - `待识别`
- 说明状态文案已经接到界面上

## 当前状态
视觉辅助现在在自动轮询时具备基础的遮挡/移动抗抖能力，能在手遮挡或板子移动时先冻结旧结果，再等画面稳定后继续更新。本次仅在本地完成，尚未发布公网。
