# 016 - 完整手工体验流程改造

## 日期
2026-02-12

## 改动概述
将游戏从简化的5阶段流程扩展为完整还原真实拼豆手工体验的9阶段流程。

### 新流程
```
selecting → placing → taping → flipping → removing → papering → ironing → rescuing → result
```

### 新增4个步骤
| 步骤 | 渲染 | 交互 | 翻车条件 |
|------|------|------|---------|
| 贴美纹纸 (taping) | Canvas 2D | 拖拽画胶带条 | 覆盖不全/按压不实 |
| 翻转钉板 (flipping) | Three.js 3D | 手势翻转180度 | 翻太快/未贴区域掉豆 |
| 去除钉板 (removing) | Three.js 3D | 向上拖拽提起钉板 | 拉太快/歪着拉 |
| 铺烘焙纸 (papering) | Canvas 2D | 拖拽纸张覆盖 | 覆盖不全→烧焦风险+50% |

## 技术要点
- Three.js 3D场景使用 Suspense 懒加载（~245KB gzip 按需加载）
- InstancedMesh 实现1个draw call渲染所有豆子
- 8段圆柱降低顶点数75%
- 移动端关闭抗锯齿，dpr限制[1, 1.5]
- 手势Hook解耦交互逻辑
- 风险计算公式：总风险 = 前置步骤风险 * 0.2 + 熨烫风险 * 0.8
- 烘焙纸覆盖不全时烧焦风险倍增
