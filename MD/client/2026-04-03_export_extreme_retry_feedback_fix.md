# 2026-04-03 导出极清无反应修复

## 问题
- 在制作模式导出图纸弹窗中点击 `极清` 后再点 `导出图片`，界面看起来没有反应。
- 浏览器控制台实际报错：`导出失败：浏览器未能生成图片数据`。
- 原因是大图导出时 `canvas.toBlob()` 直接返回 `null`，前端只打控制台日志，没有给用户可见反馈。

## 修复
1. 在 `ExportModal.tsx` 中增加导出重试策略。
   - 先按当前安全精度导出。
   - 如果失败，则按递减的 cellSize 自动降档重试。
2. 如果最终导出成功但精度低于当前档位宣称值，弹出提示：
   - 已按每格 X px 安全导出。
3. 如果所有重试都失败，直接给出用户可见错误提示，建议改用分页打印版或降低清晰度。

## 影响
- `极清` / `超高清` / 大图普通导出不再表现为“点了没反应”。
- 用户会明确知道最终实际导出精度，而不是误以为始终按名义档位导出。

## 验证
- 执行 `npm run build` 通过。
- 使用 MCP 在制作模式导出弹窗中复测 `极清 -> 导出图片` 链路。
