# 统一预览区默认适配规则修复

- 日期：2026-03-16
- 影响范围：客户端所有使用 `InteractiveCanvas` 的预览区，尤其是编辑页背景处理模式
- 文件：`perler-beads/src/components/InteractiveCanvas.tsx`

## 问题
进入背景处理模式后，预览区里的图形默认大小没有按容器完整适配，用户一开始看不到完整全图。根因不是背景模式单独逻辑错误，而是预览组件原先只在图案尺寸变化时重新计算默认缩放，没有覆盖“容器尺寸稍后才稳定”的场景。

## 修复
1. 新增统一的 `syncScaleToViewport()` 逻辑，作为所有预览区默认适配规则。
2. 规则改为：
   - 任何预览区第一次拿到有效容器尺寸时，强制完整适配全图。
   - 默认保证宽或高至少有一边正好贴合预览区。
3. 新增 `ResizeObserver` 监听预览容器尺寸：
   - 当容器在挂载后继续变化时，会重新按统一规则修正默认缩放。
4. 保留已有用户缩放意图：
   - 如果用户已经手动放大/缩小，不会在普通布局变化时被粗暴重置。
   - 如果用户本来就在“适配大小”附近，容器变化后会继续保持完整适配。

## 结果
- 编辑页主预览区和背景处理模式预览区，现在默认都遵循同一条适配规则。
- 用户第一次进入任何预览区时，都会先完整看到全图，而不是出现图过小或没贴合容器的问题。
