# 2026-03-20 编辑页宽度滑杆长度与标记连线优化

## 问题
- 宽度滑杆与数字输入框放在同一行，导致滑杆本体过短。
- 54 / 78 / 104 标记按钮缺少到滑杆对应位置的引导线，视觉对应关系不够明确。

## 处理
- 将宽度控件改为两行布局：
  - 第一行：减号、长滑杆、加号
  - 第二行：提示文案和数字输入框
- 保留 54 / 78 / 104 三个标准拼豆板宽度标记按钮在滑杆区域内。
- 为每个标记按钮增加从按钮中心垂直到滑杆位置的引导线。
- 保持 54 / 78 / 104 上下交错排列。

## 影响文件
- `perler-beads/src/pages/mobile/EditorPage.tsx`

## 验证
- 执行 `cmd /c npm run build`
- 构建通过。

## 结果
- 滑杆本体明显变长。
- 标记按钮与滑杆刻度的对应关系更清晰。
- 数字输入仍保留，但不再压缩滑杆长度。
