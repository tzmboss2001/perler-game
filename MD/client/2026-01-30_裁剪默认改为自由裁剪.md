# 裁剪默认改为自由裁剪

**日期**: 2026-01-30
**类型**: 功能优化

## 需求描述

用户希望裁剪图片时：
1. 默认是自由裁剪状态，裁剪框覆盖整个原图
2. 用户可以自由拖动裁剪框调整大小
3. 移除单独的"自由裁剪"按钮（因为默认就是自由裁剪）
4. 其他比例选项（1:1、4:3、3:4）只是方便用户快速设置比例

## 修改文件

`src/components/ImageCropper.tsx`

## 修改内容

### 1. 移除"自由"选项和"推荐"标记

**修改前**:
```typescript
const aspectOptions: AspectOption[] = [
  { label: '原图', key: 'original', aspect: undefined, isOriginal: true },
  { label: '1:1', key: '1:1', aspect: 1, recommended: true },
  { label: '4:3', key: '4:3', aspect: 4 / 3 },
  { label: '3:4', key: '3:4', aspect: 3 / 4 },
  { label: '自由', key: 'free', aspect: undefined },
];
```

**修改后**:
```typescript
const aspectOptions: AspectOption[] = [
  { label: '原图', key: 'original', aspect: undefined, isOriginal: true },
  { label: '1:1', key: '1:1', aspect: 1 },
  { label: '4:3', key: '4:3', aspect: 4 / 3 },
  { label: '3:4', key: '3:4', aspect: 3 / 4 },
];
```

### 2. 默认状态改为自由裁剪

**修改前**:
```typescript
const [selectedKey, setSelectedKey] = useState<string>('1:1');
```

**修改后**:
```typescript
const [selectedKey, setSelectedKey] = useState<string>('free');
```

### 3. 更新选项获取逻辑

**修改前**:
```typescript
const selectedOption = aspectOptions.find(opt => opt.key === selectedKey) || aspectOptions[1];
const isOriginalMode = selectedOption.isOriginal === true;
const aspect = isOriginalMode ? undefined : selectedOption.aspect;
```

**修改后**:
```typescript
const selectedOption = aspectOptions.find(opt => opt.key === selectedKey);
const isOriginalMode = selectedOption?.isOriginal === true;
const isFreeMode = selectedKey === 'free' || (!selectedOption && !isOriginalMode);
const aspect = isOriginalMode ? undefined : (selectedOption?.aspect ?? undefined);
```

### 4. 自由裁剪时裁剪框覆盖整个原图

**修改前**:
```typescript
// 自由比例
const newCrop: Crop = {
  unit: '%',
  x: 10,
  y: 10,
  width: 80,
  height: 80,
};
```

**修改后**:
```typescript
// 自由裁剪模式：裁剪框覆盖整个原图
const newCrop: Crop = {
  unit: '%',
  x: 0,
  y: 0,
  width: 100,
  height: 100,
};
```

## 效果

- 打开裁剪页面时，默认显示覆盖整张图片的裁剪框
- 用户可以自由拖动四角或边缘调整裁剪区域
- 点击比例按钮（1:1、4:3、3:4）可快速切换到对应比例
- 点击"原图"则直接使用原图不裁剪
