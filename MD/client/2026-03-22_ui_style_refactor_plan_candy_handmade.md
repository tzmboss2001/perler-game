# 2026-03-22 UI 风格改造计划 - 糖果手作风

## 背景
当前产品整体视觉仍偏深色工具风，适合编辑器，但不够贴合“拼豆图生成器”的产品气质。此前已经确定新的统一方向为“糖果手作风”，但中途被功能和交互修复打断，尚未完整落地。

## 目标
把产品主视觉从“深色工具面板风”调整为更符合拼豆产品特征的“糖果手作风”，同时保留编辑和制作页面必要的工具感，形成统一但有层次的视觉体系。

## 总体方向
- 全站统一气质：更明快、更轻、更有手作感
- 首页 / 社区 / 我的：浅色底、糖果色点缀、作品展示更轻盈
- 编辑页 / 制作页：保留工具属性，但改成“浅底工具区 + 彩色点缀”
- 避免继续朝更黑、更冷的方向演进

## 风格关键词
- 奶白底
- 薄荷绿 / 天空蓝 / 蜜桃粉 / 柠檬黄 点缀
- 圆角卡片
- 轻阴影
- 轻玻璃感或糖果按钮
- 更像手工创作工具，不像冷硬后台

## 设计原则
1. 功能优先，不为了风格破坏可读性和操作效率
2. 颜色服务于拼豆主题，而不是单纯追求花哨
3. 编辑器保持专业，但不再整体压暗
4. 手机端优先，保证窄屏下仍清晰、紧凑、可点
5. 首页与编辑页先做出可感知差异，再扩展到其他页面

## 第一阶段范围
### 页面
1. 首页
2. 编辑图案页

### 目的
- 首页：建立新的品牌第一印象
- 编辑图案页：验证“浅底工具区 + 彩色点缀”是否能兼顾效率与风格

## 第一阶段改造内容
### 首页
- 整体背景改为浅色系
- 顶部品牌区改成更轻盈的糖果手作风
- 快捷按钮改成更有产品识别度的彩色按钮
- 社区卡片改为浅底卡片，减少深色压迫感
- 分类、排序、标签区做统一的浅色胶囊风格

### 编辑图案页
- 页面背景从全深色调整为更浅的工作台底色
- 预览区保留重点感，但边框与卡片更轻
- 下方控制区改成浅底工具卡
- 左侧悬浮工具按钮统一成糖果色工具按钮
- 保留功能效率，不做幼态化装饰

## 暂不处理
- 制作模式完整重构
- 社区独立页全面换肤
- 我的页面全面换肤
- 全站动效重做

这些放到首页和编辑页第一版稳定后再继续。

## 推荐实施顺序
1. 抽取首页与编辑页共享视觉变量
2. 先改首页
3. 再改编辑图案页
4. 做一轮本地构建和 MCP 视觉回归
5. 用户确认方向后，再扩展到制作页和社区页

## 验收标准
1. 首页第一眼不再像深色后台工具，而更像拼豆创作产品
2. 编辑页不再压抑，但仍保留工具效率
3. 手机端没有因为换肤带来新的拥挤、溢出、可读性问题
4. 两页风格统一，但层级有差异：首页更轻，编辑页更专业

## 后续执行约定
后续提到“UI 风格修改”时，默认按本文件执行，而不是重新从零讨论方向。
