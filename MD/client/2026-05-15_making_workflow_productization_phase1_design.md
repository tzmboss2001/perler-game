# 制作流程体验产品化 Phase1 设计记录

## 阶段定位

生成质量 Phase1-B-2 系列研究已阶段性冻结归档。当前主优先级切换到制作流程体验产品化，目标是让真实制作用户更清楚地完成一张拼豆图，而不是继续微调生成算法或继续深挖局部 UI。

本阶段采用“制作流程闭环优先”方案。核心判断是：用户进入制作页后，最重要的问题不是按钮是否更紧凑，而是是否知道当前做哪块板、当前该放什么颜色、下一步做什么、哪些已经完成、以及如何顺利导出和打印。

## 产品目标

- 降低真实制作时的迷路感，尤其是多板图、手机端和长时间制作场景。
- 提升当前板、当前格、当前颜色、完成状态的可读性。
- 保持手机端单板沉浸式 Phase1/Phase2 的稳定交互基线。
- 先做最小产品化增量，不大改 `MakingPage.tsx`，不重构导出引擎，不引入新的生成质量策略。

## 非目标

- 不继续当前生成质量 candidate 调参。
- 不进入新的生成质量算法实验。
- 不默认启用任何已冻结的实验参数。
- 不重写制作页整体架构。
- 不改变现有手势优先级、切板模型、拖动边界、复位逻辑。
- 不把手机端沉浸式工具重新放回页面 layout 文档流。
- 不在本阶段实现模板生态、官方模板运营、复杂内容平台能力。

## 硬性不变量

- 手机端单板沉浸式中，图纸区域必须继续铺满标题栏以下空间。
- 工具、状态、导航、帮助入口必须优先作为覆盖层存在，不能重新占 layout 高度。
- 工具抽屉、设置面板、总览层打开时，底层画布必须冻结。
- 不能修改手势优先级、切板阈值、拖动边界、低中倍率有限微移、高倍率自由拖动、复位逻辑。
- 桌面端、传统模式、多板非沉浸式不能被顺手改坏。
- 高风险交互必须独立提交、可回滚、可 MCP 验证。

## 主工作流设计

制作页应围绕“当前任务”组织，而不是围绕散落按钮组织。推荐主线为：

1. 进入制作页后，系统明确当前模式、当前板、整体进度和下一步动作。
2. 用户选择或定位当前格，页面突出当前格坐标、色号、颜色名称和同色区域。
3. 用户完成一颗或一组同色豆后，完成状态有轻量反馈，不遮挡图纸核心区域。
4. 用户需要换板时，通过当前板导航或既有手势切板完成；导航只增强可见性，不改变手势模型。
5. 用户需要导出/打印时，从工具入口进入导出流程，导出前展示分板顺序、overview 和打印注意事项。

## 当前板导航

### 目标

让用户在多板图中随时知道自己在哪一块板、上下左右还有没有板、当前板是否完成、下一块建议做哪块。

### 最小增量

- 增加“当前板状态”覆盖层信息：板号、行列位置、当前板完成率、整体剩余板数。
- 当前板导航入口保持边缘化，不占图纸 layout。
- 多板图时提供轻量板位地图或可展开总览，默认不长期遮挡中心图纸。
- 不修改已有左右/上下板按钮和手机端手势切板逻辑，只调整可读性和入口层级。

### 风险

- 中风险：如果导航层点击区域过大，可能影响画布点格和拖动。
- 高风险：任何触碰切板手势阈值、拖动边界、自动切板条件的改动都必须拆到独立阶段。

## 当前格与当前色可读性

### 目标

用户应该一眼看懂当前格要放什么颜色，并能稳定识别同色区域、当前格坐标和当前任务范围。

### 最小增量

- 当前格提示边缘化，优先贴近顶部或底部状态区，不长期漂浮在图纸中央。
- 当前色信息包括色号、颜色块、当前板内数量、整体数量。
- 同色高亮继续按当前模式语义显示：单板模式优先当前板，传统模式保持区块逻辑。
- 色号字号、加粗、缩放同步继续沿用现有稳定逻辑，不重新调整渲染策略。

### 风险

- 中风险：高亮层如果透明度或混合模式过强，会降低图案底色可读性。
- 高风险：改动色号 canvas / overlay 同步机制可能复发缩放时色号错位、初始化大小、底色丢失等旧问题。

## 已完成区域反馈

### 目标

让用户知道哪些区域已经做完，同时不让图纸变脏、不遮挡未完成格子。

### 最小增量

- 已完成区域采用低干扰淡化或标记，不改变原图颜色语义。
- 当前板完成后给边缘提示，不弹中心遮挡层。
- 已完成状态写入现有制作进度体系，不在本阶段改云端同步策略。

### 风险

- 中风险：已完成淡化可能和当前色高亮互相冲突，需要定义层级。
- 高风险：如果完成状态与库存扣减、云端进度同步混改，会扩大回归面，本阶段禁止混入。

## 新手帮助入口

### 目标

新用户能找到“怎么做”的帮助，熟练用户不会被强制教程打断。

### 最小增量

- 工具抽屉中增加“帮助/操作说明”入口。
- 首次进入单板模式时只给轻量提示，提示可关闭，关闭后不频繁打扰。
- 帮助内容聚焦当前阶段：缩放、拖动、切板、当前色、高亮、完成、导出。
- 帮助面板打开时底层画布冻结。

### 风险

- 低风险：静态说明文案。
- 中风险：首次提示时机和存储状态可能影响用户节奏，需要可关闭和可重看。

## 图纸导出与打印体验

### 目标

让用户导出前知道将得到哪些文件、如何按板制作和打印，不在本阶段重写导出引擎。

### 最小增量

- 导出前检查：尺寸、板数、是否包含总览、是否分页/分板。
- 分板顺序说明：板号、页码、行列位置、文件名规则。
- 打印提示：建议按原比例、不要页面自适应缩放、先打印一页测试。
- overview 可读性作为后续独立低风险视觉优化，不改变当前导出计算逻辑。

### 风险

- 中风险：导出弹窗交互和手机浏览器下载限制相关。
- 高风险：大图导出内存、ZIP 生成、Canvas 尺寸策略必须单独开性能阶段。

## 手机端制作交互

### 目标

继续保护沉浸式模型，只在覆盖层层级、信息密度、边缘提示上做产品化增强。

### 最小增量

- 所有新增入口默认边缘化，不长期停留在图纸中心。
- FAB、工具抽屉、状态提示遵守已有 z-index 层级和冻结规则。
- 新增覆盖层不得设置会撑开页面的 padding / margin / hidden 占位。
- 动画只允许使用 opacity / transform，不影响点击区域和事件响应。

## 大图性能与稳定性

本阶段只做评估和基准设计，不直接优化实现。

后续需要单独建立：

- 大尺寸图纸加载基准。
- 多板切换耗时基准。
- 高倍率拖动帧率观察。
- 导出内存峰值观察。
- 移动端 Safari / Android Chrome 分别验证。

## 模板与内容生态

模板与内容生态属于后续产品方向，不进入 Phase1 实现范围。当前只保留方向：

- 官方入门模板。
- 热门风格模板。
- 节日、宠物、像素风内容。
- 与制作页的衔接方式：从模板进入制作后，仍复用同一套制作流程。

## 风险等级拆分

### 低风险

- 文案、帮助说明、导出前说明。
- 不参与 layout 的视觉层级微调。
- 当前板状态的只读展示。
- MCP 验收脚本和文档补充。

### 中风险

- 当前板导航覆盖层。
- 当前色和已完成区域视觉层级。
- 首次引导提示时机。
- overview 可读性调整。

### 高风险

- 手势阈值、切板模型、拖动边界。
- 色号 canvas / overlay 渲染同步。
- 完成状态与云端同步、库存扣减联动。
- 大图导出、ZIP、Canvas 内存策略。
- 对 `MakingPage.tsx` 做大规模重构。

## Phase1 最小落地范围

第一轮只建议落地以下内容：

- 当前板状态覆盖层：当前板、行列位置、当前板完成率、整体剩余。
- 当前格/当前色可读性整理：边缘状态提示、当前板内同色统计、整体统计。
- 新手帮助入口：工具抽屉内帮助入口和可关闭的轻量说明。
- 导出前说明文案：不改导出引擎，只增强用户理解。
- MCP 验收矩阵和视觉契约，确保覆盖层不占 layout。

## Stop Condition

出现以下任一情况，本阶段应停止扩大范围：

- 手机端单板图纸区域不再铺满标题栏以下空间。
- 新增工具或状态层重新占用 layout 高度。
- 工具抽屉打开时底层画布仍可拖动、缩放、点格或切板。
- 100%-200% 低中倍率微移、高倍率自由拖动、复位逻辑出现回归。
- 多板切板出现明显误触。
- 色号在缩放中再次出现错位、初始化大小、底色丢失或密集重影。
- 桌面端或传统模式出现功能回归。

## MCP 验收矩阵

- 手机端单板沉浸式：图纸区域铺满标题栏以下空间，新增覆盖层不占 layout。
- 手机端单板沉浸式：工具抽屉打开后底层画布冻结。
- 手机端单板沉浸式：100%、150%、200% 可有限上下微移。
- 手机端单板沉浸式：300%+ 可按边界自由拖动。
- 手机端单板沉浸式：多板图低倍率拖动不误切板，明确切板动作仍可用。
- 手机端单板沉浸式：当前板状态、当前色信息、新手帮助入口都可点开且不遮挡核心格子。
- 桌面端单板模式：当前板导航和导出入口可用，不压缩图纸区域。
- 传统模式：原有区块流程、当前色高亮、导出入口不回归。
- 导出弹窗：导出前说明显示正确，不改变实际导出文件顺序。

## 提交与回滚策略

- 设计文档独立提交。
- 后续实现必须按小提交拆分，优先顺序为：当前板状态、当前色可读性、新手帮助入口、导出前说明。
- 每个中风险改动必须有独立 MCP 验收记录。
- 任何高风险交互变化必须另开 proposal，不混入 Phase1 最小落地。
