# 智能抠图请求链路准备完成

## 时间
- 2026-03-11

## 本次改动
- `aiCutoutService.ts` 增加了真实请求函数、环境变量读取和接口地址规划。
- `EditorPage.tsx` 将原图源改成可变状态，后续智能抠图返回新图后可以直接在当前页重生成。
- 背景处理模式中的“智能抠图”按钮增加加载态：
  - 已接入时发起请求；
  - 未接入时继续显示状态弹窗。
- 修复了本轮接入时引入的运行时错误：`showAlert is not defined`。

## 目的
- 把智能抠图入口从“状态说明”推进到“真正可接服务”的前端闭环。
- 后续服务端只要返回新的透明背景图，就能直接回灌到编辑页重生成，无需跳页。

## 当前约定
- 默认读取：
  - `VITE_AI_CUTOUT_ENABLED`
  - `VITE_AI_CUTOUT_API_URL`
  - `VITE_API_BASE_URL`
- 未开启 `VITE_AI_CUTOUT_ENABLED=true` 时，不会真实发请求。

## 验证计划
- 本地执行 `npm run build`。
- 使用 MCP 进入编辑页背景模式，确认：
  - `智能抠图` 按钮仍可用；
  - 未接入状态下会弹结构化状态弹窗；
  - 页面不会再因为 `showAlert` 报错而白屏。
