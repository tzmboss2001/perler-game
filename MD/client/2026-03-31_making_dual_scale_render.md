# 2026-03-31 制作模式双倍率渲染支持高倍缩放

## 问题
- 多板大图在制作模式下无法放大到足以清晰查看色号的程度。
- 之前的安全上限会把大图限制在 108% / 235% 这类偏低倍率。
- 如果继续沿用“整张大图的视觉倍率 = canvas 内部渲染倍率”，一旦直接放到 600%，又会重新触发黑屏或卡死。

## 方案
- 将制作模式拆成两套倍率：
  1. 视觉倍率：用户看到和操作的缩放倍率，允许继续到 600%
  2. 内部渲染倍率：canvas 实际绘制倍率，单独封顶，避免大图爆掉

## 实现
- `renderMaxScale` 恢复为 `MAX_SCALE = 6`
- 新增 `MAX_INTERNAL_RENDER_SCALE = 2.4`
- 画布渲染时：
  - `visualCellSize = baseCellSize * scale`
  - `renderScale = min(scale, MAX_INTERNAL_RENDER_SCALE)`
  - 再叠加单边尺寸和总像素面积的安全裁剪，得到最终内部渲染倍率
- `canvas.style.width / height` 按视觉倍率设置
- `canvas.width / height` 按内部渲染倍率设置
- 绘制逻辑全部切换到内部渲染坐标，但用户点击命中仍按视觉倍率判断

## 结果
- 用户可继续把制作模式放大到更高倍率查看色号。
- 大图不再要求内部 canvas 跟着 600% 一起膨胀，从而避免重回黑屏问题。
- 这是一种在不重写为视口渲染的前提下，更适合当前结构的折中实现。
