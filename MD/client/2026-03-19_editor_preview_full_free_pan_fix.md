# 2026-03-19 编辑页预览区完全自由拖动修复

## 问题
虽然之前已经支持部分拖动，但上下和左右仍然不是完全一致的自由拖拽：某些方向会受滚动式平移影响，用户感知上仍然不够自由。

## 修复
- 文件：`perler-beads/src/components/InteractiveCanvas.tsx`
- 将预览区非编辑状态下的拖动逻辑统一为自由偏移：
  - 拖动时不再区分某个方向是否存在滚动空间
  - 上下左右全部统一使用 `offset + translate(x, y)` 做自由拖拽
- 保留首次适配和重新适配时的偏移重置，避免旧偏移残留。

## 结果
- 预览区在放大后可完全自由拖动。
- 即使某一方向已经铺满预览区，也依然可以继续向该方向拖动查看。

## 验证
- `cmd /c npm run build` 通过。
