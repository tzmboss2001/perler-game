# 移除网格圆球效果和缩放限制调整

**日期**: 2026-01-30
**类型**: 功能优化

## 需求描述

1. 图片放大比例封顶改为6倍（原来是10倍）
2. 移除预览图放大后网格中显示的圆球/珠子高亮效果

## 修改文件

1. `src/components/InteractiveCanvas.tsx`
2. `src/services/colorMatchService.ts`

## 修改内容

### 1. 最大缩放比例改为6倍

**文件**: `src/components/InteractiveCanvas.tsx`

**修改前**:
```typescript
const MIN_SCALE = 0.1;
const MAX_SCALE = 10;
```

**修改后**:
```typescript
const MIN_SCALE = 0.1;
const MAX_SCALE = 6;
```

### 2. 移除网格圆球效果

**文件**: `src/services/colorMatchService.ts`

在 `renderBeadsToCanvas` 函数中，移除了当 `cellSize >= 10` 时绘制渐变圆球的代码。

**修改前**:
```typescript
// 绘制珠子
ctx.fillStyle = bead.hex;
ctx.fillRect(px, py, cellSize, cellSize);

// 当单元格足够大时，绘制珠子效果
if (cellSize >= 10) {
  // 创建径向渐变实现珠子效果
  const centerX = px + cellSize / 2;
  const centerY = py + cellSize / 2;
  const radius = cellSize * 0.4;

  const gradient = ctx.createRadialGradient(
    centerX - radius * 0.3,
    centerY - radius * 0.3,
    0,
    centerX,
    centerY,
    radius
  );

  // 解析颜色并创建高亮效果
  const r = parseInt(bead.hex.slice(1, 3), 16);
  const g = parseInt(bead.hex.slice(3, 5), 16);
  const b = parseInt(bead.hex.slice(5, 7), 16);

  const lighterR = Math.min(255, r + 60);
  const lighterG = Math.min(255, g + 60);
  const lighterB = Math.min(255, b + 60);

  gradient.addColorStop(0, `rgb(${lighterR}, ${lighterG}, ${lighterB})`);
  gradient.addColorStop(0.7, bead.hex);
  gradient.addColorStop(1, bead.hex);

  ctx.beginPath();
  ctx.arc(centerX, centerY, radius, 0, Math.PI * 2);
  ctx.fillStyle = gradient;
  ctx.fill();
}
```

**修改后**:
```typescript
// 绘制珠子（纯色方块）
ctx.fillStyle = bead.hex;
ctx.fillRect(px, py, cellSize, cellSize);
```

## 效果

- 最大缩放比例限制为6倍（600%）
- 放大预览图后，网格中只显示纯色方块，不再显示3D圆球效果
- 渲染性能略有提升（减少了渐变计算）
- 视觉效果更简洁，更接近实际拼豆成品的样子
