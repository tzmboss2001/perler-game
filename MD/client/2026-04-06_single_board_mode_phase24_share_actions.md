# 单板模式第二十四阶段：完成态分享与收尾动作去重

## 本次目标
- 收掉单板模式全部完成态底部重复的“导出图纸”入口。
- 把“分享作品”正式纳入全部完成态收尾动作。
- 保持顶部与底部收尾动作分工更清晰。

## 实现内容
1. 保留底部主按钮 `导出图纸` 作为首要收尾动作。
2. 保留底部次级按钮 `回到编辑`。
3. 将底部原本重复的第二个 `导出图纸` 改为 `分享作品`。
4. 将底部原本额外的 `分享作品` 改为 `查看整图`，这样完成态底部三类动作分别对应：
   - 回到编辑
   - 导出图纸
   - 分享作品 / 查看整图
5. 顶部继续保留：
   - 分享作品
   - 回到编辑
   - 查看整图
   - 导出图纸

## 影响
- 全部完成状态下不再出现两个“导出图纸”按钮。
- 分享动作成为明确的完成态出口，不再只是附加能力。
- 顶部和底部的动作分工更清楚，收尾态更像完整工作流。

## 验证
- `cmd /c npm run build`
- MCP 检查单板模式全部完成态页面：
  - 顶部包含分享作品、回到编辑、查看整图、导出图纸
  - 底部不再重复出现两个导出图纸按钮
  - 底部动作改为导出图纸、回到编辑、分享作品、查看整图
