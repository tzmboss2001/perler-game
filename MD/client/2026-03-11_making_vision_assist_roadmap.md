# 视觉辅助引导与进度识别技术路线

日期：2026-03-11
范围：客户端一期 MVP，本地完成，暂不发布公网

## 目标
- 用户不安装任何额外软件，直接在项目自带页面里打开视觉辅助。
- 在制作模式内完成摄像头取景、进度识别、下一步放豆引导。
- 先做稳定可用的一期，不做硬件发光板，不做外部 App。

## 一期范围
1. 制作页内置视觉辅助入口
2. 浏览器摄像头接入（getUserMedia）
3. 用户手动四角校准
4. 用户点击空孔，记录空板参考色
5. 按当前拼豆板逐格识别已完成 / 待放 / 错放
6. 自动给出当前优先颜色和下一步位置提示
7. 多板作品按板切换识别

## 技术方案
### 1. 接入位置
- 页面：`src/pages/mobile/MakingPage.tsx`
- 原因：制作模式已经有图纸、区块、颜色上下文，最适合直接接进度识别。

### 2. 板级数据拆分
- 依据 `recommendBoard(width, height)` 得到推荐板规格。
- 将整张图纸按物理板尺寸切分为多个板块。
- 边缘残板也按完整板尺寸补齐 `null`，保证摄像头识别和真实板面一致。

### 3. 摄像头与校准
- 前端直接调用 `navigator.mediaDevices.getUserMedia`。
- 用户依次点击：左上、右上、右下、左下。
- 再点击一个空孔，取样空板颜色。
- 一期采用手动校准，不额外依赖 OpenCV 或外部安装。

### 4. 逐格识别
- 每次从视频帧抓取当前画面到隐藏 canvas。
- 通过四角点做四边形插值，算出每个格子的中心点。
- 在中心点附近采样平均 RGB。
- 与目标豆色、空板参考色做距离比较。
- 识别状态：`matched / missing / wrong / empty / extra`。

### 5. 引导策略
- 优先找当前还有剩余的颜色。
- 已正确放置：绿色圈
- 下一步要放：蓝色数字序号
- 错放：红叉
- 同时显示当前板完成度、当前优先颜色、每种颜色剩余数量。

## 为什么先不用外部软件或 OpenCV
- 一期场景固定：单手机/平板摄像头、固定拼豆板、固定网格。
- 先用浏览器原生能力 + 规则算法就能把核心价值做出来。
- 后续如果要提高自动校准、抗光照、抗遮挡，再逐步引入 OpenCV 或更强视觉算法。

## 二期预留
1. 自动识别拼豆板四角
2. 抗手遮挡与抗光照波动
3. 错放颜色更细的纠错提示
4. 按颜色分批引导与一键切换下一颜色
5. 摄像头识别结果缓存和更稳的采样平滑
