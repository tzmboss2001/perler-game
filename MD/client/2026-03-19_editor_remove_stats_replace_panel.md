# 2026-03-19 编辑页移除统计入口与换色功能

## 问题
- 编辑图案页同时提供“统计/换色”和制作模式换色，功能重叠。
- 统计面板承载了换色、排除色、智能合并等操作，页面过重，不符合当前“编辑页只做前置调整，制作模式再处理缺色换色”的产品定位。

## 处理
- 删除编辑图案页中的“统计/用量”悬浮入口。
- 删除统计面板整块 UI。
- 删除编辑页里的换色、还原、排除颜色、智能合并相关状态与处理函数。
- 保留基础 `statistics` 计算数据，继续供分享图纸和购物清单使用。
- 同步移除生成逻辑里的排除色分支，避免残留无效参数。

## 影响文件
- `perler-beads/src/pages/mobile/EditorPage.tsx`

## 验证
- 执行 `cmd /c npm run build`
- 构建通过。

## 结果
- 编辑页只保留“色系/配色”和“抠图/去背景”主入口。
- 换色能力统一收敛到制作模式，产品路径更清晰。
