# 2026-03-15 背景处理文案收口

## 背景
背景处理面板已经完成主次分层，但部分提示文案仍偏长、偏工具化，不够像普通用户可直接理解的“去背景”指引。

## 本次调整
1. 缩短面板顶部说明：
   - 改为 `先试一键去背景，不够理想再用智能抠图或高级微调。`
2. 高级微调提示简化：
   - 改为 `默认先用上面的两个主按钮`
3. 底部状态提示改成更口语化：
   - `点一下背景颜色，系统会帮你圈出同色区域。`
   - `不对的地方再点一下排除，然后点“应用透明”。`
   - `已开启手动擦除，点击格子就会去掉背景。`
   - `已开启手动补回，点击透明格即可恢复。`
4. 按钮文案改得更直白：
   - `确认透明` -> `应用透明`
   - `退出` -> `返回编辑`

## 修改文件
- `perler-beads/src/pages/mobile/EditorPage.tsx`

## 验证
- 前端构建：`cmd /c npm run build` 通过
- 预期结果：背景处理模式的说明、状态提示和按钮文案更短、更口语化。

## 结论
背景处理模式已经更接近“傻瓜去背景工具”的表达方式，普通用户更容易理解下一步该做什么。
