# 制作页视觉辅助：切板状态提示

## 日期
- 2026-03-12

## 目标
- 在多板场景下给用户明确反馈：当前已经切到哪一块板。
- 区分手动切板、自动切板、定位当前板这三类切换来源，避免用户不知道系统是否已经切板。

## 本次修改
- 文件：[BoardVisionAssistModal.tsx](/D:/work/web/perler-beads-creator/perler-beads/src/components/BoardVisionAssistModal.tsx)

### 1. 新增切板提示文案
- 新增 `BoardSwitchReason`：
  - `manual`
  - `auto`
  - `locate`

- 新增 `getBoardSwitchNoticeText()`，按切板来源生成提示：
  - 手动切板：`已切到板X`
  - 自动切板：`已自动切到板X`
  - 定位当前板：`已定位到板X`

### 2. 切板逻辑统一带原因
- `switchBoardPreservingCalibration()` 现在除了板索引，还接收切板来源。
- 切换时会同步写入一条临时提示，不影响四角和空板取样状态。

### 3. 提示自动消失
- 新增 `boardSwitchNotice` 状态。
- 新提示显示后约 `2400ms` 自动消失，避免长期占用界面空间。

### 4. 视觉样式
- 在板签区域下方新增绿色提示条样式：
  - 轻量
  - 不遮挡主内容
  - 便于真机使用时快速确认切板结果

## 验证

### 本地构建
- 命令：`cmd /c npm run build`
- 结果：通过

### MCP 验证
- 页面：`http://127.0.0.1:3005/mobile/making?test=1`
- 注入双板草稿，打开制作页 -> 设置 -> 视觉辅助

#### 验证点 1：切板提示出现
- 点击 `板2`
- 弹层立即出现：
  - `已切到板2`

#### 验证点 2：当前板同步变化
- 点击 `板2` 后：
  - `当前板尺寸` 从 `104 × 20` 切到 `1 × 20`
- 说明切板提示和当前板上下文是一致的

## 结果
- 多板视觉辅助现在除了能切板，还能给出明确反馈。
- 这一步主要提升真机使用时的可理解性，用户能更清楚地知道当前系统正在识别哪一块板。
