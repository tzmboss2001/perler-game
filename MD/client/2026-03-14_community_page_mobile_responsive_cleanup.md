# 2026-03-14 社区页小屏响应式收口

## 问题
- 社区独立页在窄屏手机下存在信息拥挤问题。
- 搜索栏、排序区和双列卡片在小屏下容易挤压，卡片标题也容易被截断得过短。

## 处理
- 为 `CommunityPage.tsx` 新增 `viewportWidth` 监听。
- 根据屏幕宽度增加两档响应式：
  - `<= 390px`：排序区改为左对齐并撑满一行。
  - `<= 360px`：双列瀑布流切为单列，搜索栏和卡片间距压缩。
- 卡片标题在极窄屏下改为最多两行显示，避免只剩一小段。
- 卡片底部统计区在极窄屏下允许换行，减少挤压。

## 影响范围
- 客户端
- 文件：`perler-beads/src/pages/mobile/CommunityPage.tsx`

## 验证
- 运行 `npm run build`，前端构建通过。

## 说明
- 本轮未改社区数据逻辑，只处理小屏布局。
