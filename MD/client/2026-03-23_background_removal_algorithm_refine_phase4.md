# 背景去除算法继续优化记录（三）

- 日期：2026-03-23
- 范围：客户端

## 本次目标
- 提高一键去背景对复杂背景、多背景色场景的覆盖率。
- 不再过度依赖单一主背景色。

## 本次修改
1. 边缘背景色增加侧边命中统计
- 文件：`perler-beads/src/services/backgroundRemovalService.ts`
- 对每个边缘颜色，不只统计总覆盖率，还统计它出现在：
  - 上边
  - 右边
  - 下边
  - 左边
  这四条边上的命中次数。

2. 多边缘背景色纳入候选
- 过去的算法更偏向“主背景色 + 与主色接近的少数颜色”。
- 现在改成：
  - 如果某种颜色同时出现在两条以上边缘，且边缘覆盖达到一定强度，就算它和主背景色差异稍大，也会纳入背景候选。
- 这样可以覆盖：
  - 树叶、天空、阴影这类多背景色混合的场景
  - 背景并非单一纯色的图片

3. 单边强背景也保留
- 如果某种颜色在单一边缘上占比非常高，也会继续纳入背景候选。
- 避免因为侧边统计收严，反而漏掉明显纯色背景。

## 预期改善
- 一键去背景不再只会识别出极少数格子。
- 对复杂背景图，应该能先圈出更大一片外部背景区域。
- 用户后续只需要用连片选背景、点格擦除做少量补救。
