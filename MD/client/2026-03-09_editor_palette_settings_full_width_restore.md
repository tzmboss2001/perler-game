# 编辑页色系设置入口恢复整行布局

日期：2026-03-09
范围：客户端

## 问题

编辑页里把“色系设置”入口改成紧凑横向布局后，实际仍然占用一整行，但视觉收益不明显，反而让入口层级变弱。

## 处理

将编辑页“色系设置”入口恢复为整行触发区：

- 恢复为整行按钮结构，点击区域更明确
- 恢复左侧标题 + 摘要、右侧齿轮图标的标准布局
- 恢复卡片原始内边距，保持和编辑页其他工具区一致

## 修改文件

- `perler-beads/src/pages/mobile/EditorPage.tsx`

## 验证

- 执行 `npm run build`，构建通过
- 重新发布到公网 `app-pd.shop888.vip`

## 结果

编辑页里的“色系设置”入口已恢复成整行布局，点击范围更直观，和当前页面的其他工具区样式保持一致。
