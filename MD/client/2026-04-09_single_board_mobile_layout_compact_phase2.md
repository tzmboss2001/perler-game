# 2026-04-09 单板模式手机布局进一步收紧

## 本次修改
- 手机单板模式不再显示独立的“继续上次制作”卡片，避免首屏再多占一层高度。
- 将手机单板模式顶部摘要收成一行，只保留进度、剩余块数和一个短文案策略开关。
- 当存在未完成板且不在当前板时，将“继续未完成”合并进顶部摘要行，而不是单独占一整行卡片。
- 手机单板模式的切板导航改成更紧凑的结构：多板时保留左右箭头、缩略图和完成按钮；单板时仅保留定位和完成。
- 手机单板模式底部选中状态卡继续压缩，隐藏重复的完成进度数字和“再次点击可取消选中”提示，让画布优先。
- 继续收紧手机单板模式的导航按钮、缩略图卡片和完成按钮尺寸。

## 目标
- 让手机端单板模式首屏更接近“画布是主工作区，信息只做辅助”。
- 弱化“板1/板2”这类系统内部编号在用户界面的存在感。
- 减少顶部和底部对主预览区的挤压。
