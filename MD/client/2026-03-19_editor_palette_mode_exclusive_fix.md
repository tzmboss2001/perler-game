# 2026-03-19 编辑页系统色系与我的颜色二选一模式修复

## 问题
色系面板里原来可以同时操作系统色数方案和“我的颜色”，从用户理解上像是在同时启用两套颜色方案，逻辑不清楚。

## 修复
- 文件：`perler-beads/src/pages/mobile/EditorPage.tsx`
- 调整为明确的二选一模式：
  - 未启用“我的颜色”时：显示系统色数按钮和系统色系说明。
  - 启用“我的颜色”后：隐藏系统色数按钮与系统应用按钮，改为显示“当前仅使用我的颜色生成，系统色数已停用”。
- 面板标题摘要也同步改为两种模式下的不同文案。

## 结果
- 用户不会再同时编辑系统色系和我的颜色。
- 启用“我的颜色”后，界面会明确提示当前已进入“我的颜色模式”。

## 验证
- `cmd /c npm run build` 通过。
