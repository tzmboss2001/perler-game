# 2026-03-29 制作模式现实豆板坐标系

## 背景
制作模式原先点击格子后只显示全局行列坐标，跨多块豆板时无法体现现实世界中的“第几块板 + 板内第几列/第几行”。这会让用户在两块或更多豆板拼接时，横向和纵向都需要自己换算。

## 本次修改
1. 制作模式点击格子后的坐标提示改成现实豆板坐标：
   - 显示 `板N`
   - 显示板内 `列X · 行Y`
2. 语音播报同步改成现实豆板口径：
   - `第N块板，第X列，第Y行`
3. 横向和纵向都按现实豆板重新从 1 开始，不再跨板连续编号。
4. 坐标换算基于当前制作模式采用的现实豆板尺寸：
   - 小于等于 54：按 54 板
   - 小于等于 78：按 78 板
   - 更大：统一按 104 板重复

## 修改文件
- `perler-beads/src/pages/mobile/MakingPage.tsx`
- `perler-beads/src/components/CoordinateTooltip.tsx`
- `perler-beads/src/utils/colorUtils.ts`

## 效果
1. 多块豆板时，横向和纵向坐标都能直接对应现实板面。
2. 用户不需要再把 105、106 这类跨板连续编号换算回第二块板。
3. 点击格子时的视觉提示和语音提示口径一致。

## 验证
- `cmd /c npm run build` 通过。
