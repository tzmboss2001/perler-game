# 2026-03-19 编辑页预览区拖动平移修复

## 问题
编辑图案页在缩放后，预览区虽然能看到局部，但用户无法通过拖动画布来移动视野，只能停留在当前局部位置。

## 根因
- `InteractiveCanvas` 里虽然存在 `isPanning`、`panStart` 等平移状态，但实际没有接入事件逻辑。
- 非编辑状态下，鼠标和触摸拖动不会驱动画布容器滚动。

## 修复
- 文件：`perler-beads/src/components/InteractiveCanvas.tsx`
- 新增预览区可平移判断：当画布尺寸超过预览区时，允许拖动平移。
- 非编辑模式下：
  - 鼠标按下并拖动，会按拖动位移更新容器 `scrollLeft / scrollTop`
  - 单指触摸拖动，也会平移预览区并阻止页面跟着滚动
- 光标状态同步调整为 `grab / grabbing`

## 结果
- 编辑图案页缩放后，用户可以直接拖动预览图位置查看局部。
- 不需要依赖再次缩放或重置，拖动行为符合常见图片预览体验。

## 验证
- `cmd /c npm run build` 通过。
