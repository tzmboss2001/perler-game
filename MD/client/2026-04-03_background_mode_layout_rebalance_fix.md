# 背景处理模式按钮可见性与预览区尺寸修复

- 日期：2026-04-03
- 文件：`perler-beads/src/pages/mobile/EditorPage.tsx`
- 文件：`perler-beads/src/components/InteractiveCanvas.tsx`

## 问题
1. 背景处理模式下，`回退一步 / 确定 / 一键去背景` 三个按钮经常掉到首屏外，看起来像消失。
2. 预览区被压得过小，首屏可操作区域不合理。

## 原因
- 背景处理模式底部操作区之前依赖 `sticky + 底部导航偏移`，在窄屏下容易被推到视口外。
- 预览区本身没有真正占满中间剩余高度，且内部 canvas 仍按固定背景模式高度工作，导致整体布局不平衡。

## 修复
1. 背景处理覆盖层改为真正的全屏四段式布局：头部、预览区、缩放区、底部操作区。
2. 覆盖层改成 `100dvh` 并隐藏整体滚动，提升层级到足以盖住底部导航。
3. 预览区改为 `flex: 1`，吃掉中间剩余空间。
4. `InteractiveCanvas` 新增 `backgroundModeFillParent`，背景处理模式下允许 canvas 容器完全填充父级高度，而不是继续使用固定 `vh` 高度。
5. 底部按钮区取消 `sticky` 方案，改成页面结构中的固定底部区块。

## 结果
背景处理模式下，首屏能稳定看到：
- 标题栏
- 预览区
- 预览缩放
- `回退一步 / 确定 / 一键去背景`

同时预览区高度会优先吃掉剩余空间，不再被压成过小的可视区域。
