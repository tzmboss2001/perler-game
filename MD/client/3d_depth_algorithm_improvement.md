# 3D深度算法改进 - 纯算法方案

## 日期
2024-02-04

## 改动说明

### 问题背景
用户希望实现3D拼豆图纸功能，但不希望依赖付费的AI深度估计API。之前的实现使用简单的亮度作为深度，效果不理想。

### 解决方案
实现了基于**距离变换（Distance Transform）**的纯算法深度估计方案，专为卡通头像和简单物品设计。

### 核心算法

1. **前景蒙版检测**
   - 通过透明度（alpha >= 128）区分前景和背景
   - 透明区域视为背景（深度=0）

2. **距离变换**
   - 使用两遍扫描算法计算每个前景像素到最近背景/边缘的距离
   - 支持对角线距离（1.4倍权重），产生更自然的圆形效果

3. **深度归一化**
   - 将距离值归一化到0-255范围
   - 边缘像素深度浅，中心像素深度深

### 改动文件
- `src/services/3d/depthService.ts`
  - 重写 `generateMockDepth()` 函数
  - 新增 `computeDistanceTransform()` 距离变换函数
  - 新增 `generateEnhancedDepth()` 增强版本（混合距离+亮度）

### 算法优势
- **零成本**：完全本地计算，无需API调用
- **自动化**：用户无需手动调整，程序自动计算
- **适用场景**：卡通头像、简单物品等轮廓清晰的图片

### 使用建议
- 使用**透明背景**的PNG图片效果最佳
- 主体轮廓清晰的图片效果更好
- 可通过"背景阈值"参数调整深度截止点

### 测试结果
- 生成成功：5层，4060颗珠子，16种颜色
- 需要使用透明背景的图片才能看到明显的层次效果

## 关于BMW汽车例子的说明
用户提供的BMW汽车3D像素模型示例（bmw_viewer.html）是**完全手工编码**的，不是从2D图片自动生成的。每个方块的位置都是设计师手动设计并用代码写出来的。这与我们的需求（从2D图片自动生成3D模型）是完全不同的场景。
