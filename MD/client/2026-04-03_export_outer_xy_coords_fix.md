# 2026-04-03 导出图纸四周坐标尺修复

## 问题
- 导出图纸虽然开启了显示坐标刻度，但实际只在左侧和底部显示坐标。
- 用户从图纸外周查看时，会误以为没有完整的 XY 坐标尺。
- 坐标还需要继续按现实拼豆板规格循环编号，而不是全局连续编号。

## 修复
1. 单图导出 `renderBeadsToCanvas`
   - 坐标尺改为四周显示：上、右、下、左。
   - 增加 top/right gutter，避免坐标被裁切。
2. 带珠子清单导出 `renderBeadsToCanvasWithList`
   - 图案区四周都显示坐标尺。
   - 珠子清单区域整体右移，避开右侧坐标尺。
3. 分页打印导出 `renderBeadsPaginated`
   - 每页图案区四周都显示坐标尺。
   - 继续按板内坐标循环编号。
4. 坐标编号规则保持不变
   - 以所选豆板规格为最大值。
   - 跨板后重新从 1 开始。

## 影响
- 普通导出、带清单导出、分页打印版导出现在都会在图案四周显示完整的 XY 坐标尺。
- 坐标最大值继续受所选豆板规格限制，例如 54 板最大显示到 54，跨板后重新从 1 开始。

## 验证
- 执行 `npm run build` 通过。
