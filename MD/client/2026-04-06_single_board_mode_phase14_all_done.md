# 2026-04-06 单板模式第十四阶段：全部完成状态与收尾入口

## 本次目标
- 继续压缩单板模式顶部结构
- 完善全部完成状态
- 进一步把控制区做成单板制作专用布局

## 本次完成
1. 新增“全部板已完成”独立收尾入口
- 当所有板都完成时，顶部恢复入口不再显示“继续上次制作”。
- 改为独立的全部完成入口：
  - `全部板已完成`
  - `10/10 · 可以直接收尾或导出图纸`
  - 主按钮：`导出图纸`
- 这样首屏会直接进入收尾状态，而不是还保留“继续制作”语义。

2. 顶部摘要同步切换到全部完成态
- 单板摘要会显示：
  - `10/10 · 100% · 已全部完成`
  - `已可收尾或导出图纸`
  - 状态标签：`全部完成`

3. 折叠态继续压缩
- 收起总览时，不再显示进度条，只保留更紧凑的摘要与导航。
- 自动切板策略文案收短为：
  - `自动切下一板`
  - `完成后停留当前板`

4. 底部任务条收尾化
- 全部完成后，底部任务条切换为：
  - `全部完成`
  - `10/10`
  - `剩余 0`
  - 主按钮：`导出图纸`
- 不再显示“完成板N/继续板N”这类制作中动作。

5. 全部完成主按钮行为收口
- 顶部和底部的主按钮在全部完成状态下都直接打开导出弹窗。
