# 2026-04-08 制作模式缩放时高亮延迟修复

## 问题
- 制作模式在放大或缩小时，底图会立即缩放。
- 但区块高亮、颜色高亮和焦点框会晚半拍更新，用户会看到高亮边界在缩放过程中出现短暂不同步。

## 根因
- 底图 canvas 的缩放依赖 React 状态与 CSS transform，更新很快。
- 高亮 overlay 和底图重绘之前使用 `useEffect`，会在浏览器完成一帧绘制之后再执行。
- 结果就是缩放发生时，用户先看到新的底图位置，随后才看到新的高亮位置，形成明显的后一拍延迟。

## 修复
- 将 `MakingPage.tsx` 中两处核心渲染 effect：
  1. 底图 canvas 重绘
  2. overlay 高亮层重绘
- 从 `useEffect` 改为 `useLayoutEffect`。

## 结果
- 缩放状态变更后，会在浏览器真正绘制到屏幕前完成底图与高亮层同步更新。
- 区块边界、颜色高亮、焦点框在缩放过程中会更贴手，不再出现明显慢半拍。

## 验证
- `cmd /c npm run build`
- MCP 回到制作模式，观察缩放时高亮与底图是否同步
