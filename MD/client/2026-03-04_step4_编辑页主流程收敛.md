# 2026-03-04 第4项优化：编辑页主流程收敛

## 目标
把编辑页主链路收敛为单一主动作，降低新手决策成本。

## 改动
- 文件：`perler-beads/src/pages/mobile/EditorPage.tsx`

1. 主按钮收敛
- 原主区为三按钮：`重新选图 / 分享 / 开始制作`
- 调整为两级结构：
  - 主按钮：`保存并开始制作`
  - 次按钮：`返回选图`
  - 次级入口（弱化展示）：`分享图纸`

2. 分享入口降级
- 新增 `handleShareClick` 统一处理分享登录校验与弹窗打开。
- 分享从主按钮区移到下方次级入口，视觉与注意力权重降低。

## 用户视角（通俗）
- 之前：你会看到多个“都像重点”的按钮，不确定先点哪个。
- 现在：你一眼就知道该点“保存并开始制作”，其它操作留在次级入口。

## MCP 回归
- 页面：`/mobile/editor`
- 结果：
  - 可见 `返回选图`、`保存并开始制作`、`分享图纸`
  - 点击 `分享图纸` 可正常弹出登录确认：`请先登录 / 登录后才能分享图纸`
- 控制台：无新增错误（仅 React Router v7 预告 warning）
