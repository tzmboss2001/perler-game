# 背景处理模式底部按钮不可见修复

时间：2026-04-03

## 问题
背景处理模式中，`回退一步 / 确定 / 一键去背景` 有时会在小屏或较高预览高度下被挤出可视区域。原因是去背景覆盖层被设置为不可纵向滚动，而预览区又占用了过多垂直空间，导致底部操作区虽然已渲染，但用户看不到。

## 修复
1. 背景处理覆盖层改为允许纵向滚动。
2. 预览区从强占剩余空间改成按内容高度占位。
3. 底部操作区增加 `marginTop: auto`，保持在内容尾部。
4. 背景处理预览默认高度从 `58vh / min 350px` 收到 `46vh / min 260px`，给缩放区和主按钮释放空间。

## 结果
背景处理模式中底部三个主按钮重新可见，缩放区、按钮区和预览区可以同时出现在可滚动页面内，不会再因为页面高度被锁死而“找不到按钮”。
