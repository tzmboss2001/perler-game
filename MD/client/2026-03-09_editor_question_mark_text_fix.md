# 编辑页问号按钮文案修复

日期：2026-03-09
范围：客户端

## 现象

编辑图案页面中，部分按钮和提示文案显示成了连续的 `?`，用户无法理解这些按钮的作用。

## 定位

- 通过代码扫描定位到 `EditorPage.tsx` 下方内容区一组新改动文案被错误写成 `?`
- 受影响内容包括：
  - 网格宽度
  - 鲜艳度
  - 流畅 / 一般 / 可能卡
  - 返回选图
  - 保存并开始制作
  - 分享图纸
  - 主流程提示文案

## 处理

- 将上述用户可见文案全部恢复为正常中文
- 重新构建并发布到公网

## 修改文件

- `perler-beads/src/pages/mobile/EditorPage.tsx`

## 验证

- 执行 `npm run build`，构建通过
- 发布到公网 `app-pd.shop888.vip`

## 结果

编辑页中原先显示为 `?` 的按钮和提示文案已恢复正常。
