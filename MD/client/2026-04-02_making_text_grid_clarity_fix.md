# 2026-04-02 制作模式高倍率文字与网格清晰度优化

## 问题
- 修复制作模式黑屏后，制作页改成了“内部安全渲染 + 外层视觉缩放”。
- 在高倍率下，格子里的色号数字和字母会随着整张画布继续被放大，显得又大又糊。
- 网格线也会随视觉缩放一起变粗、发虚，影响制作可读性。

## 根因
1. 画布使用 CSS transform 放大后，色号和网格线的最终可见尺寸仍然随 `displayScale` 无限增长。
2. canvas 默认平滑插值开启，放大后的文本和细线会出现模糊。

## 修改
- 在 `perler-beads/src/pages/mobile/MakingPage.tsx` 中：
  - 关闭 `ctx.imageSmoothingEnabled`。
  - 画布样式改为 `imageRendering: pixelated`。
  - 新增基于最终视觉倍率 `visualDisplayScale` 的清晰度控制。
  - 基础细格线、豆板分区线、高亮边框、中心十字都改为按最终屏幕可见粗细反推绘制宽度，不再跟随放大无限变粗。
  - 板号与格内色号字体改为“最终可见字号封顶”，避免格子变大后字也继续无限变大。

## 验证
- 执行 `cmd /c npm run build`，通过。
- MCP 真实测试：
  - 打开制作模式
  - 将缩放倍率拉到 `600%`
  - 截图 `TEMP/making_text_grid_clarity_after_fix.png`
- 结果：
  - 色号在高倍率下保持清晰可读
  - 网格线明显收细，不再出现放大后整层发糊的效果
  - 页面未黑屏

## 结果
- 制作模式在高倍率下的字母数字和网格清晰度明显改善。
- 色号尺寸以“最佳可读性”为准封顶，不再随格子无限变大。
- 网格线保持清晰、稳定，适合高倍率制作查看。
