# 2026-04-02 制作模式高倍率文字与网格进一步锐化

## 问题
- 上一轮虽然修复了制作模式高倍率发糊问题，但高倍率下的色号和网格线仍然偏粗。
- 用户继续反馈：放大后文字和网格仍不够利落，影响按图制作。

## 修改
- 在 `perler-beads/src/pages/mobile/MakingPage.tsx` 中继续优化高倍率绘制：
  1. 新增基于像素对齐的 `crispStrokeVertical` / `crispStrokeHorizontal`，对细线进行半像素对齐，减少发虚。
  2. 进一步收细基础网格线、豆板分区线和高亮边框线宽。
  3. 板号字号继续收紧，避免高倍率时标签压住图案。
  4. 色号字体改为更适合小尺寸高对比显示的等宽字体栈，并增加描边，提升深浅底色上的可读性。
  5. 色号字号再次封顶，避免继续放大时数字字母显得臃肿。

## 验证
- 执行 `cmd /c npm run build`，通过。
- MCP 真实测试：
  - 打开制作模式
  - 将缩放倍率拉到 `600%`
  - 截图 `TEMP/making_text_grid_clarity_after_fix_v2.png`
- 结果：
  - 色号在高倍率下更利落，深浅底色上都更容易辨认
  - 网格线更细、更稳定
  - 页面未黑屏

## 结果
- 制作模式高倍率下的可读性进一步提升。
- 现在高倍率制作时，字和线更接近“制作工具”而不是“被放大的整张图片”。
