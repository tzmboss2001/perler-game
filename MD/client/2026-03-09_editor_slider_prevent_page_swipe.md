# 编辑页滑杆误触发页面侧滑修复

日期：2026-03-09
范围：客户端

## 问题

真机上拖动编辑页滑杆时，浏览器会把横向手势识别成页面侧滑或返回手势，导致页面被整体拉动，用户无法稳定调节鲜艳度、网格宽度等参数。

## 根因

- 滑杆本身是横向手势控件，但没有明确声明由控件自己接管横向拖动
- 页面容器也没有阻断横向过度滚动
- 移动端浏览器因此把滑杆拖动误判成页面导航手势

## 处理

增加两层限制：

- 编辑页主容器和内容区增加 `overscrollBehaviorX: 'none'`
- 所有滑杆统一增加 `touchAction: 'pan-y'`

这样浏览器会保留纵向页面滚动，但不会再把滑杆的横向拖动当成页面切换手势。

## 修改文件

- `perler-beads/src/pages/mobile/EditorPage.tsx`

## 验证

- 执行 `npm run build`，构建通过
- 发布到公网 `app-pd.shop888.vip`

## 结果

真机上拖动编辑页滑杆时，页面不再被误触发为侧滑切换，滑杆调节会更稳定。
