# 2026-03-05 我的方案丢失感知修复（云端与本地双列表）

## 问题
- 用户已登录时，`我的方案` 只显示云端列表。
- 当云端保存失败回落到本地保存时，用户会误以为“方案丢失”。

## 修复
- 修改 `perler-beads/src/pages/mobile/ProfilePage.tsx`：
  - 已登录状态下展示“云端方案 + 本地方案（保底）”双列表。
  - 计数改为云端和本地总数。
  - 本地方案卡片支持继续制作、分享、删除。
- 修改 `perler-beads/src/pages/mobile/EditorPage.tsx`：
  - 本地保存时对 `originalImage` 做体积兜底（过大时降级为缩略图）。
  - 首次本地保存失败后自动重试一次（最小化载荷）降低 localStorage 超限导致的失败概率。

## 结果
- 用户在“我的方案”可以看到云端失败回落的本地方案，不再出现“看起来丢失”的问题。

## 验证
- `npm run build` 通过。
