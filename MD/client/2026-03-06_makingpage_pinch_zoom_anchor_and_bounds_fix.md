# 2026-03-06 真机双指缩小画布丢失修复

## 问题现象
- 在制作页双指缩小后，预览画布会跑到角落，视觉上像“图没了”。

## 原因
- 缩放只改了 `scale`，没有按手势中心修正 `translate`。
- 位移没有边界夹紧，缩小后原有平移值超出可视范围。

## 修复内容
- 文件: `perler-beads/src/pages/mobile/MakingPage.tsx`
- 新增统一缩放逻辑：`applyScaleAtPoint()`
  - 以手势中心/滚轮点/按钮中心为锚点缩放。
- 新增位移边界逻辑：`clampTranslate()`
  - 根据画布尺寸与容器尺寸，限制平移范围，避免画布被拖出可视区。
- 拖动逻辑改为统一走 `shiftTranslate()`，自动夹紧边界。
- 双指缩放、滚轮缩放、+/-按钮缩放全部接入同一套逻辑。
- 屏幕尺寸变化时自动重新夹紧当前位移。

## 验证
- `npm run build` 通过。

## 用户侧变化
- 双指放大/缩小时，图案会围绕手势中心缩放，不再突然跑到角落。
- 缩小后仍保持在可视区域，不会出现“画布消失”。
