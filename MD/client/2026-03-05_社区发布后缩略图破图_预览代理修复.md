# 2026-03-05 社区发布后缩略图破图（预览代理修复）

## 问题
- 真机测试版（`vite preview`）发布新作品后，社区列表出现图片加载失败。

## 根因
- 社区图片 URL 为相对路径（如 `/thumbnails/post_x.png`）。
- `preview` 模式默认未代理该路径到后端，导致资源命中前端静态目录快照，发布后的新文件不可见。

## 修复
- 修改 `perler-beads/vite.config.ts`：
  - `server.proxy` 新增：
    - `/thumbnails -> http://localhost:8012`
    - `/finished-works -> http://localhost:8012`
  - `preview.proxy` 同步新增：
    - `/api`
    - `/thumbnails`
    - `/finished-works`

## 验证
- `npm run build` 通过。
- 访问 `http://127.0.0.1:4173/thumbnails/post_11.png` 返回 `200`。
