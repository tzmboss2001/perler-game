# 编辑页背景微调命名与确认按钮优化

- 日期：2026-03-16
- 影响范围：客户端编辑页背景处理模式
- 文件：`perler-beads/src/pages/mobile/EditorPage.tsx`

## 问题
背景处理模式里的“手动选背景 / 手动擦除 / 手动补回”命名不够贴近真实行为，用户容易误解为必须先选再擦。同时底部“应用透明”按钮文案不够直白，也不够醒目。

## 修复
1. 按真实功能重命名：
   - `手动选背景` -> `连片选背景`
   - `手动擦除` -> `点格擦除`
   - `手动补回` -> `补回误删`
2. 对应说明文案同步改成更口语化表达。
3. `应用透明` 改为 `应用去背景`。
4. 把确认按钮改为整行宽度，提升可见性和点击优先级。

## 结果
- 用户更容易理解：
  - 连片选背景 = 点一个格子，选一片连通区域
  - 点格擦除 = 点哪个删哪个
  - 补回误删 = 恢复透明掉的格子
- 底部主按钮更显眼，不容易忽略。
