# JWT 失效提示文案修复

- 日期：2026-03-15
- 范围：服务端

## 问题

上线前复扫发现，JWT 中间件在以下场景仍会返回不友好的提示：
- 未登录时提示乱码
- Token 过期时提示乱码
- Token 无效时提示“无效的Token”

这类提示会直接暴露给前端用户，既不专业，也不符合提审前的体验要求。

## 修复

- 重写 `server/middleware/jwt.go`
- 统一用户可见提示为可理解中文：
  - 未登录或登录状态已失效，请先登录
  - 登录状态已过期，请重新登录
  - 登录凭证无效，请重新登录
- 同时清理文件内乱码注释，避免后续维护继续受影响

## 结果

- 登录失效相关提示更符合用户理解
- 前端再遇到鉴权失败时，不会再出现“无效的Token”这类生硬文案
