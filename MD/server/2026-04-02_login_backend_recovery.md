# 2026-04-02 登录失败后端恢复

## 问题现象

- 前端登录页提示服务器异常，无法登录。
- Vite 代理请求 `/api/v1/auth/*`、`/api/v1/user/preferences` 等接口失败。

## 根因

- 前端开发环境代理固定指向 `http://localhost:8012`。
- 当时本地并没有健康的后端服务监听 `8012`。
- 之前看到的 `8888` 端口与当前前端代理无关，不能支撑登录链路。

## 处理过程

1. 确认前端代理目标为 `8012`。
2. 在服务端目录 `perler-beads-server/server` 启动当前后端代码。
3. 验证数据库迁移正常完成，后端成功监听 `:8012`。
4. 通过 `/health` 验证服务健康。
5. 通过真实注册与登录接口验证：
   - `POST /api/v1/auth/register`
   - `POST /api/v1/auth/login`
6. 通过前端登录页面再次验证，实际成功进入编辑图案页。

## 新增脚本

- `SCRIPT/start_backend_dev.ps1`
  - 作用：本地开发一键重启后端。
  - 行为：
    - 停掉旧的后端相关进程
    - 重新 `go build`
    - 后台启动 `perler-beads-server.exe`
    - 检查 `http://127.0.0.1:8012/health`
    - 输出日志路径

## 结果

- 登录接口恢复正常。
- 前端登录页已能实际完成登录。

## 验证

- `GET http://127.0.0.1:8012/health` 返回 `{"service":"perler-beads-server","status":"ok"}`
- 实际注册与登录测试账号成功
- 前端登录页点击“登录 / 注册”后成功跳转到编辑图案页
