# 2026-03-05 静态资源路由（社区缩略图与成品图）

## 目标
- 让后端直接提供社区缩略图与成品图片静态访问，避免仅依赖前端打包目录。

## 修改内容
- 重写文件：`perler-beads-server/server/initialize/router.go`
- 新增静态路由：
  - `/thumbnails`
  - `/finished-works`
- 新增目录解析函数：
  - `resolveStaticDir(envKey, subDir)`
  - 支持从环境变量覆盖目录：
    - `THUMBNAIL_DIR`
    - `FINISHED_WORK_DIR`
  - 未配置时自动尝试定位到 `perler-beads/public/*` 目录。

## 验证
- `go build ./...` 通过。
- `GET http://127.0.0.1:8012/thumbnails/post_11.png` 返回 `200`。
