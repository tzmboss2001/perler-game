# 2026-03-14 社区列表缺失图片地址兜底收紧

## 问题
- 前一轮服务端已增加卡片图地址回退。
- 但当缩略图和详情图都不存在时，服务端仍会把原始坏地址返回给前端，前端探测时仍会出现 404。

## 修改
- 收紧 `pickExistingMediaURL()`：
  - 只有真实存在的本地文件，才返回对应地址
  - 如果缩略图和详情图都不存在，则直接返回空字符串
- 这样前端列表卡片不会再去探测一组已知不存在的图片地址。

## 涉及文件
- `perler-beads-server/server/service/community.go`

## 验证
- `go build -o perler-beads-server.exe` 通过
- 重启本地 `8012` 后端后，MCP 复查首页控制台，这批社区卡片图片 404 被清空
