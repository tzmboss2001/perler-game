# 2026-03-02 社区发布标题乱码拦截修复

## 问题
- 社区中出现了标题为 `????` 形式的乱码作品。
- 原因是终端/脚本编码异常时，标题字符被替换后仍可入库。

## 修复
- 文件：`perler-beads-server/server/service/community.go`
- 在 `CreatePost` 增加标题乱码识别：`looksLikeGarbledTitle(title)`
- 拦截规则：
  1. UTF-8 非法字符串
  2. 包含 Unicode 替换字符 `�`
  3. 问号占比过高（>=40%）
  4. 至少 3 个问号且无正常字母数字
- 命中后返回错误：`标题编码异常，请重新输入标题后发布`

## 兼容性
- 正常中文、英文、数字标题不受影响。
- 仅拦截明显异常编码标题，避免污染社区内容。

## 验证
1. `go build .` 通过。
2. 接口实测：
   - 标题 `??????-乱码测试` -> 返回失败：`发布失败: 标题编码异常，请重新输入标题后发布`
   - 标题 `title-encoding-check-20260302` -> 返回成功（code=0）
