# 编辑页调节区横向重排设计

## 目标

让编辑页的 `预览缩放` 和 `宽度调节` 在常规手机与更宽视口下改为左右分布，减少纵向占高，把 `保存并开始制作` 尽量拉回首屏；极窄屏仍保留上下堆叠，避免把滑杆和快捷按钮压得不可用。

## 方案

### 布局策略

- `viewportWidth > 390` 时，调节区改成两列布局。
- 左列放 `预览缩放`，右列放 `宽度调节`。
- 左右宽度按 `44% / 56%` 分配，给右侧宽度快捷按钮留更多空间。
- `viewportWidth <= 390` 时，退回当前上下堆叠布局。

### 交互约束

- 两侧滑杆缩短，但仍保留 `- / +`。
- `预览缩放` 继续保留 `适配 / 1:1`。
- `宽度调节` 继续保留输入框、滑杆和常用宽度快捷按钮。
- 不改变现有生成逻辑，只改布局和局部尺寸。

### 成功标准

- 常规手机口径下，`保存并开始制作` 明显上移。
- 窄屏下不出现按钮溢出或滑杆不可拖动。
- 不影响现有编辑、生成和预览逻辑。
