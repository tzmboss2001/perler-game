# 桌面单板制作工作区侧边栏优化设计

## 目标
- 在不牺牲单板制作核心操作的前提下，继续释放桌面宽屏下的图纸工作区高度。
- 让桌面宽屏单板模式把更多次级操作收进右侧侧边栏，主区只保留高频、必须贴近图纸的操作。

## 当前问题
- 右侧侧边栏已经接管了一部分工具，但主区仍保留一块单板工作流卡片。
- 这块卡片继续占用画布上方高度，导致桌面宽屏下图纸区域仍被压缩。
- 主工具条里还保留了桌面侧边栏已有的 `换色` 入口，存在重复。

## 方案
### 方案 A：继续压缩主区卡片
- 继续缩小主区工作流卡片、按钮和间距。
- 优点：改动最小。
- 缺点：高度收益有限，而且重复入口仍在。

### 方案 B：推荐，侧边栏继续接管次级操作
- 桌面宽屏单板模式下，把 `标记本板完成 / 继续未完成 / 总览展开收起 / 换色` 等次级操作并入右侧侧边栏。
- 主区去掉单板工作流卡片，只保留顶部摘要、缩放、画布和核心完成按钮。
- 优点：能直接回收可见高度，功能边界更清楚。
- 缺点：桌面侧边栏承担更多职责，需要保证按钮分组仍易找。

### 方案 C：完整桌面工作台重排
- 进一步重写桌面制作页骨架，做完整桌面工作台。
- 优点：空间潜力最大。
- 缺点：改动范围过大，不适合这轮只做面积优化。

## 采用方案
- 采用方案 B。

## 交互设计
- 仅在 `useDesktopSidebarLayout && viewMode === "singleBoard"` 时启用。
- 主区移除单板工作流卡片。
- 右侧侧边栏总览区新增一组工作流操作：
  - `标记本板完成 / 取消完成`
  - `继续板X`（仅存在继续目标时显示）
  - `展开总览 / 收起总览`
- 主工具条里的 `换色` 按钮在桌面侧边栏模式下隐藏，统一由侧边栏入口承担。
- 顶部摘要和主工具条里的 `完成板X` 按钮保留，保证高频动作仍靠近画布。

## 验收标准
- 桌面宽屏单板模式下，主区不再显示单板工作流卡片。
- 侧边栏里能完成：完成当前板、继续未完成板、切换总览、换色。
- 桌面宽屏下主画布可见高度比本轮改前增加。
- 手机端和非桌面侧边栏布局不受影响。
