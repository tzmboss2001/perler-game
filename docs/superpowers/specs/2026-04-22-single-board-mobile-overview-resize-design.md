# 单板模式手机端总览卡片缩放设计

日期：2026-04-22

## 背景

当前手机端单板模式已经支持：

- `总览` 按钮打开小型悬浮总览卡片
- 总览卡片拖动
- 总览中点击板块跳转
- `<` `>` 切板后标题与当前板高亮同步

用户新增需求是让总览卡片支持自行缩放，并希望缩放方式清晰、稳定，不影响大图制作操作和总览内部点击跳板。

## 目标

- 允许用户在手机端调整总览卡片大小
- 缩放时保持等比例，不允许任意拉伸变形
- 不影响现有拖动卡片与点击总览跳板
- 缩放后的卡片仍保持在屏幕安全区域内
- 总览卡片仍然是辅助定位，不抢占主制作区

## 不做的内容

- 不做双指缩放总览卡片
- 不做完全自由的非等比宽高拉伸
- 不做桌面端总览缩放
- 不做记忆到云端；仅做当前设备本地记忆

## 方案对比

### 方案 A：右下角等比例拖拽缩放

- 在总览卡片右下角增加缩放手柄
- 用户拖动手柄时，卡片按固定宽高比一起放大或缩小
- 设定最小/最大尺寸边界

优点：

- 直觉，符合常见浮层卡片交互
- 不会和卡片主体拖动混淆
- 可以精细调整大小

缺点：

- 需要额外处理缩放中点击、拖动和边界钳制

### 方案 B：固定两到三档尺寸切换

- 通过按钮在 `小 / 中 / 大` 间切换

优点：

- 实现简单、稳定

缺点：

- 灵活性不足
- 用户需要反复点切换才能找到顺手大小

## 选型

采用方案 A。

原因：

- 当前总览已经是悬浮卡片，继续补右下角缩放手柄最自然
- 用户明确希望有“边角等比例缩放按钮”
- 现有拖动逻辑已存在，扩展成本比重做尺寸切换更低

## 交互设计

### 卡片结构

总览卡片维持现有结构：

- 标题栏
- 关闭按钮
- 左右切板按钮（仅多板图）
- 总览画布
- 提示文案

新增：

- 右下角缩放手柄

### 拖动与缩放职责划分

- 卡片主体：继续负责拖动卡片位置
- 右下角缩放手柄：只负责缩放卡片尺寸
- 总览画布：继续优先处理点击板块跳转

这样可以避免以下冲突：

- 用户想拖动卡片，却触发跳板
- 用户想缩放卡片，却触发拖动卡片

### 缩放行为

- 缩放以卡片当前宽度为主导
- 高度按固定比例同步计算
- 缩放过程中卡片始终保持等比例
- 手柄拖动距离小于阈值时，不视为缩放操作

### 尺寸边界

手机端总览卡片宽度限制在：

- 最小宽度：`176px`
- 默认宽度：`220px`
- 最大宽度：`min(280px, viewportWidth - 24px * 2)`

高度由比例自动推导，并继续受屏幕可用高度约束。

### 边界钳制

卡片缩放后重新计算：

- `left/top`
- `maxHeight`
- 可拖动边界

如果当前卡片位置在缩放后超出安全区域，则自动钳回最近合法位置。

### 透明度策略

- 卡片外壳继续保持轻半透明
- 总览画布本体不增加额外透明度
- 缩放手柄使用轻描边 + 半透明底，不抢眼但可发现

## 状态设计

新增本地状态：

- `singleBoardMobileOverviewSize`
  - 存当前卡片宽度，或统一的 size 标量

新增交互状态：

- `singleBoardMobileOverviewResizeRef`
  - 记录缩放开始时指针位置
  - 记录缩放开始时卡片宽度
  - 记录当前是否进入缩放态

本地持久化：

- 使用 `localStorage` 记住最近一次总览卡片尺寸
- 仅按当前设备本地保存，不走云端

## 实现设计

### `singleBoardInteraction.js`

新增或扩展 helper：

- 计算总览卡片缩放布局
- 计算缩放后的宽高与位置钳制
- 统一最小/最大宽度规则

建议新增：

- `getSingleBoardMobileOverviewResizeLayout`
- `clampSingleBoardMobileOverviewSize`

### `MakingPage.tsx`

需要补充：

- 尺寸 state
- 缩放手柄 pointer 事件
- 拖动与缩放事件分流
- 打开总览时读取本地尺寸
- 关闭或缩放完成后写回本地尺寸
- 卡片 style 使用动态 width/maxHeight

### UI 样式

新增：

- `singleBoardMobileOverviewResizeHandle`
- 可选的手柄图标样式

要求：

- 触达区域不能太小，避免手机误触
- 视觉上放在卡片右下角，不盖住主要内容

## 风险与处理

### 风险 1：缩放手柄与卡片拖动冲突

处理：

- 仅手柄区域触发缩放
- 缩放开始后阻断卡片拖动

### 风险 2：缩放后卡片超出屏幕

处理：

- 每次缩放都重新做位置钳制

### 风险 3：缩放后画布点击热点不准

处理：

- 继续使用真实画布尺寸驱动重绘
- 缩放后立即重新绘制总览

## 验收标准

- 手机端单板模式下能看到右下角缩放手柄
- 拖动手柄时，总览卡片按比例缩放
- 缩放后卡片不会超出屏幕安全区域
- 卡片主体拖动仍然正常
- 点击总览中的板块跳转仍然正常
- `<` `>` 切板后，总览标题和高亮同步仍正常
- 刷新页面后，最近一次总览大小会保留
