# 移动端单板模式 UI 收口设计

## 目标
- 在不牺牲单板制作核心功能的前提下，增大手机端单板模式的图纸工作区面积。
- 保留高频操作的直达性，同时把次级工具从首屏常驻区收走，减少视觉拥挤。

## 当前问题
- 手机端单板模式首屏同时存在 `自动切换 / 总览 / 复位 / 完成 / 图纸 / 辅助` 等元素。
- 顶部状态、主工具条、缩放条叠加后，占用了较多垂直空间。
- `图纸 / 辅助 / 自动切换 / 换色` 这类次级操作和核心制作按钮同层，削弱了“图纸优先”的布局目标。

## 方案对比
### 方案 1：只压缩尺寸
- 保持现有按钮结构，只缩小按钮、间距和文案。
- 优点：改动小。
- 缺点：工作区回收有限，结构问题还在。

### 方案 2：核心常驻 + 次级工具折叠
- 首屏只保留核心高频操作。
- 把次级工具统一收进 `工具` 入口。
- 优点：工作区面积提升明显，学习成本可控。
- 缺点：次级功能多一步点击。

### 方案 3：大面积浮层化
- 把更多控制项转成悬浮覆盖层。
- 优点：图纸区域最大。
- 缺点：交互变化大，回归风险高。

## 采用方案
- 采用方案 2。

## 交互设计
### 1. 顶部状态区收薄
- 保留当前板核心进度信息。
- `自动切换` 不再作为首屏独立按钮常驻，改为：
  - 状态文案轻提示
  - 并入 `工具` 面板里的可切换项

### 2. 主工具条只保留核心操作
- 手机端单板模式首屏常驻按钮调整为：
  - `总览`
  - `复位`
  - `完成`
  - `工具`
- 其中：
  - `完成` 仍是主按钮
  - `总览` 和 `复位` 保持直达
  - `工具` 作为次级能力入口

### 3. 次级工具统一收进工具面板
- `工具` 面板内包含：
  - `图纸`
  - `辅助`
  - `自动切换`
  - `换色`（仅有选中色时显示）
- `工具` 面板采用轻量弹层或抽屉式，不覆盖太大面积。

### 4. 缩放条继续保留但压薄
- 缩放条仍保留在首屏，因为它是制作中的高频操作。
- 但整体高度和上下边距继续压缩，避免抢占图纸空间。

## 不变项
- 单板模式的总览逻辑不变。
- 完成当前板、复位当前板、进入辅助设置、下载图纸、换色能力都保留。
- 桌面端和传统模式不受这轮设计影响。

## 验收标准
- 手机端单板模式首屏不再同时出现 `图纸 / 辅助 / 自动切换 / 换色` 常驻按钮。
- 首屏保留 `总览 / 复位 / 完成 / 工具 / 缩放`。
- `工具` 内可以触达被收纳的次级能力。
- 图纸工作区高度较当前版本明显增加。
- 手机端单板主流程不变：总览、完成、复位、缩放都仍可直达。
