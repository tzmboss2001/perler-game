# 首页设计方案 v1.0

> 创建时间：2026-02-02
> 状态：待实现

---

## 一、设计目标

1. **吸引新用户**：通过精选作品展示，让用户一眼看到成品效果
2. **降低上手门槛**：新手引导 + 模板库，让用户快速开始
3. **留存老用户**：我的方案快速入口，继续未完成的创作
4. **为社区铺垫**：预留社区入口位置，后续迭代

---

## 二、目标用户

| 用户类型 | 特点 | 需求 |
|----------|------|------|
| 小孩 | 喜欢卡通、游戏角色 | 简单操作、有趣的模板 |
| 家长 | 陪孩子做手工 | 清晰的操作流程、成品预览 |
| 手工爱好者 | 追求精细作品 | 高级编辑功能、多品牌色板 |

## 四、模块详细设计

### 4.1 精选作品轮播

**功能**：
- 展示 3-5 个精选作品
- 自动轮播（3秒切换）
- 支持手动滑动
- 点击进入作品详情/直接使用该模板

**数据结构**：
```typescript
interface FeaturedWork {
  id: string;
  title: string;           // 作品名称
  imageUrl: string;        // 作品图片
  author?: string;         // 作者（可选，官方作品无作者）
  beadCount: number;       // 珠子数量
  difficulty: 'easy' | 'medium' | 'hard';  // 难度
  isOfficial: boolean;     // 是否官方作品
}
```

**初期精选作品（需要制作）**：
1. 皮卡丘 - 卡通动漫 - 简单
2. 马里奥 - 游戏角色 - 中等
3. 小猫咪 - 可爱动物 - 简单
4. 樱花树 - 风景 - 中等
5. 爱心图案 - 其他 - 简单

### 4.2 快速开始区域

**功能**：
- 两个并排大按钮
- 「拍照创作」：调用相机
- 「从相册选择」：打开相册

**交互**：
- 点击后跳转到 CreatePage
- 传递参数标识来源（camera/album）

### 4.3 模板精选

**功能**：
- 横向滚动展示模板分类
- 每个分类显示封面图 + 分类名
- 点击进入该分类的模板列表
- 右上角「查看全部」进入完整模板库

**模板分类**：
| 分类 | 图标 | 示例内容 |
|------|------|----------|
| 卡通动漫 | 🎬 | 皮卡丘、哆啦A梦、海绵宝宝 |
| 游戏角色 | 🎮 | 马里奥、Minecraft史蒂夫、吃豆人 |
| 可爱动物 | 🐱 | 猫、狗、兔子、熊猫 |
| 风景 | 🌸 | 樱花树、日落、山水 |
| 节日主题 | 🎄 | 圣诞树、春节福字、万圣节南瓜 |
| 其他 | ✨ | 爱心、星星、几何图案 |

**数据结构**：
```typescript
interface TemplateCategory {
  id: string;
  name: string;
  icon: string;
  coverImage: string;
  templateCount: number;
}

interface Template {
  id: string;
  categoryId: string;
  name: string;
  imageUrl: string;
  thumbnailUrl: string;
  gridWidth: number;
  gridHeight: number;
  beadCount: number;
  colorCount: number;
  difficulty: 'easy' | 'medium' | 'hard';
  beadData: BeadColor[][];  // 珠子数据
}
```

### 4.4 我的方案

**功能**：
- 显示最近 1-2 个方案的缩略图
- 点击直接进入编辑器继续制作
- 未登录状态显示提示登录

**状态处理**：
| 状态 | 显示内容 |
|------|----------|
| 未登录 | "登录后同步云端方案" + 登录按钮 |
| 已登录无方案 | "还没有方案，开始创作吧" |
| 已登录有方案 | 方案缩略图列表 + 查看全部 |

### 4.5 社区入口（预留）

**当前状态**：
- 显示灰色卡片 + "社区功能即将上线"
- 或暂时隐藏，等社区功能完成后再显示

**后续规划**：
- 显示热门作品预览（2-3个）
- 点击进入社区页面（瀑布流）

## 五、新手引导设计

- 首次打开 App（localStorage 判断）
- 可在设置页面重新触发

```
✨ 贴心的制作辅助

• 多品牌珠子色板匹配

[下一步]  [跳过]
```


### 5.3 存储标记

```typescript
// localStorage key
const ONBOARDING_COMPLETED_KEY = 'perler_onboarding_completed';
```

## 八、技术要点

### 8.1 轮播组件
- 使用 CSS scroll-snap 或 swiper 库
- 自动播放 + 手动滑动
- 指示器点点

### 8.2 瀑布流（后续）
- 使用 CSS columns 或 masonry 布局
- 虚拟滚动优化性能
- IntersectionObserver 实现无限加载

### 8.3 图片懒加载
- 使用 IntersectionObserver
- 占位图/骨架屏

## 九、设计风格

- 马卡龙色调
- 圆角卡片（16px）
- 柔和渐变
- 磨砂玻璃效果
