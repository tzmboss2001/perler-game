# 制作辅助模式实现

## 日期
2026-01-23

## 功能描述
为拼豆工坊添加"制作辅助模式"，帮助用户在实际制作拼豆时逐行/逐列对照放置珠子。

## 新增/修改文件

### 1. src/pages/mobile/MakingPage.tsx（新增）
制作辅助页面，核心功能：
- **行/列高亮导航**：当前行用青色边框高亮，其他行变暗显示
- **进度追踪**：显示已完成/总行数，百分比进度条
- **颜色序列显示**：当前行的所有珠子颜色按顺序展示
- **颜色统计**：显示当前行用到的颜色及数量
- **已完成标记**：完成的行显示绿色半透明覆盖
- **方向切换**：支持逐行或逐列模式

### 2. src/router/index.tsx（修改）
- 添加 MakingPage 懒加载导入
- 添加路由 `/mobile/making`

### 3. src/pages/mobile/EditorPage.tsx（修改）
- 导入 Play 图标
- 添加"开始制作"按钮，导航到制作辅助页面
- 传递 beadData 和 brand 数据到 MakingPage

## 功能说明

### 导航控制
| 按钮 | 功能 |
|------|------|
| 上一行 | 回到前一行（第一行时禁用） |
| 完成并继续 | 标记当前行完成，自动跳到下一行 |
| 下一行 | 跳到后一行（最后一行时禁用） |

### 显示控制
- 方向切换按钮（右上角）：切换逐行/逐列模式
- 显示已完成按钮：切换是否显示已完成行的绿色覆盖

### 数据流
```
EditorPage → navigate('/mobile/making', { state: { beadData, brand } }) → MakingPage
```

## 用户体验

1. 在编辑器完成图案后，点击"开始制作"
2. 进入制作模式，从第 1 行开始
3. 对照颜色序列，逐颗放置珠子
4. 完成一行后点击"完成并继续"
5. 系统自动跳到下一行，进度更新
6. 重复直到全部完成
