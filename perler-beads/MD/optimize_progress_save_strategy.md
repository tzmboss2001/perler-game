# 优化：制作进度保存策略

## 日期
2026-02-02

## 问题描述
之前的实现每次用户点击都会自动上传进度到云端，存在以下问题：
1. 消耗用户流量
2. 占用服务器带宽
3. 可能被恶意刷接口

## 优化方案

### 双轨保存机制

```
┌─────────────────────────────────────────────────────────────┐
│                     双轨保存机制                             │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  📱 同一设备（自动）：                                       │
│  ┌─────────────────────────────────────────────────────┐   │
│  │  每次操作 → localStorage 自动保存                    │   │
│  │  下次打开 → 自动恢复本地进度                         │   │
│  │  ✅ 无网络请求，无流量消耗                           │   │
│  └─────────────────────────────────────────────────────┘   │
│                                                             │
│  ☁️ 跨设备（手动）：                                        │
│  ┌─────────────────────────────────────────────────────┐   │
│  │  用户点击"保存进度"按钮 → 上传云端                   │   │
│  │  其他设备登录 → 读取云端进度                         │   │
│  │  ✅ 用户主动控制，防止恶意刷接口                     │   │
│  └─────────────────────────────────────────────────────┘   │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 恢复优先级

进入制作页面时：
1. 优先使用云端进度（从方案详情获取）
2. 其次使用本地 localStorage

## 修改内容

### MakingPage.tsx

1. **移除自动云端同步**
   - 删除防抖机制（cloudSyncTimerRef, pendingProgressRef, syncToCloud）
   - 删除自动上传逻辑

2. **添加本地保存函数**
   ```typescript
   const saveSelectionStateToLocal = useCallback(() => {
     // 只保存到 localStorage，无网络请求
   }, [getStorageKey, selection]);
   ```

3. **添加手动云端保存函数**
   ```typescript
   const saveProgressToCloud = useCallback(async () => {
     // 用户点击按钮时调用
     // 带 loading 状态和 toast 提示
   }, [projectId, selection, toast]);
   ```

4. **添加"保存进度"按钮**
   - 只在有 projectId 时显示
   - 绿色渐变背景，云朵图标
   - 保存时显示加载动画

5. **新增图标**
   - CloudArrowUp：保存按钮图标
   - CircleNotch：加载动画图标

## 优势

| 方面 | 之前 | 现在 |
|------|------|------|
| 网络请求 | 每次操作都请求 | 只在用户点击时请求 |
| 流量消耗 | 高 | 极低 |
| 服务器压力 | 高 | 低 |
| 恶意攻击风险 | 高 | 低（用户主动触发） |
| 本地体验 | 相同 | 相同（自动本地保存） |

## 用户体验

1. **同一设备**：无感知自动保存，下次打开自动恢复
2. **换设备**：点击"保存进度"按钮，云端同步
3. **新设备登录**：自动读取云端保存的最新进度
