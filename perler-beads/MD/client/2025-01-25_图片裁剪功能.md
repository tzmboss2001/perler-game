## 功能说明

### 用户流程
```
选择图片/拍照 → 裁剪页面（新增）→ 预览+颜色选择 → 开始生成
```

### ImageCropper 组件功能
- 显示图片和裁剪框
- 支持拖拽调整裁剪区域
- **5种比例选项**：原图、1:1（推荐）、4:3、3:4、自由
- 原图模式：不显示裁剪框，直接使用原始图片
- 左上角返回按钮 = 取消
- 底部只有一个"确认"按钮
- 使用 Canvas 生成裁剪后的 Base64 图片
- 使用 createPortal 渲染到 body，避免层叠上下文问题

### CreatePage 状态变更
```typescript
// 旧
const [selectedImage, setSelectedImage] = useState<string | null>(null);

// 新
const [rawImage, setRawImage] = useState<string | null>(null);      // 原始图片
const [croppedImage, setCroppedImage] = useState<string | null>(null); // 裁剪后的图片
```

### 渲染逻辑
1. `!rawImage` - 显示上传区域
2. `rawImage && !croppedImage` - 显示裁剪页面（全屏覆盖）
3. `croppedImage` - 显示预览+颜色选择

## Bug 修复记录
### 2025-01-25 比例切换问题
- **问题**：1:1 比例选择后裁剪框不是正方形
- **原因**：组件使用了混合类型（数字和字符串）导致状态匹配问题
- **解决方案**：
  1. 使用 `AspectOption` 接口统一管理比例选项
  2. 使用字符串 `selectedKey` 代替混合类型状态
  3. 通过 `aspectOptions.find()` 获取当前选项的 `aspect` 值
- **验证**：所有5种比例选项切换测试通过

### 2025-01-25 裁剪输出图片比例错误
- **问题**：选择 1:1 比例后，裁剪框视觉上是正方形，但点击确认后输出的图片不是正方形
- **原因**：`getCroppedImg` 函数依赖 `completedCrop` 状态来计算裁剪区域，但 `completedCrop` 只在用户手动拖动裁剪框时通过 `onComplete` 回调更新。当通过 `useEffect` 设置新的 `crop` 时（如切换比例），`completedCrop` 不会自动更新，导致使用了旧值或 undefined
- **解决方案**：
  1. 修改 `getCroppedImg` 函数，增加回退逻辑
  2. 优先使用 `completedCrop`（用户交互产生的值）
  3. 当 `completedCrop` 无效时，从当前 `crop` 百分比状态计算像素值
  ```typescript
  // 从百分比 crop 计算像素值
  if (crop.unit === '%') {
    pixelCrop = {
      unit: 'px',
      x: (crop.x / 100) * displayWidth,
      y: (crop.y / 100) * displayHeight,
      width: (crop.width / 100) * displayWidth,
      height: (crop.height / 100) * displayHeight,
    };
  }
  ```
- **验证**：使用 200x600 竖向测试图片，选择 1:1 比例后裁剪，输出图片为正方形（160x160 像素）

### 2025-01-25 UI文案优化
- **修改**：将"裁剪比例"改为"宽高比"
- **原因**：4:3 和 3:4 表示的是宽高比例关系，用"宽高比"更准确
  - 4:3 = 宽4份，高3份 → 横向矩形
  - 3:4 = 宽3份，高4份 → 竖向矩形

### 2025-01-25 裁剪框视觉比例错误（第二次修复）
- **问题**：选择 1:1 比例后，裁剪框在视觉上仍然不是正方形（宽高比约 0.41 而非 1.0）
- **根本原因**：
  1. `useEffect` 中设置的初始 `crop` 使用固定的 50x50 百分比
  2. `aspect` prop 只在用户拖动时生效，不会自动调整程序设置的初始裁剪区域
  3. 需要根据图片实际显示尺寸和目标宽高比来计算正确的初始裁剪区域
- **解决方案**：
  1. 导入 `makeAspectCrop` 和 `centerCrop` 函数
  2. 使用 `makeAspectCrop` 根据图片尺寸和目标宽高比计算正确的裁剪区域
  3. 使用 `centerCrop` 将裁剪框居中
  ```typescript
  import ReactCrop, { Crop, PixelCrop, makeAspectCrop, centerCrop } from 'react-image-crop';

  // 在 useEffect 中
  const { width: imgWidth, height: imgHeight } = imgRef.current;
  const newCrop = centerCrop(
    makeAspectCrop(
      { unit: '%', width: 80 },
      currentAspect,  // 如 1 表示 1:1
      imgWidth,
      imgHeight
    ),
    imgWidth,
    imgHeight
  );
  setCrop(newCrop);
  ```
- **验证结果**：
  | 比例 | 裁剪框尺寸 | 实际比例 | 预期比例 | 状态 |
  |------|------------|----------|----------|------|
  | 1:1 | 176×175 | 1.002 | 1.000 | ✅ |
  | 4:3 | 176×131 | 1.336 | 1.333 | ✅ |
  | 3:4 | 176×234 | 0.752 | 0.750 | ✅ |
