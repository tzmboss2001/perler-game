# 透明背景支持

## 修改日期
2025-01-25

## 修改内容

### 功能说明
支持用户上传带透明背景的 PNG 图片，透明区域不会生成珠子。

### 解决方案
修改像素化和颜色匹配逻辑，支持透明像素处理。

### 注意
原计划的"智能抠背景"功能因许可证问题（AGPL）已移除。
用户如需透明背景，需自行使用其他工具处理后上传 PNG 图片。

## 修改文件

### 1. `src/services/pixelizeService.ts`
- `PixelData` 接口添加 `alphas?: number[]` 可选属性
- `pixelizeFromImage` 函数现在读取并保存 alpha 通道

```typescript
export interface PixelData {
  width: number;
  height: number;
  pixels: [number, number, number][];
  alphas?: number[];  // 新增：Alpha 通道数组
}
```

### 2. `src/services/colorMatchService.ts`
- `BeadPixelData.beads` 类型改为 `(BeadColor | null)[]`
- `ColorMatchOptions` 添加 `transparentThreshold` 选项（默认 128）
- `matchPixelsToBead` 跳过透明像素（alpha < 阈值时返回 null）
- `calculateBeadStatistics` 跳过 null 珠子
- `reduceColors` 保留 null 珠子
- `renderBeadsToCanvas` 透明位置绘制棋盘格背景

```typescript
export interface BeadPixelData {
  width: number;
  height: number;
  beads: (BeadColor | null)[];  // null 表示透明
}
```

### 3. `src/components/InteractiveCanvas.tsx`
- 高亮遍历时跳过 null 珠子
- 吸色工具跳过透明珠子

## 效果说明

| 场景 | 之前 | 之后 |
|------|------|------|
| 抠背景后透明区域 | 生成黑色珠子 | 不生成珠子（棋盘格显示） |
| 珠子统计 | 包含透明区域 | 只统计有效珠子 |
| 购物清单 | 包含多余黑色 | 正确统计 |

## 透明阈值
- 默认值：128（alpha 值 0-255）
- alpha < 128 的像素视为透明
- 可通过 `transparentThreshold` 参数调整
