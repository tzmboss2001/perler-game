# 背景透明化功能实现记录

## 日期
2025-01-25

## 功能描述
在 EditorPage 添加"背景处理模式"，允许用户手动选择并透明化背景网格。适用于背景颜色简单（1-2种颜色）的场景。

## 用户场景
- 用户上传的图片有纯色背景
- 用户希望只制作主体部分，不需要背景的珠子
- 透明部分不计入珠子统计和购买清单

## 交互流程
1. **进入模式**：点击工具栏的魔棒图标
2. **选择颜色**：点击任意网格，高亮所有同色号网格
3. **排除误选**：点击已高亮网格可取消高亮（保护主体上的同色区域）
4. **确认透明**：点击"确认透明"按钮，将剩余高亮网格设为透明
5. **多轮处理**：可重复步骤2-4处理多种背景色
6. **退出模式**：点击"退出"或返回按钮

## 查看/选择模式切换
由于移动端和桌面端的交互差异，提供统一的切换按钮：
- **选择模式**（默认）：点击网格进行选择/排除操作
- **查看模式**：可拖动浏览图案，不触发选择操作

底部操作栏按钮：`[查看/选择] [重新选择] [确认透明] [退出]`

## 视觉效果
- **高亮网格**：金色边框 + 半透明黄色遮罩
- **被排除网格**：绿色边框（表示被保护）
- **已透明网格**：显示棋盘格底纹（灰白交替）
- **已透明网格不可选中**

- 添加 `MagicWand` 图标导入

  - `bgExcludedIndices` - 排除的网格索引集合

  - `handleEnterBackgroundMode` - 进入背景处理模式
  - `handleExitBackgroundMode` - 退出背景处理模式

  - `handleBgToggleExclude` - 排除/恢复网格
  - `getBgHighlightedIndices` - 获取高亮网格列表
  - `handleBgConfirmTransparent` - 确认透明化
  - `handleBgClearSelection` - 清除选择
- 添加背景模式覆盖层 UI
- 添加相关样式

### 3. InteractiveCanvas.tsx
- 添加背景模式相关属性：
  - `isBackgroundMode` - 是否处于背景处理模式
  - `bgModeHighlightedIndices` - 高亮的网格索引
  - `bgModeExcludedIndices` - 排除的网格索引
  - `onBgSelectColor` - 选择颜色回调
  - `onBgToggleExclude` - 切换排除回调
- 更新渲染逻辑：绘制背景模式的高亮效果和排除效果
- 更新点击处理：区分背景模式和普通模式的交互

## 技术要点

### 透明珠子的表示
`BeadPixelData.beads` 数组中使用 `null` 表示透明珠子，现有代码已支持：
- `renderBeadsToCanvas` 已实现棋盘格渲染
- `calculateBeadStatistics` 已跳过 `null` 珠子

### 状态管理
背景模式使用 EditorPage 的本地状态，不影响 Zustand store 的编辑状态。

### 交互冲突处理
背景模式使用全屏覆盖层，完全隔离普通编辑模式的交互。

## 测试要点
| 场景 | 预期结果 |
|------|----------|
| 点击魔棒进入模式 | 显示背景处理模式覆盖层 |
| 点击非透明网格 | 高亮所有同色网格 |
| 点击高亮网格 | 该网格取消高亮（显示绿色边框） |
| 再次点击被排除网格 | 恢复高亮 |
| 确认透明化 | 高亮网格变棋盘格，统计更新 |
| 点击棋盘格网格 | 无反应（不可选） |
| 多轮处理 | 可继续选择其他颜色透明化 |
| 退出模式 | 回到正常编辑 |
