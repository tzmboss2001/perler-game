# 精选作品功能优化

## 修改日期
2026-02-03

## 修改概述
优化精选作品的展示和交互流程，包括缩略图完整显示、新增模板详情页、制作功能对接。

## 修改内容

### 1. 缩略图适配 (`FeaturedCarousel.tsx`)

**问题**: 精选作品缩略图使用 `objectFit: 'cover'` 导致图片被裁剪，只能看到局部。

**解决方案**:
- 将 `objectFit: 'cover'` 改为 `objectFit: 'contain'`，完整显示图片
- 添加深色背景 `#1a1b2e`，让拼豆图案更突出
- 添加 `imageRendering: 'pixelated'` 让像素图更清晰
- 图片高度从 180px 调整为 200px

```typescript
// 修改前
image: {
  width: '100%',
  height: '100%',
  objectFit: 'cover',
}

// 修改后
image: {
  maxWidth: '100%',
  maxHeight: '100%',
  objectFit: 'contain',
  imageRendering: 'pixelated',
}
```

### 2. 点击行为变更 (`FeaturedCarousel.tsx`)

**修改前**: 点击精选作品直接跳转到 `/mobile/create` 创建页面。

**修改后**: 点击精选作品跳转到 `/mobile/template/:id` 模板详情页。

```typescript
// 修改前
navigate('/mobile/create', { state: { templateId: work.id } });

// 修改后
navigate(`/mobile/template/${work.id}`);
```

同时将"使用模板"按钮改为"点击查看"提示，样式更轻量。

### 3. 新增模板详情页 (`TemplateDetailPage.tsx`)

**文件位置**: `src/pages/mobile/TemplateDetailPage.tsx`

**页面功能**:
1. **图片展示区**
   - 支持双指缩放（0.5x ~ 3x）
   - 支持拖动平移
   - 支持鼠标滚轮缩放
   - 双击重置缩放和位置
   - 显示当前缩放比例

2. **信息展示**
   - 模板名称
   - 难度标签（简单/中等/困难，带颜色）
   - 精选标签（如果是精选作品）
   - 基本信息卡片：网格尺寸、珠子数量、颜色种类、分类

3. **颜色预览**
   - 展示前12种主要颜色
   - 显示每种颜色的珠子数量

4. **开始制作按钮**
   - 解析 `bead_data` 转换为 `BeadPixelData` 格式
   - 跳转到 `/mobile/making` 制作页面
   - 自动调用 `useTemplate` API 记录使用次数

### 4. 路由配置 (`router/index.tsx`)

添加模板详情页路由：

```typescript
const TemplateDetailPage = lazy(() => import('../pages/mobile/TemplateDetailPage'));

// 路由配置
<Route path="/mobile/template/:id" element={<TemplateDetailPage />} />
```

```

```

## 技术要点

### bead_data 解析
后端返回的 `bead_data` 格式：
```json
{
  "beads": [
    {"brand": "perler", "hex": "#FF0000", "id": "80-19005", "name": "Red"},
    ...
  ],
  "width": 64,
  "height": 64
}
```

前端 `BeadPixelData` 格式：
```typescript
interface BeadPixelData {
  width: number;
  height: number;
  beads: BeadColor[];
}
```

### 图片缩放实现
- 使用 CSS `transform: translate() scale()` 实现
- 触摸事件处理双指缩放和单指拖动
- 缩放范围限制在 0.5x ~ 3x
