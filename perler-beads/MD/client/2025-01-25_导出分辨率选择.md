# 导出分辨率选择功能

## 修改日期
2025-01-25

## 修改内容

### 功能说明
点击"导出图案"时弹出选项弹窗，用户可以选择不同分辨率导出图片。

### 分辨率选项

| 选项 | 单格像素 | 32×32图案尺寸 | 适用场景 |
|------|----------|---------------|----------|
| 小图 | 10px | 320×320 | 快速分享到社交媒体 |
| 标准 | 20px | 640×640 | 日常使用（推荐） |
| 高清 | 40px | 1280×1280 | 打印使用 |

### 导出选项
- **显示网格线**：开关控制是否在导出图片中显示珠子间的网格线
- **显示坐标刻度**：开关控制是否在图片边缘显示行列坐标

### 文件命名格式
```
perler-{宽度}x{高度}-{分辨率选项}-{日期}.png
例如：perler-32x32-standard-20250125.png
```

## 技术实现

1. 使用 React Portal 渲染弹窗到 body
2. 底部弹出动画（slideUp）
3. 点击遮罩层关闭
4. 根据选项动态计算预估文件大小
5. 调用 renderBeadsToCanvas 并使用 canvas.toDataURL 生成 PNG
