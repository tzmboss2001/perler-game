# 色号字体优化（2026-02-25）

## 问题
导出图纸中的色号（如 R16、B10）字体太粗，像素感明显，而且统一使用白色字体，在浅色格子上不够清晰。

## 修改

### `src/services/colorMatchService.ts`（两处修改）

#### 1. renderBeadsToCanvas（整张图纸渲染）
- 字体权重：`bold` → `500`（中等粗细，减少像素感）
- 文字颜色逻辑：
  - 旧：`getContrastColor(bead.rgb)` 统一对比色（阈值 0.5）
  - 新：计算亮度 `luminance = (0.299*R + 0.587*G + 0.114*B) / 255`
    - `luminance < 0.35`（很暗的背景）→ 白色文字 `#ffffff`
    - 其他 → 深色文字 `#1a1a1a`
- 描边粗细：`2/1` → `1.5/0.8`

#### 2. renderBeadsPaginated（分页渲染）
- 同上修改

## 效果对比

| 项目 | 修改前 | 修改后 |
|------|--------|--------|
| 字体粗细 | bold（粗体） | 500（中等） |
| 浅色格子文字 | 黑色（对比色） | 深灰 #1a1a1a |
| 深色格子文字 | 白色 | 白色（仅 luminance < 0.35） |
| 描边粗细 | 2px/1px | 1.5px/0.8px |

## 验证
- `npm run build` 编译通过
- 导出 32×32 高清图纸 → 浅色格子深色字、深色格子白色字、字体更精致
