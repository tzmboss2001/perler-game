# 首页简化 — 去除空模板分类（2026-02-25）

## 背景
拼豆图纸生成器的核心功能是"图片→像素图→拼豆图纸"，官方模板分类（卡通动漫、游戏角色等）全部为空（0个），空架子影响用户体验。

## 改动

### `src/pages/mobile/HomePage.tsx`
1. **删除** `TemplateCategoryList` 组件引用和导入
2. **优化"我的方案"区域**：
   - 未登录 + 有本地方案：显示"本地方案 (N)" + "继续制作未完成的作品"
   - 未登录 + 无方案：显示"还没有方案" + "上传图片生成你的第一个拼豆图案"
   - 已登录：保持原有"查看全部方案"
3. **新增本地方案计数**：标题栏显示数量角标
4. 引入 `localStorageService` 获取本地方案数

## 简化后首页结构
```
精选作品（轮播）
    ↓
快速开始（拍照/相册）
    ↓
我的方案（本地方案数量 + 入口）
    ↓
社区作品（即将上线占位）
```

## 验证
- `npm run build` 编译通过
- Chrome MCP 验证首页显示正常
