# 首页重新设计

> 日期：2026-02-02
> 模型：Claude Opus 4.5

## 修改概述

根据需求讨论，对首页进行了全面重新设计，新增了多个组件和功能模块。

## 新增文件

### 1. 新手引导弹窗组件
**文件**：`src/components/OnboardingModal.tsx`

**功能**：
- 首次打开 App 时显示 3-4 页滑动引导
- 支持跳过和完成
- 使用 localStorage 记录状态，不重复显示
- 可在设置页面重新触发（通过 `forceShow` 属性）

**导出工具函数**：
- `shouldShowOnboarding()` - 检查是否需要显示引导
- `resetOnboarding()` - 重置引导状态

### 2. 精选作品轮播组件
**文件**：`src/components/FeaturedCarousel.tsx`

**功能**：
- 自动轮播（3秒间隔）
- 支持手动滑动
- 显示作品难度、官方标签
- 点击可使用该模板

**数据接口**：
```typescript
interface FeaturedWork {
  id: string;
  title: string;
  imageUrl: string;
  beadCount: number;
  gridSize: string;
  difficulty: 'easy' | 'medium' | 'hard';
  isOfficial: boolean;
  category: string;
}
```

### 3. 模板分类横向滚动组件
**文件**：`src/components/TemplateCategoryList.tsx`

**功能**：
- 6 个分类：卡通动漫、游戏角色、可爱动物、风景、节日主题、其他
- 横向滚动展示
- 点击进入分类页面
- "查看全部" 入口

### 4. 示例作品数据
**文件**：`src/data/featuredWorks.ts`

**功能**：
- 5 个示例作品：皮卡丘、超级马里奥、可爱小猫、樱花树、爱心图案
- 使用 Canvas 动态生成像素图案
- 每个作品都是 16x16 像素网格

## 修改文件

### 首页 HomePage.tsx
**文件**：`src/pages/mobile/HomePage.tsx`

**新布局结构**：
```
┌─────────────────────────────────┐
│  Header: Logo + 用户头像        │
├─────────────────────────────────┤
│  精选作品轮播                   │
├─────────────────────────────────┤
│  快速开始                       │
│  [拍照创作] [相册选择]          │
├─────────────────────────────────┤
│  模板精选（横向滚动）           │
├─────────────────────────────────┤
│  我的方案                       │
├─────────────────────────────────┤
│  社区作品（即将上线）           │

```

**变更**：
- 移除固定标题区，改为更紧凑的 Header
- 新增精选作品轮播
- 快速开始改为两列并排布局
- 新增模板分类横向滚动
- 我的方案根据登录状态显示不同内容
- 新增社区预留区域
