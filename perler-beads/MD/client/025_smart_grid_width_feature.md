# 智能网格宽度与板子规格功能实现记录

## 日期
2025-01-26

## 功能描述
三个相关功能的实现：
1. **扩展网格宽度上限**：从100扩展到256，支持大型拼豆板和拼接板
2. **板子规格提示**：在编辑页面显示推荐的拼豆板规格
3. **智能宽度推荐**：根据图片复杂度自动推荐合适的网格宽度

## 拼豆板规格说明

| 规格 | 钉数 | 说明 |
|------|------|------|
| 小方板 | 52×52 | 单块小板 |
| 大方板 | 104×104 | 单块大板（相当于4块小板） |
| 拼接板 | 156×156 | 3块大板拼接 |
| 大拼接 | 208×208 | 4块大板拼接 |

## 智能推荐算法

### 复杂度计算
```typescript
// 边缘密度：简化版 Sobel 算子
edgeDensity = 水平梯度² + 垂直梯度² 的均值

// 颜色复杂度 = 颜色数量分数(40%) + 渐变分数(60%)
colorComplexity = colorCountScore * 0.4 + gradientScore * 0.6

// 综合复杂度：边缘权重更高（拼豆中边缘细节更重要）
overallComplexity = edgeDensity * 0.6 + colorComplexity * 0.4
```

### 推荐映射
| 复杂度范围 | 推荐宽度 | 描述 |
|-----------|---------|------|
| < 0.15 | 32 | 简单图案 |
| 0.15-0.25 | 42 | 较简单图案 |
| 0.25-0.35 | 52 | 中等复杂度 |
| 0.35-0.50 | 64 | 较复杂图案 |
| 0.50-0.65 | 80 | 复杂图案 |
| > 0.65 | 104 | 高细节图案 |

## 性能优化（2025-01-26 补充）

### 性能问题
珠子数量是平方增长的，高宽度时会明显变慢：
| 网格宽度 | 珠子数量 | 计算量 |
|---------|---------|-------|
| 32×32 | 1,024 | 基准 |
| 64×64 | 4,096 | 4倍 |
| 100×100 | 10,000 | 10倍 |
| 150×150 | 22,500 | 22倍 |

### 优化措施

1. **UI 限制**
   - 滑动条最大值：150（从256降低）
   - 智能推荐最大值：104
   - 创建页选项：32-104

2. **性能警告**
   - 当宽度 > 80 时显示警告
   - 样式：橙色背景提示框

3. **算法缓存优化**（colorMatchService.ts）
   - `beadLabCache`：缓存珠子颜色的 Lab 值
   - `beadSaturationCache`：缓存珠子颜色的饱和度
   - `colorMatchCache`：缓存颜色匹配结果
   - `vibrancyMatchCache`：缓存带鲜艳度的颜色匹配结果
   - 缓存大小限制：10,000 条

## 技术要点

### 图片分析优化
- 分析时将图片缩小到 100×100，避免性能问题
- 使用简化版 Sobel 算子，平衡准确度和性能
- 颜色量化到 32 级，减少计算量

### 推荐值对齐
推荐的宽度会对齐到标准规格：32, 42, 52, 64, 80, 104, 156, 208

### 原图尺寸限制
如果原图很小，不会推荐超过原图 1/3 的网格宽度，避免过度放大
