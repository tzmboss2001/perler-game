# 抖音提审文案模板（拼豆工坊）

## 1. 小程序简介（后台）
拼豆工坊是一款图片转拼豆图纸工具。用户可上传图片，自动生成拼豆方案，查看颜色统计，并进入制作辅助模式进行分步制作。支持作品发布到社区、点赞与举报，提供基础内容审核与违规处理机制。

## 2. 主要功能说明（后台）
- 图片上传与自动生成拼豆图案
- 图案编辑（网格、颜色、替换）
- 制作辅助（区块高亮、坐标提示、导出图纸）
- 本地/云端方案保存与恢复
- 社区发布、点赞、举报
- 管理后台审核与举报处理

## 3. 用户协议与隐私说明（后台摘要）
- 已在应用内提供《用户协议》《隐私政策》入口
- 仅收集实现核心功能所需信息（如登录态、用户发布内容）
- 用户可通过反馈渠道进行问题咨询与内容申诉

## 4. 广告与商业化说明（后台）
- 应用内广告位有“广告”标识
- 激励广告仅用于解锁高级导出次数
- 广告失败时不影响核心制作功能
- 不强制观看广告才能完成核心流程

## 5. 内容治理说明（后台）
- 社区内容支持用户举报
- 管理后台支持举报处理（采纳/驳回）
- 违规内容可下架，处理过程可追溯
- 支持运营日志审计

## 6. 审核测试建议路径（可填在审核备注）
1) 进入首页 -> 上传图片 -> 生成图案
2) 进入编辑页 -> 进入制作模式 -> 导出图纸
3) 登录后发布到社区 -> 在详情页点赞/举报
4) 进入设置页查看《隐私政策》《用户协议》《意见反馈》

## 7. 备注模板（可选）
如审核中遇到接口不可用，请在网络恢复后重试。应用对弱网场景已做超时提示与重试引导，不会阻塞核心使用。
