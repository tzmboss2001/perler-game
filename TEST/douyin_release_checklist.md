# 抖音小程序上线合规清单（拼豆工坊）
> 日期：2026-03-05
> 说明：用于提审前逐项打勾，完成后需附对应截图或日志证据。

## A. 基础信息与可用性
- [ ] 小程序名称、简介、图标与实际功能一致
- [ ] 首页到核心链路（上传/生成/编辑/制作/保存）可完整走通
- [ ] 无明显黑屏、白屏、崩溃
- [ ] 404/接口失败有用户可理解提示

## B. 隐私与协议
- [ ] 应用内可访问《隐私政策》
- [ ] 应用内可访问《用户协议》
- [ ] 设置页含隐私/协议入口
- [ ] 个人信息收集说明与实际行为一致

## C. UGC 内容治理（社区/成品）
- [ ] 社区作品详情有举报入口
- [ ] 成品详情有举报入口
- [ ] 后台有举报处理能力（采纳/驳回/下架）
- [ ] 后台有审核日志可追溯
- [ ] 违规内容可下架，处理结果可记录

## D. 用户反馈与客服
- [ ] 应用内有意见反馈入口
- [ ] 反馈提交后有成功提示
- [ ] 后端可接收并保存反馈

## E. 商业化与广告
- [ ] 广告位标识清晰（如“广告”）
- [ ] 激励广告节点有明确说明
- [ ] 广告不误导点击，不遮挡核心操作
- [ ] 广告策略文案与实际一致

## F. 风控与运营
- [ ] 登录态校验正确（游客/登录行为一致）
- [ ] 点赞/举报/发布失败有兜底提示
- [ ] 管理后台权限校验有效（非管理员不可操作）
- [ ] 关键操作有日志（审核、举报处理）

## G. 发布前技术门禁
- [ ] 前端 `npm run build` 通过
- [ ] 后端 `go build` 通过
- [ ] 合规自动检查脚本通过（`SCRIPT/douyin_compliance_check.ps1`）
